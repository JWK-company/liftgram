## 1. 판단 원칙

1. **정체성 = (동작, 기구).** 자세·기구·주동근이 같고 이름만 다르면 한 종목 + 별칭(예: 밀리터리 프레스→바벨 오버헤드 프레스, 하이바 스쿼트→바벨 스쿼트). 기구가 다르면 별도 종목이고 같은 `family`로 잇는다. **family 안에서 기구는 서로 다르다**(검증 통과 — 위반 0).
2. **대표 이름 = 「기구 + 동작」.** 괄호형(`X (덤벨)`)·후미형(`X 머신`)을 모두 접두형으로 바꿨다. 맨몸은 기구를 붙이지 않는다. 링·플레이트·티바·랜드마인처럼 기구가 이름에 이미 들어 있는 것은 그대로 둔다. 옛 이름은 모두 별칭으로 남겼다(아래 예외 1건).
3. **머신 고유 동작은 「머신」 접두를 생략**했다 — 레그 프레스·레그 익스텐션·라잉/시티드/스탠딩 레그 컬·핵 스쿼트·펜듈럼/벨트 스쿼트·펙 덱 플라이·리버스 펙 덱·글루트 햄 레이즈·리버스 하이퍼익스텐션·어시스트 3종. 같은 동작을 다른 기구로 하는 경우가 흔하지 않고, 접두를 붙이면 이름만 길어진다(애매 항목 A1).
4. **부착물·손그립·원암(S1 확정).** 이름에 부착물·그립·원암을 넣은 종목은 기본 종목에 병합하고 `implied_axes`에 축 값을 적었다. 옛 이름은 대상의 `aliases_ko`에 넣고, 대상 note에 "별칭이 축 값을 함축"한다고 적었다. 대상이 이미 있는 별칭(예: `V바 풀다운`, `언더그립 푸시다운`)도 같은 방식으로 표시했다.
   - **예외(동작 자체가 다름)**: 덤벨 로우(원암 — 사용자 확정), 원암 푸시업·아처 푸시업(칼리스데닉스 스킬), 메도우스 로우·수트케이스 캐리·랜드마인 프레스(한쪽만 쓰는 것이 동작의 정의).
   - **예외 후보(관행상 독립 + 주동근이 바뀜)** — 기본은 유지로 두고 애매 항목으로 올렸다: 덤벨/케이블 해머 컬, 리버스 컬 3종·EZ바 리버스 컬, 리버스 리스트 컬, 바벨 클로즈그립 벤치프레스 계열, 친업, 다이아몬드 푸시업.
5. **브랜드·모델명.** `해머스트렝스 체스트 프레스`는 delete → 머신 체스트 프레스 + `brand=hammer`. `하이 로우`·`로우 로우`(Hammer iso-lateral 모델명)는 운영에서 쓰고 있어 `머신 하이 로우`·`머신 로우 로우`로 rename했다(옛 이름은 별칭). `컨버징 체스트 프레스 머신`은 머신 궤적 특성(모델)이라 병합했다.
6. **운영에서 쓴 종목(§H.2·H.3)은 delete 0건** — rename 또는 merge만 했다. delete는 해머스트렝스 1건뿐이다(사용 0).
7. **커버리지(S3).** 부위×기구 매트릭스의 빈칸 중 **흔한 동작의 흔한 기구 대응**만 채웠다(사용자 예시: 프리처 컬 머신·머신 랫풀다운·머신 시티드 로우·덤벨 스쿼트·트랩바 데드리프트·EZ바 컬·케이블 프리처 컬·인클라인 케이블 플라이·스미스 RDL은 모두 반영. 머신 시티드 로우는 기존 `머신 로우`를 rename해서 해결). 드문 변형(체인·밴드 저항 바벨, 스트롱맨, 메디신볼 던지기, 단측 변형)은 넣지 않았다.
8. **별칭 정책.** 한국 헬스장에서 흔히 쓰는 줄임말·오기를 넉넉히 넣었다(랫풀/렛풀다운·벤치·밀프·사레레/레레·턱걸이·데드·스쿼드·레그익스·레그컬·카프레이즈·힙쓰·불스스·행레레·이너타이/아웃타이·롱풀 등). 영어 별칭도 넣었다. **여러 종목에 다 맞는 일반어("런지"·"킥백"·"프레스" 등)는 별칭으로 넣지 않았다** — 부분일치 검색으로 이미 찾히고, 정확일치 별칭이 겹치면 충돌하기 때문이다(예외: 옛 sync 이름이던 `런지`·`인클라인 프레스`는 원래 종목의 별칭으로 보존).
9. **media.** 같은 동작·같은 기구 사진이 free-exercise-db(fedb)에 있으면 `fedb:<id>`, 없으면 `gen`. 다른 기구 사진을 빌려 쓰던 것(괄호 폴백 상속 포함)은 `gen`으로 내렸다(ADR-036). 병합·삭제 행은 `inherit:<대상>`. 유산소는 `none`(현행 정책대로 제외).
10. **load_mode** 열은 시드 값(`assisted`) 또는 파생값을 적었다: 맨몸=`bodyweight`, 그 외=`weight`(시드 미지정·기구 무게 의미 — 도메인 enum엔 없는 표기용 값).
11. **기구 어휘.** 기존 enum 9종에 `ezbar`·`trapbar` 2종을 신설 제안했다(EZ바 7종·트랩바 3종). EZ바 컬은 기존 barbell에서 ezbar로 바뀐다(애매 항목 A14).

## 8. 미확인

- usage_sets는 §H.2 상위 30 + `로우 로우` 11만 채웠다. 나머지 사용 종목(~40종)의 세트 수는 분석 문서에 없어 비웠다(delete 금지 판정은 §H.3 변형 사용 흔적까지 포함해 적용).
- fedb @main 덤프는 커밋 해시를 고정하지 않았다. 생성 스크립트에서 고정 필요.
- 별칭 충돌 검사는 정확일치(정규화 후) 기준이다. 초성·부분일치 검색에서 생기는 결과 겹침은 검사하지 않았다.
- `Lying Chest Press Machine`↔fedb `Machine_Bench_Press`, `Seated Cable Chest Press`↔`Cable_Chest_Press` 동작 일치 여부는 사진으로 확인하지 않아 gen으로 두었다.
