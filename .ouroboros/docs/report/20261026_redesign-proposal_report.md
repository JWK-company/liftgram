## 진단 (모든 화면이 공유하는 뼈대 문제)
1. 앱바가 화면마다 다름(홈 없음 · 큰 제목 · 피드는 붉은 아이콘 5개)
2. 탭 6개(기록·캘린더가 같은 데이터) → 좁음
3. 모든 요소가 카드 → 위계 없음
4. 위험 버튼 과노출(운동 취소·기록 휴지통)
5. 운동 중 탭바 존재 → 휴식 띠 겹침
6. 홈이 비어 보임(루틴·목표·최근이 첫 화면에 없음)

## 북타래 규칙 차용

구간 선택기/밑줄 탭 · 위험 동작은 ⋯/시트 · 여백 16–20 · 터치 44+ · 반경 12/16 · 활자 10단계
