광고로 무료, 광고 없이 구독 — 어디에 붙이고 얼마에 팔까

「모든 기능 무료 + 광고, 광고가 싫으면 월 구독」 안을 경쟁 앱 7곳과 견주고, 운동하는 사람이 광고를 만나는 지점을 화면 단위로 정했습니다. 수치는 북타래 광고 조사(2026-10-07 · 10-11)에서 쓴 웹 광고 단가를 운동 앱 사용 패턴에 맞게 다시 셈했습니다.

기준: PRD · SRS-014 · BS-003(착용장비)운영 현황: 가입 3명 · 최근 30일 운동 기록 168건환율 1달러 = 1,400원 가정

2곳국내 1·2위 기록 앱(번핏·짐워크)이 이미 쓰는 모델이 「광고 + 광고 없는 PRO」
약 50원웹(PWA)에서 무료 사용자 1명이 한 달에 만드는 광고 수익(기준 추정)
월 2,900원제안 구독가. 번핏 PRO 월 5,900원의 절반, Hevy 월 $2.99와 비슷

결론

방향은 맞습니다. 국내 경쟁 앱 번핏과 짐워크가 광고를 붙이고 PRO에서 광고를 뺍니다. 다만 그대로 하면 세 가지가 아쉽습니다.

  1. 웹 광고는 생각보다 적게 법니다. 리프트그램은 지금 웹(PWA)만 있어서 앱 광고(AdMob)를 못 쓰고, 웹 광고는 배너를 바꿔 끼우지 못하고 전면 광고 시점도 고를 수 없습니다. 무료 1명이 월 50원 안팎이라 MAU 1만 명이어도 광고는 월 50만 원 정도입니다.
  2. 「광고 제거」 하나만 파는 구독은 약합니다. 운동 중 광고를 안 띄우면 광고가 거슬리는 순간이 적어서, 돈 내고 뺄 이유도 그만큼 줄어듭니다. 기능은 잠그지 않되 「서포터」 혜택(광고 없음 + 배지·공유 카드 테마·새 기능 먼저)과 평생 이용권을 붙이는 편이 낫습니다.
  3. 큰돈은 광고망이 아니라 직접 파는 스폰서 자리에서 나옵니다. 헬스장·보충제·장비 브랜드가 피드와 완료 요약 카드에 직접 돈을 내는 자리입니다. PRD의 헬스장 B2B, BS-003 착용장비와 같은 자리를 씁니다.
광고 원칙 한 줄: 「운동하는 동안에는 광고가 절대 없다」를 약속 문구로 겁니다. Hevy가 「No ads」를 내세우듯, 우리는 「운동 중엔 광고 없음」을 내세웁니다. 광고는 운동이 끝나 결과를 다 본 뒤, 그리고 피드·기록·통계처럼 둘러보는 화면에만 둡니다.
지금 문서와 부딪힙니다. PRD 비목표에 「광고 모델 전면 채택 안 함 · Hevy 무광고 강점 훼손」, 목표 G1에 「무료·무광고」, SRS-014에 「프리미엄은 AI 코치 심화·고급 분석 잠금 해제」가 적혀 있습니다. 이 안으로 가면 PRD·SRS-014를 고치고 BS·BIZ로 근거를 남겨야 합니다.

본받을 점 다섯

국내 시장은 「광고 + 광고 없는 PRO」가 기본값이다번핏·짐워크 모두 이 모델입니다. 사용자가 낯설어하지 않습니다. 대신 Hevy가 쓰는 「광고 없음」 문구는 잃으니, 「운동 중엔 광고 없음」으로 바꿔 겁니다.
광고 불만은 운동 중 광고에서 나온다JEFIT·짐워크 리뷰의 광고 불만은 대부분 기록 도중 뜨는 광고입니다. 둘러보는 화면의 광고는 덜 문제됩니다.
연간을 싸게, 평생 이용권을 같이Hevy·Strong 모두 연간 월 $2~2.5에 평생 $75~100을 둡니다. 기록 앱은 몇 년씩 쓰는 도구라 평생 이용권이 잘 팔리고, 초기 현금이 생깁니다.
원가가 드는 기능만 따로 받는다플랜핏은 AI, 짐워크는 코치 루틴을 돈 받는 자리로 씁니다. 「모든 기능 무료」 원칙과도 맞습니다. 서버나 사람에게 돈이 드는 것만 유료로 받으면 됩니다.
파는 사람이 따로 있으면 사용자는 무료로 둘 수 있다짐워크 코치 센터는 코치가 루틴으로 벌고, Strava는 브랜드가 챌린지 스폰서로 돈을 냅니다. 광고망보다 단가가 높고, 운동 맥락에 맞는 내용이라 덜 거슬립니다.

2. 웹 앱이라서 생기는 제약

리프트그램은 지금 웹(PWA)만 있습니다. 북타래 조사에서 확인한 웹 광고 규칙이 운동 앱에서는 이렇게 작동합니다.

규칙운동 앱에 뜻하는 것
앱 광고(AdMob)는 스토어 앱만웹에서는 AdSense · Ad Manager · 카카오 애드핏만 씁니다. 단가가 가장 높은 앱 전면·보상형은 스토어 앱을 낸 뒤의 이야기입니다.
AdSense 배너 자동 새로고침 금지운동 화면처럼 한 화면에 1시간 머물면 배너 노출은 1회입니다. 운동 중 배너는 불쾌하기만 하고 돈도 안 됩니다.
웹 전면(비넷)은 링크로 페이지를 옮길 때만Next.js 화면 전환은 페이지를 새로 부르지 않아 거의 안 뜹니다. 「운동 끝나면 전면」을 우리가 정해서 띄울 수 없습니다.
실수 클릭을 부르는 배치 금지(AdSense 정책)세트 완료 버튼·휴식 타이머 옆 광고는 땀 젖은 손의 오터치를 부릅니다. 무효 클릭으로 계정이 정지될 위험이 있습니다.
화면이 꺼지면 노출 0 · 국내 광고 차단 약 17%운동 중에는 화면이 대부분 잠겨 있습니다. 실제 노출은 운동 앞뒤와 둘러보는 화면에서 생깁니다.
그래서 운동 중 광고를 빼는 것은 체험만이 아니라 수익으로 봐도 손해가 거의 없습니다. 광고 수익은 운동이 끝난 뒤의 요약, 피드 스크롤, 기록·통계를 둘러볼 때 생깁니다.

3. 광고를 어디에 띄우나

사용자가 앱을 여는 순서대로 놓고, 화면마다 광고를 두는지 정했습니다.

허용 · 아래쪽만홈 · 루틴 고르기시작 버튼보다 위에는 안 둡니다. 루틴 목록 맨 아래 배너 1개
금지운동 중세트 입력 · 휴식 타이머 · 종목 추가 피커 · 다른 탭의 운동 바
금지PR 축하축하 순간은 그대로 둡니다
추천 1순위완료 요약결과를 다 보여 준 뒤, 종목별 기록 아래 카드 1개
추천피드게시물 6개마다 「광고」 표시 카드 1개
허용기록 · 통계 · 종목 둘러보기스크롤 끝 배너 1개
광고 금지추천 자리허용(조건부)

광고를 두지 않는 곳

  • 운동 세션 전체: 세트 표, 휴식 타이머, 운동 중 종목 추가·교체 피커, 다른 탭에 떠 있는 운동 바
  • PR 축하 · 공유 카드: 공유 이미지에 광고를 넣으면 남의 피드에 우리 광고가 실려 거부감이 큽니다
  • 가입 후 첫 7일(또는 첫 운동 5회): 습관이 들기 전에는 광고를 안 봅니다. D30 리텐션이 3~10%인 업종이라 첫 주가 가장 비쌉니다
  • 로그인 · 결제 · 설정 · DM · 코칭 · 신고 화면

빈도 규칙

  • 완료 요약 광고는 하루 첫 운동에만. 같은 날 두 번째 운동부터는 없습니다.
  • 한 사람이 하루에 보는 광고 상한 8회(피드 포함). 넘으면 그날은 숨깁니다.
  • 광고 자리는 공용 「광고 슬롯」 하나로 만들고, 운동 세션이 켜져 있으면 슬롯이 스스로 비도록 막습니다. 나중에 화면을 고치다 실수로 운동 중 광고가 생기지 않게, e2e로 운동 화면에 광고 요소가 0개인지 지킵니다.

4. 더 좋은 방법 — 무료 전부 + 서포터 + 스폰서

사용자 원안(모든 기능 무료 + 광고 + 광고 제거 구독)을 뼈대로 두고, 구독이 「광고를 빼려고 내는 돈」에서 「응원하고 혜택을 받는 돈」이 되도록 넓혔습니다.
