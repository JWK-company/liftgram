# 화면 정리안 — 정보는 그대로, 소음은 덜어 내기 (2026-10-27 · v0.38.0 기준)

웹 보고서 원본: scratchpad `declutter/report.html` (캡처 `declutter/shots/*` · 생성기 `gen_report.py`)
캡처: 새 DB를 붙인 로컬 운영 빌드(3200)에 계정 2개를 시드했다. 데이터는 머신 해머·플레이트 한쪽, 케이블 로프, 슈퍼셋, lb, 총평, 공유, 팔로우, DM이다. 29화면을 390 라이트·다크와 360×640로 찍었다. 종목 상세·루틴 편집·검색·피커는 시드 스크립트가 화면을 열지 못해 빠졌다.

## 진단 — 반복되는 6가지 습관
1. **모든 정보가 상자에 담긴다.** 운동 블록 머리에만 칩·버튼이 9개다. 변형 시트에는 브랜드 칩이 16개 있다.
2. **빨강을 7곳에 쓴다.** 완료·볼륨 숫자·조합 칩·kg 선택·볼륨 칩·이전 칸 테두리·1RM이 모두 빨강이다. 그래서 정작 지금 눌러야 할 것이 묻힌다.
3. **같은 말을 두 번 한다.**
   - 조합 칩 바로 아래 「이전 기록 · 조합」 줄이 같은 내용을 되풀이한다.
   - 요약의 PR은 「종목·중량 PR / 종목·볼륨 PR」로 8줄이다.
   - 피드 카드의 숫자를 본문 자동 문구가 다시 말한다.
4. **늘 보일 필요 없는 것이 늘 보인다.** 운동 방법·이전기록 지우기·빈 RPE 열·종목마다 붙는 Epley 주석이 그렇다.
5. **행동이 한 줄에 끼어 꺾인다.** 피드 카드의 「바로 시 / 작」, 요약의 버튼 4개가 세로로 길게 이어지는 것이 예다.
6. **한 사실을 두 곳에 알린다.** 홈의 진행 중 카드와 진행 막대가 겹치고, 분석의 1RM은 두 섹션에 나온다.

핵심 수치(육안 집계): 360×640에서 첫 세트 체크 버튼은 위에서 486px에 있다. 블록 하나에 정보 요소는 약 52개다.

## 원칙안
- **A 점진 공개:** 핵심만 보이고 나머지는 한 줄로 접는다.
- **B 밀도 2단:** [집중 | 자세히]로 전환한다.
- **C 위계 재정렬:** 정보는 두고 상자를 걷어 낸다.
  - 칩은 회색 메타 글자로 바꾼다.
  - 색 의미는 「빨강=행동·완료 / 금색=PR」 두 가지만 남긴다.
  - 글자 단계를 6에서 4로 줄인다.
- **추천 C+A:** C를 공통 규칙으로 삼고, 정보가 몰리는 세 곳(블록 부가 행동·요약 PR·시트 브랜드)에만 A의 접기를 쓴다. 이렇게 하면 360에서 첫 세트 체크까지 거리가 약 300px로 줄어든다(추정).
