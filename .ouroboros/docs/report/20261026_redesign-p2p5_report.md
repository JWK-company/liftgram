## 단계별 화면 변화
### P2 기록·분석 (v0.26.0)
- **기록 목록(05)**: 달별 묶음(머리에 횟수·볼륨 합계) + 왼쪽 날짜 칸(일·요일) 줄. 휴지통 제거 → 삭제는 기록 상세 ⋯ 안(확인창 그대로).
- **기록 상세**: 하위 앱바(← · 기록 · ⋯ 삭제) + 숫자 한 줄(총 볼륨·시간·세트).
- **달력(06)**: 운동한 날은 칸을 주황으로 채움(수동 표시는 초록 칸, 메모만 있는 날은 점). 목표·연속은 요약 한 줄 → 누르면 설정 시트(± · 주말 포함/제외). 「이번 달 자랑하기」는 기록 머리 ⋯ 안(운동 없으면 ⋯ 째 숨김). 메모는 「+ 이 날 메모」로 펼침. 고른 날 세션은 줄 목록.
- **분석(07)**: 구간 선택기 4칸(주·월·3개월·전체). 대표 숫자(기간 볼륨) + 지난 같은 기간 대비(▲▼%) + 추세 막대 최소 8칸(최근 12주까지). 숫자 한 줄(세션·워킹 세트·세션당 볼륨). 추정 1RM·최근 PR은 줄 목록(1RM 줄 → 종목 상세).
- **루틴 편집(12)**: 하위 앱바(← · 루틴 이름 · ⋯ 삭제), 하단 고정 「완료 + 이 루틴으로 시작」(저장된 루틴·종목 있음·진행 중 운동 없음일 때).
- **종목 목록**: 하위 앱바, 카드+칩 더미 → 한 판의 줄 목록(이름 + 「부위 · 기구 · 다른 이름」).
- **종목 상세**: 맨 위 「내 추정 1RM」 추세(로컬 기록 · 분석과 같은 저장소 함수 · 기록 없으면 숨김).
- **다크 구간 선택기**: 선택 칸이 틀보다 어둡던 것 → `--seg-on`(다크 #535353).

### P3 계정·설정 (v0.27.0)
- **프로필(09)**: 맨 위 사람(아바타·이름·경력/의향 + 「수정」 → 경력·코칭 의향 시트). 설정은 줄 + 현재값 → 선택 시트(단위·테마·언어·알림음+음량·가용 기구·기구 이름). 바 무게·체중은 줄 안 스테퍼. 「계정과 데이터」 줄(로그인·보안 › 주소 · 백업 파일 · 장비함 · 코칭 · 저장한 게시물 · 차단 · 모더레이션). 맨 아래 버전·고지·약관·사업자 정보.
- **로그인/가입(10)**: 탭바 없는 전체 화면 · 로고 · 큰 제목 · 소셜 3종(「최근」 배지 유지) → 또는 이메일 → 아래 한 줄 링크. 로그인/가입 탭 제거(표식 `mode-signup`/`mode-login` 은 하단 링크로 옮겨 유지). 백업 카드·사업자 정보는 로그인 화면에서 뺌. 바닥 한 줄 「이용약관 · 개인정보처리방침 · 타래(TARAE)」. 로그아웃하면 로그인부터 다시.
- **비밀번호 찾기·재설정·이메일 확인·소셜 완료**: 같은 배치(AuthPage — 탭바 없음·로고·큰 제목·한 열).
- **/account**: 하위 앱바(← · 계정) + 세 구역 — 계정(이름·주소·로그아웃·프로필 편집) / 로그인·보안 / 기기와 서버(동기·백업 파일 `#backup`). 로그인 전 /account 는 로그인 폼 + 이 기기 백업 파일.
- **첫 실행 안내**: 「L」 임시 아이콘 → 앱 아이콘.

### P4 소셜 (v0.28.0)
- **피드(08)**: 앱바 아이콘 5개(붉은색) → 검색·DM·알림 3개(기본 글자색, 알림은 안 읽음 수 배지). 저장함은 프로필로, 사람 찾기는 「발견」 탭으로.
- 팔로잉/발견 밑줄 탭 — 발견 탭은 사람 찾기를 탭 안에 그대로(embedded). 팔로잉이 비면 그 자리에 사람 찾기.
- **글쓰기(D5)**: 화면 위 1/3 을 차지하던 입력 상자 → + 버튼 → 전체 화면 작성기(장비 태그·사진 그대로, 실패하면 연 채로 오류). 올리면 팔로잉으로 돌아와 새 글이 보인다.
- **DM 목록·알림**: 카드 더미 → 한 판의 줄 목록. 안 읽은 대화는 굵은 이름, 안 읽은 알림은 옅은 브랜드 바탕 + 점.
- **남의 프로필**: 내 프로필과 같은 머리(왼쪽 아바타 · 이름 · 게시물/팔로워/팔로잉). 차단은 머리 ⋯ 안.

### P5 나머지·넓은 화면 (v0.29.0 · v0.29.1)
- **넓은 화면(1024px+)**: 탭바 → 앱 칸(560px) 왼쪽 세로 막대(현재 탭 왼쪽 강조선). 진행 중 막대·글쓰기 버튼은 바닥에서 띄움.
- **약관·개인정보처리방침**: 하위 앱바 + 맨 아래 사업자 정보(로그인 화면에서 옮긴 자리).
- **내 장비함**: 손으로 만든 머리 → 공통 하위 앱바. 나머지 하위 화면(코칭·헬스장·프로그램·모더레이션·차단·DM 대화·댓글·팔로우 목록·종목 폼 등)은 P0 에서 ScreenHeader 가 앱바 2형으로 바뀌어 이미 따라왔다(전수 확인).
- **버그 수정**: 루틴 편집 하단 고정 줄이 모바일 탭바에 가려 있던 것(P2 도입) → 탭바 높이만큼 위.
- **v0.29.1 수정(PWA)**: 첫 방문에 서비스워커가 처음 자리 잡을 때도 홈을 새로고침해, 막 누른 화면 이동이 끊겼다(운영 offline e2e 에서 「/exercises 이동이 / 새로고침에 끊김」 으로 재현). 옛 워커가 있었을 때만 새로고침한다. 사용자가 말한 「이상한 화면」 유형 하나였다.

## 계획과 다르게 한 것
- **완료 화면 「피드에 공유」(D5)**: 같은 작성기로 합치지 않았다. 완료 화면의 공유는 운동 카드(종목·세트 구조 데이터)를 붙여 올리는 별도 흐름이라, 일반 작성기에 운동 첨부를 새로 만들어야 한다 — 로직 변경이라 이번 범위(배치만)에서 뺐다.
- **피드 머리의 팔로워 수(시안 09 프로필 숫자 셋)**: 내 프로필에는 숫자 셋을 넣지 않았다(서버 왕복이 하나 더 늘어 체감 속도 목표와 부딪힌다). 남의 프로필에는 있다.
- **데이터·동기화 로직 무변경 원칙의 예외 하나**: syncOwner 의 시드 import 를 동적으로 바꿨다(받는 시점만 바뀜 · 동작 같음).
