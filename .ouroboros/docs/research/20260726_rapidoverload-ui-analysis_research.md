# RapidOverload(급진적 과부하) UI·특장점 분석 및 Liftgram 적용 방안

- 조사일: 2026-07-26 · 조사 방법: 로그인 세션으로 전 화면 실클릭 탐색(chrome-devtools MCP) + 격리 컨텍스트로 온보딩 퍼널 전체 주행
- 대상: https://rapidoverload.com (PWA · 앱스토어 없음 · "홈 화면에 추가" 안내)
- 스크린샷: `assets/rapidoverload/01~19` (본문에서 번호로 인용)
- 포지셔닝: **"알고리즘 기반 1:1 운동 코칭"** — Hevy가 "자유 기록 + 소셜"이라면, RapidOverload는 **"처방(프로그램)을 파는 앱"**. 기록은 처방을 검증하는 입력 수단이다.

---

## 1. 제품 구조 한눈에

```
온보딩(8문항 설문) → 맞춤 루틴 생성 → [페이월: 7일 무료+카드등록] → 가입
홈(오늘 운동·블록 주차) → 운동(RIR 처방 세트 로깅) → 분석(캘린더·퍼포먼스·볼륨)
루틴(카탈로그·에디터: 부위강조/목적/중량선호/훈련주기) → 설정(구독·FAQ)
알고리즘: 첫 7일(루틴 상 7일치)=데이터 수집 → 8일차~ 중량·횟수 코칭 → 10-14일~ 세트수·RIR 조절
블록 종료 시: 부진 부위 감지 → 운동 교체 제안 / 세트 수 임시 감소 + RIR 하향
```

- 하단 4탭: 홈 / 루틴 / 분석 / 설정 (Liftgram 6탭보다 단순)
- 다크 단일 테마, 보라 포인트 컬러, 모바일 전용 레이아웃

## 2. 화면별 상세 발견

### 2.1 홈 대시보드 (01)
- 상단: 현재 루틴명 + **"스트렝스 0 : 근비대 100"** 비율 게이지(내 프로그램의 성격을 항상 노출).
- "오늘 운동" 카드: Day 번호·운동 수·세트 수 요약 + 큰 CTA 하나("오늘 운동 시작"). **오늘 할 일이 단 하나로 수렴**하는 화면.
- **"맞춤 코칭을 위한 데이터 분석 중 0%"** 진행바: 첫 주 데이터 수집 기간을 기대치 관리로 전환(코칭이 아직 안 오는 이유를 미리 설명).
- 주차 스트립: `1주차 — 5주 운동 • 1주 디로딩` + Day1·2·3·휴식·Day1a·2a·휴식 칩. **블록 주기화가 홈에 상시 노출**.
- 튜토리얼 버튼 → 유튜브 영상(https://www.youtube.com/watch?v=HatCT2zCXME)으로 외부화.

### 2.2 워크아웃 세션 /training (04~06)
핵심 화면. 운동 카드 아코디언(한 번에 하나 펼침) + 드래그 재정렬 + 하단 "운동 완료".

- 상단 고정 버튼 2개: **RIR 가이드 / 웜업 가이드** — 세션 안에서 4p/3p 페이지네이션 모달 교육:
  - RIR 정의(남은 횟수) → "주관적 힘듦이 아니라 **수행 속도(Bar Speed) 변화**로 판단" → RIR 3/2/1/0 단계별 서술 기준 → "가끔 RIR 0까지 가서 영점 조절" (콘텐츠 자체가 카피할 가치 있음)
  - 웜업: 목적 → "횟수보다 낮은 강도(속도 안 느려지는 구간)" → "익숙하면 생략 가능"
- **세트 타입 처방 구조(최대 차별점)** — 세트가 "n세트 × m회"가 아니라 타입별 역할·RIR·rep range로 처방됨:
  | 세트 타입 | 복합운동(벤치) | 고립운동(플라이) |
  |---|---|---|
  | 웜업 | 6RIR 저중량×6 → 5RIR ×5 (2세트) | 6RIR 중간중량×6 (1세트) |
  | 탑 세트 | 1RIR 고중량×4-7 | 0RIR 고중량×4-7 |
  | 본(백오프) 세트 | 1RIR 고중량×4-7 / 중간중량×8-12 | 0RIR 중간중량×8-12 ×2 |
  - placeholder에 "저중량/중간중량/고중량"+목표 횟수를 프리필 → 데이터 없어도 빈 화면이 아님.
- **중량 추천 캐스케이드**: 웜업 1세트에 20kg 입력·체크하자 다음 웜업 placeholder가 **22.4kg**로 즉시 계산됨. 소수점 권장 중량 + "가장 가까운 중량으로 맞추세요" 안내(온보딩 슬라이드).
- **세트 체크 UX**: 중량+횟수 모두 입력해야 체크 가능 → 체크 시 해당 행 **readonly 잠금** + 상단 고정 **휴식 타이머 배너**(권장 휴식 35초/웜업 — 세트 타입별 상이, 일시정지·닫기·진행바) 자동 시작. 재탭으로 해제. 미체크 입력값도 서버에 드래프트 유지(접었다 펴도 보존).
- 운동 카드 내부: GIF 시연 + **Tip 버튼** → 유튜브 쇼츠 링크 + 부위 태그("가슴 복합") + **수정·저장 가능한 팁 텍스트**(기본 코칭 팁을 사용자가 덮어쓰는 개인 메모로 활용).
- kg/lbs 토글(운동 단위), + 세트 추가 / − 세트 삭제(추가 세트는 본 세트 타입).
- "운동 완료" → 미완료 세트 있으면 "아직 남은 세트가 있어요! 정말 끝낼까요?" 확인 모달.

### 2.3 루틴 탭 (07·13)
- 내 루틴(사용중 배지 + ⋮ 메뉴: 사용 중지/수정/삭제) + **루틴 카탈로그 4탭**:
  - 운동횟수: 주2 무분할 ~ 주6 PPL·몸통-말단-하체 (9종)
  - **특수루틴**: Bear Mode·뽀빠이·캡틴 아메리카·아파트 헬스장(미니멀)·순수 근비대·파워빌딩·패션근육 — **콘셉트 브랜딩**(어떤 몸을 원하는가로 이름 붙임)
  - 여성헬스: 여성 루틴·힙업·힙 only
  - 커스텀: 주2~6 직접 만들기
- 루틴 상세(13): **스토리텔링 설명**("곰 같은 육중한 체형… 상부 승모근·목·측면 삼각근·삼두·대퇴사두·둔근 집중") + **루틴 미리보기(1주 기준)** 데이별 GIF 타임라인 + "내 루틴에 저장 / 루틴 바로 사용".

### 2.4 루틴 에디터 /user_routines/:id/edit (08~10)
Day 목록(편집·휴식일 드래그 재배치) + 루틴 파라미터 4종 — **알고리즘의 사용자 노브**:
1. **신체 부위 강조** (09): 강조/유지 모드 · 17개 근육 중 **최대 3개** · 집중 강도(적당히/강하게) · 가이드 토스트("루틴에 없는 부위는 강조해도 반영 안 됨 — 운동을 먼저 추가하라")
2. **운동 목적** (10): 스트렝스↔근비대 **5단계 슬라이더** · 가이드("근비대=볼륨 위주, 스트렝스=중량 위주")
3. **중량 선호도**: 성별 + 초고중량/고중량/중간(추천)/저중량/초저중량 5단계 · 경고 "잦은 변경은 퍼포먼스 가늠과 정확한 코칭을 방해해요"
4. **훈련 주기**: 연속(디로딩 없음) / 4+1 / **5+1(추천)** / 6+1주
- Day 편집(12): 운동별 처방 미리보기(탑/본 세트·중량대·RIR) + 세트 추가/삭제 + 운동 삭제 + **운동 변경**(11): 같은 무브먼트 패턴 대체운동 ~25종(푸시업→해머스트렝스→바벨/덤벨/케이블/머신 변형) GIF 라디오 리스트 + **부위별 커스텀 운동 슬롯**("가슴 (커스텀 운동 1)")
- 운동 추가: 검색 + 부위 필터(17근육 멀티선택) — 라이브러리 **~284종**, 전부 GIF 썸네일.
- 상단 고지: "횟수·강도·세트 수는 알고리즘에 의해 운동 수행 시 변경될 수 있습니다".

### 2.5 분석 탭 /performance
- 운동 기록 캘린더(월간) + 3개 리포트: 블록 진행 상황 / 운동별 퍼포먼스 변화 / 부위별 볼륨 변화.
- 데이터 없으면 진입 차단 토스트("운동을 진행한 후 확인해 주세요") — 빈 차트를 안 보여줌.

### 2.6 설정 /settings
- 프로필·구독 관리·FAQ·문의(카카오 채널)·약관·로그아웃·탈퇴. 매우 얇음.
- **구독**: 이용기간·해지예정일·결제수단·카드변경·"계속 이용하기". FAQ 4개가 사실상 코칭 알고리즘 문서:
  - "첫 7일(=루틴 상 7일치 완료 기준) 데이터 수집, 8일차부터 코칭"
  - "알고리즘은 퍼포먼스·근육통·몸 상태를 보고 볼륨·중량·운동 종류를 변경"
  - PWA 설치 안내 / "운동 없으면 비슷한 동작으로 바꿔도 됨"

### 2.7 온보딩 퍼널 /app/onboarding (14~19) — 격리 컨텍스트로 전체 주행
1. **인트로 캐러셀 4장**: 알고리즘 소개(권장 중량 소수점 안내 / 블록 완료 시 부진 부위 운동 교체 제안 목업 / **"세트 수를 줄일게요" — 특정 부위 퍼포먼스 감소 감지 → 세트 1개 감소+RIR 하향** 목업) → 코칭 타임라인(1주 수집 → 8일 중량·횟수 → 10-14일 세트수·RIR) → "20년 근비대/스트렝스 연구" 브랜드 스토리
2. **설문 8문항**(성별 선택 시 6→8문항 동적 분기): 체중(중량 계산용 명시) → 성별 → **체지방% 입력 → 해당 구간(18-22%) 실사 체형 사진 3장 중 탭 선택**(수치를 시각으로 캘리브레이션 — 최고의 UX 발견) → 경력(1-2/3-6/7년+) → 주당 횟수(1~6) → 목적 슬라이더(권장 마커) → 강조/유지 부위(선택·최대3) → 중량 선호(중간=추천)
3. 생성 로딩 → **루틴 프리뷰**: "운동종류·중량·횟수·RIR·주기·비율 모두 맞춤" 배지 6개 + 1주 전체 GIF 미리보기 + **스크롤해야 활성화되는 CTA**(루틴을 훑게 강제)
4. **디로딩 교육 페이지**(18): 6주 사이클 도식 + 피로도 곡선 + 6개월 성장 트렌드 그래프 — 결제 전에 "왜 이 프로그램이 과학적인가"를 시각 설득
5. 소셜 프루프(바디 변화 후기 사진 캐러셀) → **페이월(19)**: "첫 7일 무료 · 언제든 취소 · 7일 후 자동결제" — 1년 9,800원/월(33%↓·BEST) / 6개월 11,175원/월 / 1개월 14,900원/월 · 토스페이먼츠 카드등록 → 그 다음에야 계정 생성
- 로그인: 비밀번호 없는 **이메일 매직링크**.

## 3. 특장점 리스트 (카피 우선순위 순)

| # | 특장점 | 요지 |
|---|--------|------|
| 1 | **RIR 세트 타입 처방** | 웜업(6-5RIR)→탑(1/0RIR·4-7)→백오프(8-12) 구조로 "오늘 뭘 몇 kg 몇 회"까지 처방. 기록앱→코치앱의 결정적 차이 |
| 2 | **중량 추천 캐스케이드** | 직전 세트 실측 입력 → 다음 세트 권장 중량 즉시 재계산(소수점+반올림 안내). 체중·중량선호가 초기값 |
| 3 | **블록 주기화 내장** | N주+1주 디로딩이 홈 주차 스트립·훈련주기 설정·온보딩 교육에 일관 노출. Day1a/2a 표기 |
| 4 | **부위별 피로 관리 코칭** | 부위 퍼포먼스 감소 감지 → 세트 수 임시 감소+RIR 하향, 블록 종료 시 부진 부위 운동 교체 제안(수락/유지 선택) |
| 5 | **데이터 수집 기간의 기대치 관리** | "분석 중 n%" 진행바 + 7일 수집→8일 코칭 타임라인을 온보딩·FAQ·홈에서 반복 |
| 6 | **체지방 사진 캘리브레이션 온보딩** | %입력→구간별 실사 3장 탭 선택. 부정확한 자가측정을 시각으로 보정 |
| 7 | **루틴 파라미터 4노브** | 부위 강조(≤3·강도2단)·목적 슬라이더 5단·중량선호 5단(+변경 경고)·훈련주기 — 알고리즘 튜닝을 사용자 언어로 노출 |
| 8 | **콘셉트 루틴 카탈로그** | Bear Mode·뽀빠이·패션근육 등 "원하는 몸"으로 이름 붙인 프리셋 + 스토리 + 1주 GIF 프리뷰 + 저장/바로 사용 |
| 9 | **인워크아웃 마이크로 교육** | RIR/웜업 다페이지 가이드 모달, 운동별 편집 가능한 Tip + 쇼츠 링크, "속도 기반 RIR 판단" 같은 실전 카피 |
| 10 | **대체운동 = 무브먼트 패턴 그룹** | 운동 변경 시 같은 패턴 ~25종 GIF 제시 + 부위별 커스텀 슬롯. "머신이 없어요" 문제의 정답 UI |
| 11 | **세트 완료 마이크로 UX** | 완료행 readonly 잠금·재탭 해제·타입별 권장 휴식 자동 타이머·드래프트 자동보존·미완료 종료 확인 모달 |
| 12 | **선결제 퍼널** | 설문→프리뷰(스크롤 게이트)→교육→후기→7일 무료+카드등록을 가입 전에 배치. 연구·교육 콘텐츠가 페이월 설득 장치 |
| 13 | 경량 운영 | PWA(스토어 수수료 0)·매직링크 로그인·카카오 문의·유튜브 튜토리얼 — 1인/소규모 운영 최적화 |

**약점(우리 기회):** 소셜/친구 기능 전무, 유산소·스트레칭 없음, 분석 빈약(3종), 운동 이력 없는 상태에선 화면 대부분이 빈 깡통, 앱 성격상 락인이 구독에만 의존(데이터 이전 불가), 웹뷰 한계(오프라인·백그라운드 타이머 — 우리가 restAlarm으로 이미 푼 문제).

## 4. Liftgram 적용 방안 (기존 자산 매핑)

Hevy(자유 기록·소셜)와 RapidOverload(처방 코칭)는 상보적. Liftgram의 방향: **"기록은 Hevy처럼 자유롭게, 처방은 RapidOverload처럼 똑똑하게"** — 단 코칭 카피는 wellness.ts 가드레일(의료 단정 금지) 안에서.

| 카피 대상 | Liftgram 현황 | 적용 방안 | 규모 |
|---|---|---|---|
| ① RIR 세트 타입 처방 | `programGenerator.ts`(SRS-009)가 세트×반복만 생성, `progression.ts`(SRS-010)는 더블 프로그레션 | ProgramSlot에 `setType(warmup/top/backoff)`·`targetRir` 추가, 세션 UI(ExerciseBlock)에 타입 배지+RIR 라벨 렌더 | Feature |
| ② 중량 캐스케이드 | progression은 세션 간 제안만 | 세트 체크 시 다음 세트 placeholder 재계산(웜업 래더 % + 백오프 %) — 순수함수로 progression 확장 | Task~Feature |
| ③ 블록 주기화 | 없음 (streak만) | 루틴에 blockWeeks·deloadWeek 필드 + 홈 주차 스트립 + 디로딩 주엔 볼륨 스케일다운 | Feature |
| ④ 부위별 피로 관리 | `volume.ts`·`personalRecords.ts` 집계 있음 | 부위별 세션 퍼포먼스 추세(e1RM·볼륨) 감소 감지 → "세트 1개 줄임" 제안 카드(수락형·자동 아님 — 웰니스 가드레일상 '제안+근거 reasonKey' 패턴 재사용) | Feature |
| ⑤ 데이터 수집 기대치 관리 | 없음 | 신규 사용자 첫 N세션 "분석 중 %" 진행바 — 코칭 기능 출시 전에도 UX만 먼저 도입 가능 | Patch~Task |
| ⑥ 체지방 사진 온보딩 | onboarding feature 존재 | 구간별 체형 일러스트(실사 라이선스 부담 회피) 3장 탭 선택. 성별 분기 문항 수 변화 패턴도 | Task |
| ⑦ 루틴 4노브 | programGenerator 입력(goal·experience·daysPerWeek·equipment)과 부분 겹침 | 목적 슬라이더(5단)와 부위 강조(≤3)를 RoutineEditor에 노출, 강조는 볼륨 재배분 규칙으로 | Feature |
| ⑧ 콘셉트 루틴 | `routineRecommendation.ts` + 프리셋 | 프리셋에 콘셉트명·스토리·1주 프리뷰(우린 exerciseMedia GIF 보유) 부여. 한국 시장 감성 네이밍 | Task |
| ⑨ 마이크로 교육 | 없음 | RIR/웜업 가이드 모달(다페이지) — 콘텐츠는 §2.2 요약을 재작성. 운동별 팁은 exercises 카탈로그에 사용자 편집 노트 필드 | Task |
| ⑩ 패턴 대체운동 | `variants.ts`·`machineVariants.ts`·substitutes 이미 있음 | 교체 피커 UI를 "같은 패턴 전체 GIF 리스트+커스텀 슬롯"으로 승격 | Task |
| ⑪ 세트 완료 UX | ActiveWorkoutScreen+restAlarm.ts 있음 | 완료행 잠금·세트타입별 권장 휴식(우리 restAlarm은 이미 잠금화면 대응으로 우위)·미완료 종료 확인 | Patch~Task |
| ⑫ 선결제 퍼널 | 무료 앱 | 당장 카피 대상 아님. 단 "프리뷰 스크롤 게이트·교육 페이지" 패턴은 프리미엄(SRS-027 PREM) 설계 시 참고 |

**권장 순서(가치/의존성):** ①+② (코칭의 몸통, progression·programGenerator 확장) → ⑤+⑨ (UX·콘텐츠, 저비용 고인지) → ③ (블록) → ⑦ → ④ (데이터 축적 필요, 마지막) / ⑥⑧⑩⑪은 독립 Task로 병렬 가능.

## 5. 사업 모델 참고
- 구독: 1년 117,600원(9,800/월·33%↓) / 6개월 11,175/월 / 1개월 14,900/월 · 7일 무료체험(카드 선등록·자동전환) · 토스페이먼츠
- 무료 구간이 없음(체험 후 전면 유료) — 콘텐츠·알고리즘 신뢰로 정면 돌파하는 모델. Liftgram은 무료 기록+프리미엄 코칭 계층화가 차별 여지.

## 6. 탐색 커버리지·부기
- 커버: 홈(+블록 진행)·워크아웃 세션(가이드 2종·팁·세트 체크/해제·추가/삭제·완료 모달)·루틴 4탭+상세+에디터 4노브+Day편집+운동변경/추가·분석 3종(빈 상태)·설정(구독·FAQ 4종 전개)·온보딩 인트로 4장+설문 8문항+프리뷰+디로딩 교육+후기+페이월. 미커버: 실결제 이후 플로우, 코칭 발동 상태의 홈/분석(계정에 운동 이력 없음), 여성 분기 설문.
- 계정 상태 메모: 테스트 중 Day 1 스미스 머신 벤치 웜업 1행에 **미완료 드래프트(중량 0·횟수 6)**가 남음 — 체크 안 된 값이라 코칭 데이터에 미반영, 다음 운동 시 덮어쓰면 됨. 완료 처리한 세트는 즉시 해제해 0/18 상태 유지. 구독 "계속 이용하기"는 건드리지 않음(해지예정 유지).
