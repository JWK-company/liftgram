## 발견
| # | 심각도 | 근거 | 내용 | 반영 |
|---|---|---|---|---|
| Q1 | 높음 | `SetRowEdit.tsx:132,144,158,262` `String(fromKg(...))` | lb 표시가 `100.00000000000001` 같은 부동소수 꼬리를 그대로 보일 수 있다. 왕복 정확도는 저장이 아니라 **표시 한 곳**에서 지켜야 한다 | `displayWeight` 를 입력 칸·이전 기록·제안·편집 시트 전부에 |
| Q2 | 높음 | `units.ts:32` `formatWeight` lb 증분 1 | 세트 무게를 `formatWeight` 로 그리면 102.5lb → 「103lb」. PR 칩·이전 기록·기록 상세가 이 함수를 쓴다 | 세트 무게는 `formatEnteredWeight`(증분 반올림 없음), 합계만 `formatWeight` |
| Q3 | 중간 | `workoutRepository.ts:545,601,946` `getUserWeightUnit()` | 처방 원판 반올림이 프로필 단위를 본다 — 프로필 선택이 없어지면 칸 단위와 어긋난다 | 반올림 단위 = 블록 단위(시작 때는 줄마다 정한 시작 단위) |
| Q4 | 중간 | `setDrafts`·`onRoundToggle` (슈퍼셋 일괄 완료) | 다른 멤버의 미저장 입력을 kg 로 바꾸는 단위가 그 멤버 블록 단위여야 한다 | 각 `SetRowEdit` 이 자기 블록 단위로 kg 를 만들어 등록부에 넣는다(이미 kg 등록 — 블록 단위 prop 만 맞추면 됨) — 확인 테스트 |
| Q5 | 중간 | `GlobalWorkoutBar.tsx` 막대 전체가 `<a>` | 취소 버튼을 링크 안에 두면 누르는 순간 `/workout` 으로 간다(중첩 인터랙티브) | 링크와 **형제**로 버튼 — 컨테이너 `pointer-events-none` 이므로 버튼에 `pointer-events-auto` |
| Q6 | 중간 | Q4 B 오조작 | 완료 세트까지 숫자가 단위만 바뀌므로 잘못 누르면 볼륨이 2.2배 흔들린다 | 토글 직후 토스트 「무게 단위를 lb 로 바꿨어요 · 숫자는 그대로」 · 다시 누르면 정확히 원복(왕복 테스트) |
| Q7 | 낮음 | 기본 단위 유도가 「완료 블록」만 봄 | 토글만 하고 운동을 취소하면 기억이 안 남는다 | 의도된 동작(기록이 남아야 기억) — 스펙에 명시 |
| Q8 | 낮음 | `calcPlates` 는 kg 원판 고정 | lb 블록의 원판 계산이 kg 원판으로 나온다 | 이번 범위 밖(보류) — 표시 단위만 블록 단위 |
| Q9 | 낮음 | 옛 클라이언트(v24) push | 얕은 병합(`payload || EXCLUDED.payload`)이라 모르는 `weight_unit` 키를 지우지 않는다 | 조치 불필요 — 리스크 표에 근거 기록 |
