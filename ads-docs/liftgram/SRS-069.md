# SRS-069 — 화면 정리 P1 — 공용 시각 규칙(색 의미 2·글자 4단계·메타 줄·조용한 칩·접기)과 운동 블록 재배치(D1~D4)

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-069.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-023

### 요구 서술

앱 전체에 공통 시각 규칙을 둔다: 색 의미는 브랜드 빨강=행동·완료, 금색=PR 두 가지만 쓰고 나머지 메타는 무채색 글자로 표현한다. 글자 단계는 화면 안에서 4단계(title·heading·body·caption)로 제한하고, 칩 대신 「회색 메타 줄」과 「조용한 칩(무테·무채)」 조각을 공용 컴포넌트로 제공한다. 정보가 몰리는 곳에는 「한 줄 접기」 조각을 쓴다.

운동 블록은 이름 아래 회색 메타 줄(기록 칸 조합 — 누르면 칸 시트), 금색 PR 글자 한 줄(누르면 채우기, ⓘ 기록으로), 오른쪽 회색 볼륨 숫자로 머리를 재배치한다. kg/lb 는 세트 표 머리 「무게」 칸 안으로, 이전 기록 칸은 테두리 없는 회색 숫자로 바꾼다. 운동 방법·다른 조합·이전기록 지우기는 「더 보기」 한 줄로 접는다. 순서 화살표와 픽토그램의 겹침을 고친다.

### 수용 기준

- 360×640·390×844 운동 화면에서 첫 세트 체크 버튼 top ≤ 320px(360)·좌표 e2e.
- 블록 머리에 테두리 있는 칩 0개, 블록 안 브랜드 빨강 사용처는 완료 체크·「완료」 버튼만(계산 스타일 검사).
- PR 채우기·ⓘ 기록 이동·kg/lb 전환·칸 시트·다른 조합·이전기록 지우기·운동 방법이 모두 지금처럼 동작하고 기존 data-testid(pr-chip-*·unit-toggle·prev-slot·btn-other-slots·prev-clear·set-prev·variant-trigger)가 유지된다.
- 라이트·다크에서 금색 PR 글자와 회색 메타 글자 대비 ≥ 4.5:1, 누를 수 있는 글자 목표 높이 ≥ 32px.
