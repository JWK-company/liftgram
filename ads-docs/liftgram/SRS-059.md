# SRS-059 — 운동 완료 시 루틴 대비 변경점 계산·항목별 선택 반영 — 종목 교체·추가·삭제·세트 수·순서·슈퍼셋(변형 칸 제외)

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-059.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-019

### 요구 서술

루틴에서 시작한 운동을 완료하면, 시스템은 완료 세트가 1개 이상인 오늘의 운동과 그 루틴을 비교해 변경점 목록을 만든다. 변경 종류는 종목 교체(같은 자리의 종목이 바뀜)·종목 추가·종목 삭제·세트 수(완료한 워킹 세트 수 기준)·순서·슈퍼셋 묶음/해제이며, 무게·횟수·휴식·기록 칸 변형(그립·적재 방식·브랜드·부착물)은 변경으로 보지 않는다.

변경점이 하나라도 있으면 「바뀐 대로 루틴 바꾸기 / 새 루틴으로 저장 / 오늘만」을 묻고, 바꾸기를 고르면 항목별 체크(기본 전부 체크)로 고른 것만 루틴에 반영한다. 반영은 한 번의 로컬 쓰기 트랜잭션이며 동기 대상이다. 세트별 처방(prescription)이 있는 루틴은 바꾸기를 막는다. 운동 중 종목 교체 때 묻던 「이번만 / 루틴에도」는 없앤다.

### 수용 기준

- 바벨 벤치프레스→덤벨 벤치프레스 교체 + 케이블 플라이 2→3세트 운동에서 두 항목이 보이고, 플라이만 체크해 반영하면 루틴은 벤치 그대로·플라이 3세트가 된다.
- 그립·적재·브랜드·부착물만 바뀐 운동, 아무것도 바뀌지 않은 운동에서는 시트가 뜨지 않는다.
- 추가한 종목은 그 위치에, 삭제는 루틴에서 제거, 순서·슈퍼셋은 오늘 배치대로 반영되며 반영하지 않은 항목의 루틴 값은 그대로다.
- 세트별 처방이 있는 루틴은 바꾸기가 비활성이고 이유가 보인다. 루틴이 삭제된 운동은 빠른 운동처럼 다룬다.
- 변경점 계산은 순수 함수(도메인)로 단위 테스트한다.
