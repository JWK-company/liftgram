# ADR-037 — 플레이트 머신 한쪽 무게 입력 — 종목별 표시 플래그, 볼륨·PR 은 양쪽 합으로 계산

> 타입 ADR · 그룹 liftgram · ADStudio가 `ADR-037.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **informs** → SRS-058

### 맥락 (Context)

플레이트로드 머신은 한쪽에 끼운 원판으로 무게를 세는 것이 자연스럽지만, 볼륨은 양쪽 합이어야 한다. 원판 라벨을 따로 두는 방식은 입력 단계가 늘어난다(#53).

### 결정 (Decision)

- 적재 방식이 플레이트인 머신 종목에 「한쪽 무게로 입력」 플래그를 둔다(사용자 × 종목 선호, 한 번 켜면 유지).
- 켜져 있으면 입력·표시는 한쪽 무게, 저장은 원값 + 배수(2)를 함께 남기고, 볼륨·1RM·PR 비교는 계산 무게(×2)로 한다.
- 핀로드·프리웨이트에는 나타나지 않는다.

### 근거 / 대안

- 입력 단계 증가 없이 볼륨이 정확하다.
- 대안 항상 양쪽 합 입력(현행): 헬스장에서 머릿속 계산이 필요 — 기각(사용자 선택 A).

### 결과 (Consequences)

- 세트에 배수(또는 계산 무게) 저장이 필요하고, 통계·PR·피드 공유가 계산 무게를 쓰도록 맞춘다.
- 플래그를 나중에 바꿔도 과거 세트의 의미는 저장된 배수로 보존된다.

### 연결
