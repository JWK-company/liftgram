# DR-001 — 3D 스타일 운동 애니메이션 미디어 소싱 조사 (SRS-046 선행)

> 타입 DesignResearch · 그룹 liftgram · ADStudio가 `DR-001.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 조사 목적

SRS-046(운동 팁 미디어 UX)은 실사 영상이 아닌 RapidOverload식 3D 모델 스타일 움짤을 요구한다. 라이선스 구매 vs 자체 제작의 비용·품질·확장성을 비교해 소싱 방식을 결정한다. 대상 규모: 카탈로그 갭 이관(SRS-047) 포함 약 300종.

| --- | --- | --- | --- |

### 결론 (SAD·ADR 입력)

- **1안 채택 권장: GymVisual 대량 구매** — 300종 ≈ $270(10+ 단가 $0.90/GIF·팩 협상 시 추가 절감), N-CRFL 영구 라이선스로 자체 CDN 호스팅. 목표 룩앤필(3D 모델·근육 하이라이트)을 검증된 형태로 즉시 확보.
- 커버리지 갭(한국 특수 기구 등)은 종목별 확인 후 부재분만 개별 제작 보완(하이브리드).
- 에셋은 자체 스토리지/CDN에 호스팅(외부 API 핫링크 금지 — 오프라인·성능). 파일명·매핑은 exerciseMedia 규약(nameKo KEY)을 따른다.
- 구매 전 확인 체크리스트: ① N-CRFL의 앱 재배포 조항 원문 확인 ② 팩 협상 견적 ③ 갭 종목 대조표(SRS-047)와 GymVisual 카탈로그 매칭률.

### 게이트 검증 결과 (2026-07-26 추가 — ADR-029 구매 게이트 ① 실집행)

GymVisual N-CRFL 원문 확인 결과, **'재판매/재배포 금지'와 '재판매 목적 제품(물리·디지털)에의 사용 제한' 조항이 앱 임베드 허용 여부를 불명확하게 만든다**. 본 조사의 당초 전제('앱 임베드 허용')와 충돌 소지 — 구매 전 GymVisual support에 앱 번들 임베드 허용 여부 서면 확인이 필수다. 무료(Free) 항목의 라이선스도 별도 명시가 없다.

- 대안 후보(앱 상업 라이선스를 명시적으로 표방): Gym Animations(gym-animations.com — 7,000+ 애니메이션·커머셜 라이선스·평생 사용권, 무료 데모 샘플 제공) · MoveKit(movekit.com — 피트니스 앱용 3D 클립·상업권 포함).
- WorkoutX 무료 API(1,400+ GIF)는 월 500요청 제한·자체 호스팅 권리 불명 — 프로덕션 부적합 재확인.
- 앱 측 준비 완료: 3D 움짤 오버레이 파이프라인(exerciseMedia3d.data + ingest-3d-media.js + /media3d 자체 호스팅 + 무결성 테스트) — 라이선스 확보 즉시 에셋 폴더 반입만으로 전환.
- 후속: 사용자 결정 필요 — ⓐ GymVisual support 문의 후 구매 ⓑ Gym Animations/MoveKit 견적 비교 구매. 결정 시 ADR-029 갱신(또는 supersede).
