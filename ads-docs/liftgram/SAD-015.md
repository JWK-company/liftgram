# SAD-015 — 크레딧·월렛·P2P 정산 아키텍처 (이중기입 원장·에스크로·환전·결제 연계)

- **refs** → SRS-023

### 개요 (Summary)

크레딧 충전→소비(피드백·멘토링·번개)→파트너 현금 정산의 내부 경제를 이중기입 원장(double-entry ledger) 위에 구현한다. 충전은 웹 MoR(ADR-013/SAD-013)로 수금하고, P2P 거래는 에스크로로 보호하며, 파트너 정산은 트레이너 수익배분(SAD-013)의 글로벌 payout·세무 파이프라인을 재사용한다. 전자금융·세무 규제(ADR-022)를 준수하는 범위에서만 현금 환전을 개방한다.

### 컴포넌트 / 책임

- **CreditLedger: **모든 크레딧 이동을 이중기입으로 기록(불변·감사 가능), 잔액·거래내역 조회.
- **TopupService: **웹 MoR 결제→크레딧 발행(SAD-013 연계), 환불·복원 처리.
- **EscrowService: **일회성 피드백·멘토링 계약 크레딧을 홀드→이행 확인 시 해제, 분쟁 시 환불/중재.
- **MentorContract: **기간형 멘토-멘티 계약 상태·정산 근거(실제 사용 기반) 관리, 만료·갱신.
- **PayoutBridge: **파트너 인증(신원·계좌·세금양식) 확인 후 크레딧→현금 정산, SAD-013 글로벌 payout·원천징수 재사용.
- **AbuseGuard: **자전거래·머니세탁 패턴 탐지, 정산 한도·쿨다운, 규제 리포팅 훅.
