# UCS-016 — 사용자가 위치 기반으로 운동을 인증하고 등급·운동온도가 매겨진다

> 타입 UCS · 그룹 liftgram · ADStudio가 `UCS-016.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **elaborates** → URS-015

### 주 흐름

1. 사용자가 운동을 마치고 위치/기록 기반으로 '오운완' 인증을 남긴다(실제 세트·무게 데이터에 근거).
2. 수행능력·성실성(연속 인증·완주율) 지표로 등급이 산정·갱신되어 프로필에 표시된다.
3. 원하는 상대와 일정 기간 VS 챌린지를 개설·참여하고, 종료 시 검증 데이터로 판정된다.
4. 같이 운동한 사람끼리 매너를 평가해 운동온도 게이지가 갱신되고, 검증된 완주율·후기가 신뢰 이력으로 쌓인다.

### 대안 / 예외 흐름

- 위치 인증 위조·어뷰징 방지(중복·비정상 패턴 탐지), 인증 실패 시 무등급 기록으로 저장.
- 등급·운동온도는 웰니스 범위(수행·매너)로 한정하고 건강 진단성 평가는 하지 않는다(SRS-015).
- 평가 악용(보복 저평가) 방지: 상호·시간창 제한, 신고 반영.

### 사전 / 사후 조건

사전: 기록/만남 이력. 사후: 등급·운동온도·검증 이력이 프로필과 매칭 신뢰도(SRS-021/024)에 반영된다.
