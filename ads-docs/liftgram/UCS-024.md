# UCS-024 — 회원이 기간 성과 요약을 만들어 담당 트레이너에게 보내고, 트레이너가 열어 처방으로 이어간다

> 타입 UCS · 그룹 liftgram · ADStudio가 `UCS-024.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **elaborates** → URS-025

### 사전 조건

- 회원과 트레이너는 로그인했고 코칭 관계가 '코칭 중'이다(SRS-048).
- 회원에게 고른 기간 안 운동 기록이 하나 이상 있다.

### 주 흐름

1. 회원이 통계에서 「성과 요약」을 누른다.
2. 기간을 「4주」로 고른다. 미리보기에 운동 횟수·총 시간·총 볼륨, 직전 4주 대비 증감, 새 기록, 종목별 최고 세트 변화, 부위별 세트, 힘든 정도, 체중 변화가 나온다.
3. 「코치에게 보내기」를 누르고, 보낼 항목에서 '체중'을 끈다.
4. 받는 사람(담당 코치)을 확인하고 보낸다. 회원에게 '보냈어요'가 보인다.
5. 트레이너에게 알림이 오고, 코치와의 대화(또는 코칭 화면)에 요약 카드가 도착한다.
6. 트레이너가 카드를 열어 요약 전체를 보고, 「루틴 처방」을 눌러 그 회원 루틴 처방 화면으로 간다.

### 대안 / 예외 흐름

- 2a. 기간 안 기록이 없으면 미리보기 대신 '이 기간엔 운동 기록이 없어요'와 다른 기간 고르기가 보인다.
- 2b. 힘든 정도·체중 기록이 없으면 그 항목은 미리보기와 보낼 항목에 나오지 않는다.
- 3a. 담당 코치가 없으면 「코치에게 보내기」 대신 코칭 연결 안내가 보인다. 요약 보기는 그대로 된다.
- 3b. 코치가 여럿이면 받을 사람을 고른다.
- 4a. 오프라인이면 보내기 대기열에 넣고, 연결되면 보낸다. 대기 중임을 표시한다.
- 6a. 회원이 코칭을 해지한 뒤 트레이너가 카드를 열면 '코칭이 끝나 볼 수 없어요'가 보인다.

### 사후 조건

- 트레이너 쪽에 보낸 시점 내용으로 고정된 요약이 하나 남는다(이후 기록이 바뀌어도 그대로).
- 회원은 보낸 요약 목록에서 무엇을 언제 누구에게 보냈는지 볼 수 있다.
