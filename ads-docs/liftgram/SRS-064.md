# SRS-064 — 운동 총평 — 요약에서 입력 · 기록 상세에서 쓰기·고치기 · 캘린더 날짜 상세에 표시(나만 봄 · 피드 글과 별개)

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-064.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 요구 서술

운동 하나에 총평 한 개(여러 줄 글, 최대 2,000자)를 둔다. 저장 위치는 이미 동기되는 운동 레코드의 notes 칸(로컬 스키마에 있음, 지금 화면에서 쓰지 않음)을 재사용한다. 요약 화면 아래에 「오늘 총평」 입력란을 두고, 기록 상세에서 언제든 쓰거나 고친다.

캘린더에서 날짜를 누르면 그날 운동 줄 아래에 총평 앞부분이 보이고, 누르면 기록 상세로 간다. 기존 「날짜 메모」(운동 없는 날의 달력 메모)와는 다른 것이며 둘 다 유지한다. 총평은 피드 공유 글·공유 데이터에 싣지 않는다.

### 수용 기준

- 요약에서 쓴 총평이 기록 상세와 캘린더 날짜 상세에 보이고, 기록 상세에서 고치면 양쪽이 바뀐다.
- 피드에 공유한 글·공유 운동 데이터에 총평이 들어가지 않는다. 다른 기기에서 로그인하면 총평이 보인다(동기).
