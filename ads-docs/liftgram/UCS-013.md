# UCS-013 — 사용자가 조건으로 주변 헬스장을 찾고, 헬스장이 리드를 받아 응답한다

> 타입 UCS · 그룹 liftgram · ADStudio가 `UCS-013.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **elaborates** → URS-012

### 주 흐름

1. 사용자가 '헬스장 찾기'를 눌러 조건(반경 km·24시간·시설·가격대 등)을 입력해 게시한다.
2. 반경 내 등록 헬스장이 '주변 사용자가 헬스장을 찾고 있다'는 리드 알림을 받는다.
3. 후보 헬스장이 수수료(광고비) 비율에 따른 우선순위 + 신규 헬스장 노출 보장 규칙으로 랭킹되어 사용자에게 제시된다.
4. 헬스장이 프로모션/응답을 보내고, 사용자가 방문·문의로 전환한다. 운영자는 성과 지표를 확인한다.

### 대안 / 예외 흐름

- 반경 내 등록 헬스장이 없으면 반경을 확장하거나 '등록 요청' 리드로 공급 온보딩에 활용한다.
- 수수료 미납 헬스장도 신규 노출 보장·기본 노출 몫을 받아 마켓이 유료 순위만으로 왜곡되지 않게 한다.
- 위치 정보는 동의 기반으로 처리하고, 스팸/허위 리드를 필터링한다.

### 사전 / 사후 조건

사전: 헬스장 1개 이상 등록 + 사용자 위치 동의. 사후: 리드가 전달되고 매칭 결과·성과가 양측에 기록된다.
