# SRS-029 — 세트 로깅 정밀도 — 정자세/부분반복(깔짝) 구분 (볼륨·PR 제외)

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-029.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-016

### 요구 서술

시스템은 한 세트에서 **정자세(clean) 반복과, 실패 후 반동·보조로 추가한 부분반복(깔짝)을 구분해 기록**한다. 주 횟수 입력은 정자세 횟수이며, 부분반복은 세트 행 상세의 별도 필드로 입력한다. 총중량(volume)·추정 1RM·PR 검출은 정자세 횟수만으로 계산하고 부분반복은 제외해, 세트당 실제 완전가동 수행량을 왜곡 없이 남긴다(BS-002 #13). 이전기록·이력 화면에는 정자세와 부분반복을 구분해 '8+3'처럼 표시한다.

부분반복은 운동 **수행 중에만** 세트 행 상세(펼침)에서 입력하며(루틴 생성 단계에는 없음), 미입력 시 0으로 취급해 기존 기록과 무손실 호환된다. 편측(원암/투암) 등 그립·팔 변형은 SRS-028 소관으로, 본 요구는 세트 단위 정자세/부분반복 구분에 한정한다.

### 수용 기준

- 운동 수행 중 세트 행의 펼침 토글(▼/▲)로 여는 상세 패널에서 부분반복 `partial_reps`(깔짝)을 정자세 `reps`와 별도로 입력한다. 세트 행 본체에는 무게·횟수만 두어 좁은 화면에서 행이 꾸겨지지 않게 하며(인앱 피드백 #36 "세트별 정보가 많다보니 휴대폰에서 볼때 꾸겨져서 보임"), 부분반복 값이 있으면 접힌 상태에서도 토글이 점등되어 값의 존재를 알 수 있다.
- 총중량(volume)·추정 1RM·PR은 정자세 `reps`만으로 계산하고 부분반복은 제외한다(워밍업·실패 세트 제외 규칙과 병존).
- 이전기록·이력·피드에서 부분반복이 있으면 정자세와 구분해 표시된다(예: 20kg×8+3). 완료 요약 화면은 종목별 세트수·총중량·최고 추정 1RM만 집계하므로 세트별 표시 대상이 아니나, 피드 게시 payload에는 세트별 부분반복이 포함되어 전달된다.
- 부분반복 미입력(null/0) 레거시 세트는 볼륨·표시에 영향이 없다(무손실 하위호환).

### 설계 반영 (스키마 v9)

정밀도 필드는 세트 단위로 소유되며 `set_logs`에 optional 컬럼 `partial_reps`(number)를 추가한다(v9 마이그레이션, 기존 행 null). 볼륨·PR 순수 계산 계층(volume.ts effectiveReps=reps·effectiveWeightKg=유효무게, personalRecords.ts, oneRepMax.ts)은 정자세 reps만 사용하고 부분반복은 어떤 집계에도 들어가지 않는다. (구 v6 보조/가중 무게(load_adjust_kg)·정자세비중(strict_reps)은 폐기 — 컬럼은 하위호환 위해 잔존하나 볼륨/PR·UI에서 미사용.) 폐기된 보정무게의 대체 수단은 세트 단위 입력이 아니라 종목 단위 하중모드다 — v12 `load_mode` + `user_profiles.bodyweight_kg`로 유효무게를 파생하며 SRS-033 소관이다(ADR-026).

### 연결

도출 URS: URS-016(세트 로깅 정밀도·수행 조건 기록), URS-001(핵심 운동 기록). 설계: SAD-019(수행 기록 데이터 모델). 웰니스 가드레일: SRS-015 준수(정보·기록 보조이며 진단·처방 아님). 경계: 원암/투암 등 편측·그립·기구 변형은 SRS-028 소관.

### 개정 이력

2026-07-20 — 코드 감사 결과에 맞춰 부분반복 입력 위치와 표시 범위 서술을 정정했다. 수용 기준 1은 "정자세 reps 옆 부분반복 입력 컬럼(헤더와 정렬)"이라 규정했으나 실제 구현은 세트 행의 펼침 토글로 여는 상세 패널 안 입력이다(ExerciseBlock.tsx:575-600) — 인앱 피드백 #36(세트 행 과밀)에 대응해 의도적으로 옮긴 것이므로 구현이 아니라 요구 서술을 실측에 맞췄고, 값이 있으면 접힌 상태에서도 토글이 점등되어 인지 가능하다는 보완 조건을 함께 명시했다(:549-551). 수용 기준 3의 표시 지점에서 '요약'은 제외했다 — WorkoutSummaryScreen은 종목별 세트수·총중량·최고 추정 1RM만 집계하고 세트별 reps를 표시하지 않으며, 다만 피드 게시 payload에는 partialReps가 실려 전달된다(WorkoutSummaryScreen.tsx:151). 설계 반영 절에서는 v6 `strict_reps`·`load_adjust_kg` 폐기 서술은 그대로 두되, 폐기된 보정무게의 대체가 세트 단위 입력이 아니라 종목 단위 하중모드(v12 load_mode + 사용자 체중, SRS-033)임을 한 줄 덧붙이고 effectiveWeightKg 설명을 v12 유효무게 기준으로 갱신했다. 근거 결정은 ADR-026(ADR-025 대체)이다.
