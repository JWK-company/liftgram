### 핵심 지적

첫판은 스크립트를 줄 단위로 읽어 조각난 말·지나가는 언급을 다루지 못했고, 사람 검수용 우선순위(스크립트 > 설명란)를 자동 해석에 그대로 써서 깔끔한 설명란 숫자를 말 숫자가 덮을 수 있었다. 휴대폰에서는 설명란·스크립트 복사가 어렵다는 전제가 빠져 실패 문구가 막다른 길이었고, 유튜브를 오가는 사이 초안이 사라질 수 있었다. 서버는 키가 주소에 붙어 로그로 샐 수 있었고 할당량 방어가 사용자당 제한 하나뿐이었으며, API 로 받은 제목·채널을 루틴에 영구 저장하는 것은 YouTube API 정책(30일)과 맞지 않았다.
