# EXE-085 — SPEC-054 Phase 3 — 가져오기 화면 구현

> 타입 Execution · 그룹 liftgram/영상-루틴-가져오기 · ADStudio가 `EXE-085.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-054

### 요약

운동 탭에서 「영상·글로 루틴 가져오기」를 열어 링크·글·스크립트를 넣으면 core 해석기로 초안을 만들고, 줄마다 상태(자동·확인 필요·못 찾음)·근거 시각·「표기 없음」을 보여 주는 확인 화면에서 고친 뒤 내 루틴으로 저장한다. 하루짜리는 편집기로(replace), 여러 날은 목록으로 와서 「루틴 N개를 저장했어요」. 원문은 상태에만 두고, 새로고침 대비 초안은 정해진 칸만 sessionStorage 에 둔다.
