# EXE-086 — SPEC-054 Phase 4 — 영상 보며 받아 적기 구현

> 타입 Execution · 그룹 liftgram/영상-루틴-가져오기 · ADStudio가 `EXE-086.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-054

### 요약

확인 화면의 「영상 보며 받아 적기」(또는 줄의 ▶ m:ss)로 전체 화면을 열면 위에 YouTube 플레이어(youtube-nocookie + 공식 IFrame API, 이 화면에서만 지연 로드)가 붙고, 「+ 종목」을 누를 때마다 플레이어 시각이 남은 빈 줄이 생긴다. 종목은 나중에 그 줄을 눌러 고르거나 「누르면 바로 종목 고르기」로 즉시 고른다. 플레이어를 가리는 창을 열 땐 늘 멈췄다가 닫으면 다시 재생하고, 임베드가 안 되면(서버 embeddable=false · 오류 코드 · 8초 · 앱 껍데기) 새 창 링크와 시각 없는 줄로 대신한다.
