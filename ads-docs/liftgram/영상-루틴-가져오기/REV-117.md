### 핵심 지적

- **W2(배포 막음)** 줄 0개에서 뒤로 했는데 바로 아래가 같은 화면이면(묻힌 칸·새로고침 뒤 복원) `exitingRef` 가 true 로 굳어 가드·초안 보존이 조용히 꺼짐.
- **W1** 줄 0개에서 화면 안 링크로 떠나면 가드 칸이 묻혀 뒤로가 헛돎.
- **W3** 부분 저장 뒤 저장한 날을 지우면 남은 날 이름에서 「· N일차」가 빠짐 · 전부 저장 뒤 실패면 `days: []`.
- **Y1** 재생 중 선택 창·처방 시트가 플레이어를 가림(YouTube 정책) — 「잠깐 멈춤」을 끄거나 줄 이름을 누를 때.
- **Y2** 폭 356 미만에서 플레이어가 200×200 미만.
- **Y3** 방침이 「youtube-nocookie 를 불러온다」고만 써 www.youtube.com 스크립트·쿠키를 빠뜨림 · 설명란을 해석에도 씀 · 재생 가능 여부도 받음.
- **Y5·W12** 받아 적기 덮개에 dialog 역할·포커스 이동·Tab 가두기·Esc 없음 · 닫으면 포커스가 body 로.
- **Y4** 안드로이드 Capacitor 는 iframe 안 이동도 바깥 인텐트로 보낼 수 있음(실기기 확인 필요).
