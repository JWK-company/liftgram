# EXE-083 — SPEC-054 Phase 1 — 규칙 해석(core) 구현

> 타입 Execution · 그룹 liftgram/영상-루틴-가져오기 · ADStudio가 `EXE-083.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 요약

라이브 LLM 없이 링크·글·「스크립트 표시」 복사본을 루틴 초안으로 바꾸는 규칙 해석기를 core 에 만들었다(처방 패턴 표 · 종목 언급 · 앞뒤 창 묶기 · 칸별 신뢰도 · 「언급만」 · 같은 종목 합치기). 코드 리뷰 REV-114 의 채택 17건을 반영했다. 평가 합격선은 리뷰대로 공정하게 바꿨고, 새 합격선에는 아직 못 미친다 — 정답이 프로그램 일부만 담은 루틴 2개를 빼면 기준선 바로 근처다(아래).
