### 핵심 지적

- **P1(H)** 초안 키 `liftgram.importDraft` 가 앱 기록 가져오기(`src/frontend/app/components/sync/ImportFlow.tsx:65`)와 같아, 루틴 가져오기 화면을 열면 CSV 맞추기 결정이 조용히 지워짐.
- **P2(H)** 이용약관에 「YouTube 서비스 약관에 동의」 조항이 없음(개발자 정책 III.A.1).
- **P3·P4(M→H)** 방침이 「저장하지 않음」이라 쓰지만 서버는 24시간 메모리 캐시·실패 로그에 영상 id · 해석한 종목은 루틴으로 저장·동기 · 시행일이 11-05 그대로.
- **U1(M)** 저장·나가기 뒤 가드 칸을 걷지 않고 replace → 뒤로 가면 빈 가져오기 화면으로 돌아옴(스펙 「replace」 위반).
- **U2(M)** 줄 0↔1 이 바뀔 때 가드 칸을 걷고 쌓다가 back 뒤 push 경합으로 엉뚱한 「가져오기를 멈출까요?」.
- **U3(M)** 언급만 된 종목을 더하면 `status` 를 무조건 auto 로 → 「확인 필요」·저장 확인창이 건너뛰어짐.
- **U4(M)** 여러 날 저장이 중간에 실패하면 다시 저장할 때 앞 날이 중복.
- **U12·U13(M)** e2e 의 `/\/routines\/[^/]+$/` 가 `/routines/import` 와도 맞음 · 확인창을 `isVisible()` 로 기다리지 않고 판정.
- **P9(M)** 강조색이 저장 하나가 아니라 붙여넣기·이어서·받아 적기·원본 영상·「종목 고르기」 줄 이름(빨강 = 오류처럼 읽힘)·+ 종목 더하기에.
- **P10(M)** 칩 묶음 id 에 공백(`ir-횟수 · 최소`) → aria-labelledby 가 깨져 묶음 이름이 사라짐.
