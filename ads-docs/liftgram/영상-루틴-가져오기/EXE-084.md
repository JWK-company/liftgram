# EXE-084 — SPEC-054 Phase 2 — 영상 정보 API(backend) 구현

> 타입 Execution · 그룹 liftgram/영상-루틴-가져오기 · ADStudio가 `EXE-084.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-054

### 요약

공식 YouTube Data API `videos.list`(snippet·contentDetails·status) 하나만 부르는 `VideoService.DescribeVideo` 를 만들었다. 로그인 필요 · 사용자 분 6/하루 50 · IP 하루 100 · 서버 하루 8,000 · 할당량 소진은 태평양시 자정까지, 분당 한도는 1분, 키 거절은 10분 멈춤 · 같은 id 동시 호출은 한 번 · 메모리 캐시(있음 24시간 · 없음 10분). 키는 헤더로만, 설명란은 응답으로만 보낸다. 코드 리뷰 REV-115 의 채택 16건을 반영했다.
