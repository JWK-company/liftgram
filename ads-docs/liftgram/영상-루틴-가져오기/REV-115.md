### 핵심 지적

- **G1(H)** 운영 이미지(alpine)에 시간대 자료가 없어 태평양시가 PST 고정 — 서머타임 동안 하루 경계가 1시간 어긋나 서버 예산 상한이 보장되지 않음.
- **G2=S1(M, 배포 전)** `RATE_LIMIT_EXCEEDED`(분당 한도에도 옴)를 하루 할당량으로 보아 최대 24시간 멈춤.
- **S2(M)** `forbidden` 사유로 서버 전체 10분 정지 — 영상 단위 사유일 수 있어 한 사람이 기능을 계속 끌 수 있음.
- **S4(L, 배포 전)** 리다이렉트를 따라가면 직접 단 키 헤더가 다른 호스트로 복사됨(실측).
- **G3=S5(M)** 정지·예산 끝인데도 사용자 횟수를 먼저 깎음 · 분 통과 뒤 하루 거절이면 분만 깎임.
- **S3(M)** 매번 새 id 로 여러 계정이 서버 하루 예산을 바닥낼 수 있음.
- **G4·G5·G8·G9·G13(M/L)** 하루 제한·정지 길이·DST·singleflight·크기 상한·KR 허용·예산 증가·LRU 를 테스트가 증명하지 못함.
- **G6·G7·G10·G11·G14(L)** 404 미캐시 · 키 거절 사유 누락 · ISO 주(W) 꼴 · int32 넘침 · 시간 초과 꼬리표.
