# ADR-065 — 그룹 챌린지 벌칙은 돈 없이 — 만회 운동·벌칙 기록·면제권, 최종 판정은 서버 시각과 멤버 이의

> 타입 ADR · 그룹 liftgram/plan · ADStudio가 `ADR-065.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **informs** → SAD-027, SRS-119, SRS-120

### 맥락

처음 안은 앱이 참가비를 걷어 두었다가 목표가 끝나면 나눠 주고 수수료를 받는 것이었다. 남의 돈을 맡았다가 돌려주는 구조라 유사수신·전자금융·사행성 판단이 걸린다. 또 인증 사진만으로 출석을 판정하면 속이기 쉽다.

### 결정

- 앱은 돈을 받지도, 맡지도, 나눠 주지도 않는다. 벌칙은 (1) 다음 날 2배 세트로 만회, (2) 그룹이 정한 벌칙을 앱 밖에서 이행하고 앱은 기록만, (3) 주 1회 면제권이다.
- 출석 판정은 서버 시각 기준이다: 지시를 받은 시각과 사진을 받은 시각을 서버가 기록하고, 운동 기록의 시작·끝과 비교한다. 기기 시각은 믿지 않는다.
- 최종 판정은 사람이 한다: 멤버 과반 이의가 자동 판정을 뒤집는다. 나중에 AI 판별을 붙여도 표시만 하고 막지는 않는다.
- 사진은 갤러리에서 고를 수 없다. 앱 카메라로만 찍는다.

### 대안

| 대안 | 버린 까닭 |
| --- | --- |
| 예치금·분배(처음 안) | 법적 위험, 보류 |
| 앱 포인트 벌점 | 돈처럼 보이면 같은 질문이 생긴다. 쓸 곳도 없다 |
| AI 판별로 자동 거부 | 오판하면 억울한 벌칙이 생긴다. GPU는 공유 자원이다 |
| 위치(GPS) 필수 | 홈트 그룹을 배제한다. 위치 권한 부담과 GPS 조작 가능성이 있다 |

### 결과

- 법적 위험 없이 바로 내놓을 수 있다
- 운동 기록·사진을 속이는 비용은 높아지지만 0이 되지는 않는다(가족이나 친구 계정으로 대신 찍기 등). 남는 위험은 친구 그룹이라는 사회적 관계로 감수한다
- 2명 그룹은 상대 한 명의 이의로 무효가 된다. 작은 그룹의 갈등 위험이 있다(SPEC 위험에 적음)
