# BS-009 — 영상·글로 내 루틴 한 번에 만들기 — 유튜브와 앱 왕복 없애기

> 타입 BS · 그룹 liftgram/plan · ADStudio가 `BS-009.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 문제

앱에 넣어 둔 영상 루틴만으로는 모든 사용자의 수요를 채울 수 없다. 사용자가 유튜브에서 본 루틴(예: 크리스 범스테드의 가슴 운동 영상)을 내 루틴으로 만들려면 지금은 (1) 영상을 넘기며 종목·세트 설명 부분을 찾고 (2) 유튜브와 앱을 여러 번 오가며 루틴을 입력해야 한다. 기억에 기대는 왕복이라 번거롭고 자주 틀린다.

### 아이디어

- **붙여 넣으면 초안 루틴**: 유튜브 링크·글(인스타 캡션·블로그·메모)·유튜브 「스크립트 표시」에서 복사한 글을 넣으면 앱 안의 규칙 해석기가 종목·세트·횟수·휴식을 뽑아 초안을 만든다. 줄마다 「확실/확인 필요/못 찾음」과 그 장면부터 보는 영상 링크.
- **영상 보며 받아 적기**: 앱 안 공식 유튜브 플레이어 아래 루틴 칸 — 「+ 종목」을 누르면 지금 영상 시각이 함께 저장된다. 자동이 실패해도 왕복이 없다.
- (다음 판) 유튜브 앱 「공유 → 리프트그램」, 같은 영상으로 만든 루틴 나눠 보기(동의한 것만).

### 제약

- **라이브 LLM 을 쓰지 않는다**(운영비) — 해석은 `core` 의 규칙 코드만.
- 우리 서버는 자막·음성을 긁지 않는다(유튜브 약관 · 서버 차단 위험). 스크립트는 사용자가 직접 붙여 넣은 글만 처리하고 원문은 저장하지 않는다 — ADR-063.
- 영상 메타데이터는 공식 Data API(`videos.list`, 1회 1단위) — 영상 단위 캐시.

### 기대 효과

- 영상 하나로 루틴 만들기 시간을 크게 줄인다(왕복·기억 부담 제거).
- 손으로 다듬은 영상 루틴 150개가 해석기 정답 시험 데이터가 된다(같은 작업에서 스크립트로 보완 — 2026-11-10).
