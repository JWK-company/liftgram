# SRS-118 — 그룹 챌린지 — 만들기·규칙·초대 링크·참가·나가기·시작/취소

> 타입 SRS · 그룹 liftgram/plan · ADStudio가 `SRS-118.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-035

### 기능

- 만들기: 이름(1~30자), 시작일(내일~30일 뒤), 기간(1~8주), 목표(매일 / 요일 비트), 최소 세트(1~30, 기본 5), 인증 방식(gym / any_photo / record), 벌칙 글(0~60자), 면제권(주 0 또는 1회).
- 초대 링크: `/challenges/join/<토큰>`. 토큰은 128비트 난수이고 방장이 다시 만들 수 있다(옛 링크 무효). 목록 검색·공개 노출은 없다.
- 참가: 모집 중(시작 전)에만, 정원 10명, 차단 관계면 거부, 이미 멤버면 그대로.
- 규칙 고치기: 시작 전에 방장만. 고치면 멤버에게 바뀐 점을 보인다.
- 시작: 시작일 04:00 KST. 멤버가 2명 미만이면 취소하고 알린다.
- 나가기: 언제든 가능. 진행 중이면 다음 날부터 판정하지 않는다. 방장이 나가면 가장 먼저 들어온 멤버가 방장이 된다.
- 방장은 시작 전 멤버 내보내기만 할 수 있다(진행 중에는 못 함 — 벌칙 회피·괴롭힘 방지).
