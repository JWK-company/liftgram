### 흐름

1. 운동 중 「인증 사진」 → IssuePrompt(challenge_id, workout_id) → 지시·번호(3분 유효)
2. 카메라로 찍기 → 기기에서 1280px JPEG, EXIF 없음 → UploadProof(번호, 사진 바이트, source) → 서버가 번호 검사, dHash, 중복 검사, 비공개 저장, proof 행(pending_workout)
3. 운동이 완료로 동기되면 판정 루프가 그날을 계산한다. 하루 끝 + 12시간에 판정하고, 만회 기간이 끝나면 확정한다.
4. 이의 → 과반이면 proof invalid → 그날을 다시 판정한다.

### 판정 루프

서버 안 고루틴이 10분마다 돈다(media RescanLoop와 같은 방식). 진행 중인 챌린지의 판정할 날을 찾아 `challenge_days`를 upsert한다(멱등). 21시 미완료 알림은 (챌린지, 사용자, 날) 키로 한 번만 보낸다. 끝난 지 30일이 지난 사진 지우기는 하루에 한 번 돈다. 서버가 여러 대여도 겹치지 않게 트랜잭션 안에서 pg_try_advisory_xact_lock을 잡는다.
