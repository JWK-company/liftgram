# SRS-119 — 그룹 챌린지 — 인증 사진(앱 카메라만·운동 중·오늘의 지시·중복 검사)

> 타입 SRS · 그룹 liftgram/plan · ADStudio가 `SRS-119.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-035

### 기능

- 카메라: 화면 안에서 실시간 카메라(getUserMedia)를 열고 셔터로 찍는다. 파일 입력·갤러리 고르기를 두지 않는다. 앱(안드로이드·iOS 웹뷰)은 카메라 권한이 필요하다.
- 오늘의 지시: 「인증 사진」을 누르면 서버가 지시 하나(손 모양·기구 종류·방향 — 고정 목록에서 무작위)와 일회용 번호를 준다. 카메라 위에 지시가 보인다. 3분 안에 올려야 하고, 지난 지시는 다시 못 쓴다.
- 운동에 붙이기: 진행 중인 운동이 없으면 버튼이 꺼져 있다(「운동을 시작하면 찍을 수 있어요」). 사진에는 그 운동 id가 붙는다. 인정은 그 운동이 완료로 동기된 뒤 판정한다.
- 줄이기: 기기에서 긴 변 1280px JPEG로 줄여 올린다. 위치 정보(EXIF)는 지운다.
- 중복 검사: 서버가 64비트 dHash를 계산해 같은 사용자의 지난 인증과 같은 그룹 인증에 비교한다.
- 하루에 인증은 여러 장 가능하다(마지막 인정된 것 하나가 대표).

### REV-159 반영 (스펙 리뷰)

- 서버가 디코드한 이미지를 JPEG(품질 80, 긴 변 ≤1280)로 다시 인코딩해 저장한다. 기기 쪽 줄이기는 전송량을 줄이려는 것일 뿐이다.
- 지시를 낼 때 그 운동이 서버에 없어도 된다(동기 지연). workout_id만 기록하고, 판정할 때 대조한다.
- 중복 거부 문턱(기본 4)은 실제 사진으로 재서 정한다. 같은 헬스장 친구 사진은 거부하지 않고 표시만 한다.
- `source` app/web은 참고 표시이고 판정에는 쓰지 않는다. 실제로 막는 장치는 지시 손 모양과 멤버 확인이다.
