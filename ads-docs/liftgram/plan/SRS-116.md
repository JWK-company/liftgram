# SRS-116 — 영상·글에서 루틴 가져오기 — 규칙 해석 초안 + 영상 보며 받아 적기

> 타입 SRS · 그룹 liftgram/plan · ADStudio가 `SRS-116.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-033

### 기능

1. **입력**: 유튜브 링크 · 붙여 넣은 글 · 유튜브 「스크립트 표시」에서 복사한 글(시각 포함). 링크면 서버가 공식 Data API 로 제목·채널·설명란·챕터를 읽는다(영상 단위 캐시).
2. **해석(규칙만)**: 종목 = 카탈로그 이름·별칭(한·영)·오타 허용 맞추기 · 세트×횟수 패턴(`4x8-10` · `4 sets of 10` · `3세트 12회` · RPE/RIR · 휴식 · 슈퍼세트 `SS`/`A1·A2` · 드롭세트) · 시각(챕터·스크립트) → 줄마다 근거 시각.
3. **확인 화면**: 줄마다 상태와 「그 장면부터 보기」 · 못 찾은 줄은 종목 선택 창(검색어 채움) · 세트 미기재는 「영상에 표기 없음 — 기본 3×10」처럼 표시 · 줄 지우기·순서 바꾸기.
4. **영상 보며 받아 적기**: 앱 안 공식 임베드 플레이어 + 루틴 칸 · 「+ 종목」= 지금 시각 저장 · 세트 칩 · 해석 결과가 있으면 미리 채움.
5. **저장**: 내 루틴(기존 루틴 편집으로 이어짐) · 출처 영상 링크·제목·채널 인용.

### 하지 않는 것

- 라이브 LLM · 서버의 자막·음성 수집 · 스크립트 원문 저장(해석 결과·링크만).
- 유튜브 앱 공유 받기 · 다른 사용자에게 공유(다음 판).
