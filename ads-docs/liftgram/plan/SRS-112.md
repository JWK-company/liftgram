# SRS-112 — 운동 팁 — 스트레칭·워밍업·자세·부상 예방·회복 팁을 영상 출처와 함께 모으고, 종목 상세·운동 시작 전에 다시 보여 준다

> 타입 SRS · 그룹 liftgram/plan · ADStudio가 `SRS-112.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-028

### 요구 서술

루틴이 아닌 운동 지식(스트레칭·가동성, 워밍업, 자세 교정, 부상 예방, 회복·휴식)을 「운동 팁」으로 모은다. 팁 하나 = 유튜브 영상 하나에서 운영자가 정리한 우리 말 요점(2~5줄)과 주의 한 줄(있으면), 관련 부위·종목, 출처(영상 id·영상 제목·채널명·채널 주소·확인 날짜)다. 크리에이터 루틴(SRS-091)과 같은 표기 규칙을 따른다 — 출처는 「출처: {채널} · 「{영상 제목}」」 인용으로만, 사람 이름을 팁 제목에 넣지 않는다.

원본 영상은 루틴처럼 링크(유튜브 공식 주소 · 새 창)로 연다. 설명란에 챕터(타임스탬프)가 있으면 챕터 이름을 우리 말로 옮겨 그 시각으로 바로 여는 링크를 함께 둔다. 대본·썸네일·캡처는 넣지 않는다.

팁은 세 곳에서 보인다: ① 운동 탭의 「운동 팁」 구역(주제 → 팁 목록 → 팁 상세) ② 종목 상세의 「자세 설명」 아래 「관련 팁」(그 종목을 지목한 팁 먼저, 다음은 주동근이 겹치는 팁, 최대 3개) ③ 루틴 미리보기의 「시작 버튼」 위 「시작 전」 한 줄(그 루틴 부위에 맞는 운동 전 팁 하나 — 누르면 팁 상세).

### 수용 기준

- 운동 탭에서 초보자 루틴 다음에 「운동 팁」 구역이 있고, 주제 5개(스트레칭·가동성 / 워밍업 / 자세 교정 / 부상 예방 / 회복·휴식)가 팁 수와 함께 보인다. 팁이 0개인 주제는 숨긴다.
- 첫판 팁 ≥20개, 주제마다 서로 다른 채널 ≥2.
- 팁 상세에 요점·주의·관련 부위·출처 인용·「영상 설명란 기준 정리 · 확인 {날짜}」·「원본 영상 보기」(https://www.youtube.com/watch?v=… 새 창)·안전 고지(통증·저림이 있으면 멈추고 전문가와 상담)·제휴 아님 고지가 있다. 챕터가 있으면 「mm:ss 챕터 이름」 링크가 `&t={초}s` 로 열린다.
- 종목 상세에 관련 팁이 있으면 「관련 팁」 카드(최대 3개)가 보이고, 없으면 카드가 없다.
- 루틴 미리보기에 그 루틴 부위에 맞는 「운동 전」 팁이 있으면 「시작 전」 한 줄이 시작 버튼 위에 보이고, 누르면 팁 상세가 열린다.
- 데이터 테스트: 팁 id 유일 · 영상 id 형식 · 출처 필드 · 관련 종목이 활성 카탈로그에 있음 · 부위가 근육 그룹 값 · 챕터 초가 오름차순 · 문구에 단정·보장·의학적 표현 없음(웰니스 게이트).
- 점검 스크립트가 팁 영상도 oEmbed 로 확인한다 — 코드·스크립트에 영상·자막 다운로드 경로가 없다(SRS-092).

### 연결
