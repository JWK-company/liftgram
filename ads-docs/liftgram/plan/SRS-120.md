# SRS-120 — 그룹 챌린지 — 하루 판정·만회·면제권·벌칙 기록·이의·알림

> 타입 SRS · 그룹 liftgram/plan · ADStudio가 `SRS-120.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-035

### 기능

- 하루 상태: 예정 → 완료 / 면제 / 빠짐(만회 가능) → 만회 / 빠짐 확정. 쉬는 요일은 「쉼」.
- 인정 조건: `sync_records`의 workouts 중 state completed·source null·시작 시각이 그날, 그 운동의 완료 세트(set_logs) ≥ 최소 세트, 사진 방식이면 그 운동에 붙은 유효 인증(무효·거부 아님).
- 만회: 빠진 날 D의 다음 날 D+1에 한 운동에서 최소 세트 × 2 이상을 채우면 D는 「만회」, D+1은 「완료」. D+1이 쉬는 요일이어도 만회할 수 있다.
- 면제권: 그 챌린지 주(시작일부터 7일 단위)마다 1번. 빠짐이 나오면 자동으로 쓴다.
- 벌칙: 빠짐이 확정되면 그 사람에게 벌칙 1개(그룹이 정한 글). 이행 체크·취소는 본인과 방장.
- 이의: 멤버마다 한 인증에 한 번. 과반 = floor(다른 활성 멤버 수 / 2) + 1. 무효가 되면 그날을 다시 판정한다(확정된 날이면 벌칙도 고친다).
- 알림: 21시 KST에 그날 해야 하는데 아직 안 한 멤버 · 빠짐(만회 안내) · 이의로 무효 · 챌린지 끝(결과).
- 판정은 서버가 10분마다 돌리고, 같은 날을 다시 돌려도 결과가 같다(멱등).

### REV-159 반영 (스펙 리뷰)

- 21시 미완료 알림은 앱 안 알림 목록에 쌓인다. 앱 푸시는 아직 없으므로 화면 문구도 「알림 목록에 보여요」로 쓴다(푸시는 별도 범위).
- 상태 전이는 한 방향이다: missed_open → made_up / pass / missed. done은 이의 무효일 때만 다시 판정한다.
- 취소 알림(CHALLENGE_CANCELLED)을 더한다. 시작할 때 2명 미만이면 보낸다.
