# SRS-121 — 그룹 챌린지 — 인증 사진 공개 범위·보관·신고

> 타입 SRS · 그룹 liftgram/plan · ADStudio가 `SRS-121.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-035

### 기능

- 읽기: 사진은 멤버 확인 뒤 따로 내 주는 주소로만 보인다(공개 미디어 저장 경로와 분리).
- 보관: 끝난 지 30일이 지나면 지우는 작업이 매일 돈다.
- 찍을 때 안내: 「다른 사람 얼굴이 나오지 않게 찍어 주세요」.
- 신고: 기존 신고(moderation)에 인증 사진 대상을 더한다.

### REV-159 반영 (스펙 리뷰)

- 삭제 시험은 DB 칸뿐 아니라 저장소 파일이 실제로 사라졌는지 확인한다.
- 비로그인 초대 요약에는 멤버 수만 보이고 이름은 보이지 않는다.
