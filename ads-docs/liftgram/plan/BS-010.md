# BS-010 — 그룹 운동 챌린지와 벌칙 — 기구 사진 인증으로 출석 속이기 막기

> 타입 BS · 그룹 liftgram/plan · ADStudio가 `BS-010.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 문제

혼자 하는 운동은 의지에만 기대서 2~3주면 끊기기 쉽다. 사용자 피드백 가운데 「친구들과 그룹을 만들어 같이 목표를 세우고, 못 나간 사람에게 벌칙을 주자」는 의견이 있었다. 처음 안은 앱이 참가비를 걷어 맡아 두었다가 목표가 끝나면 나눠 주고 수수료를 받는 방식이었다. 남의 돈을 받아 두었다가 다시 나눠 주는 구조라 법적 위험이 있어 **돈은 보류**하고, 돈 없이 그룹 운동과 벌칙만 먼저 만든다.

**출석 속이기**도 막아야 한다. 알람을 끄려면 집 안 사진을 찍어야 하는 알람 앱처럼, 헬스장 기구 사진을 찍어야 그날 운동으로 인정한다.

### 아이디어

#### 1. 그룹 챌린지

- **그룹**: 2~10명이 초대 링크로 모인다. 기존 피드·DM·알림을 그대로 쓴다.
- **규칙**: 기간(1~8주), 목표(매일, 주 N회, 지정 요일), 하루를 나누는 시각(기본 새벽 4시 — 밤늦게 한 운동도 그날로), 인정 조건(운동 기록 최소 N세트 또는 M분 + 인증 사진)을 정한다.
- **그룹 화면**: 날짜×멤버 출석표, 오늘 아직 안 한 사람, 연속 일수, 벌칙 현황을 보여 준다. 마감이 다가오면 「오늘 아직 안 했어요」 알림을 보낸다.
- **끝**: 결과 카드(달성률·MVP)를 피드에 공유한다. 같은 멤버로 다시 시작할 수 있다.

#### 2. 벌칙 (돈 없이)

| 안 | 방식 | 평가 |
| --- | --- | --- |
| **보충 운동** (추천) | 빠진 날 다음 날까지 보충 세트(예: 그날 목표의 1.5배)를 하면 「만회」로 표시된다. 하지 않으면 「빠짐」이 확정된다 | 운동 앱의 목적과 맞다. 벌칙이 곧 운동이 된다 |
| **그룹이 정하는 벌칙** (추천) | 시작할 때 그룹이 정한다(예: 「빠지면 커피 쏘기」). 이행은 앱 밖에서 하고, 앱은 누가 몇 번 빚졌는지 기록하고 「이행함」을 체크한다 | 재미와 사회적 압박이 있다. 돈이 앱을 거치지 않는다 |
| **면제권** (추천) | 주마다 1번 쓸 수 있는 패스(아픔·출장) | 첫 결석 뒤 포기해 버리는 이탈을 줄인다. 엄격한 규칙만 두면 오히려 빨리 깨진다 |
| 사회적 표시 | 출석표에 빨간 칸이 남는다 | 따로 만들 것 없이 기본으로 들어간다 |
| 앱 포인트 | 벌점이나 보증 포인트(환전 불가) | 보류: 돈처럼 보이면 같은 법적 질문이 다시 생긴다 |

#### 3. 인증 사진 — 속이기 막기

**기구 사진 한 장만으로는 약하다.** 옛 사진을 다시 쓰거나, 인터넷 그림을 화면에 띄워 찍거나, 집에 있는 덤벨을 찍을 수 있다. 그래서 여러 겹으로 막는다.

| 겹 | 무엇 | 막는 것 | 단계 |
| --- | --- | --- | --- |
| 앱 카메라만 | 갤러리 고르기 금지. 찍은 시각은 서버가 기록한다 | 옛 사진, 내려받은 그림 | MVP |
| 운동 중에만 | 진행 중인 운동(시작~마치기) 안에서만 찍을 수 있다. 사진이 그 운동 기록에 붙는다 | 사진만 찍고 운동은 안 함 | MVP |
| 오늘의 지시 | 찍을 때마다 무작위 지시를 준다(예: 「손가락 두 개 펴고 기구와 함께」, 「케이블 머신」). 알람 앱 방식이다 | 미리 찍어 둔 사진, 화면 촬영 | MVP |
| 중복 검사 | 내 지난 사진과 그룹 사진의 지각 해시를 비교한다 | 같은 사진 재사용 | MVP |
| 멤버 이의 | 멤버가 「의심」을 누르고 과반이 동의하면 그날을 무효로 한다 | 나머지 전부(사람이 마지막 판정) | MVP |
| AI 기구 판별 | 헬스장 기구가 찍혔는지 점수로 매기고, 낮으면 「확인 필요」로 표시한다(막지는 않음) | 엉뚱한 사진 | 2단계 (GPU는 동업자와 공유라 CPU 소형 모델부터) |
| 위치 | 등록한 헬스장 반경 안인지 본다(근처 헬스장 찾기 자료를 재사용) | 집에서 찍기 | 2단계·선택 (위치 권한 부담, 홈트 그룹은 끔) |

- **홈트 그룹**: 그룹이 인증 방식을 고른다(헬스장 기구 / 아무 운동 사진 / 기록만).
- **개인정보**: 헬스장 사진에는 남의 얼굴이 찍힐 수 있다. 사진은 그룹 멤버만 보고, 챌린지가 끝나고 30일 뒤 자동으로 지운다. 얼굴 가리기 안내를 하고, 기존 신고·숨김 흐름을 그대로 쓴다.
- **웹**: 웹 카메라는 가상 카메라로 속일 수 있다. 웹에서도 찍을 수는 있게 하되 「웹 인증」으로 표시한다. 마지막 판정은 멤버 이의로 한다.

#### 4. 돈 — 보류하되 나중에 열 길

- 앱이 돈을 받아 두었다가 나눠 주는 구조는 법률 검토 전까지 하지 않는다(유사수신, 전자금융, 사행성 판단이 걸린다).
- 다시 검토할 때 볼 길: 벌칙금을 앱 밖에서 주고받고 앱은 기록만 하기, 기부형(빠진 돈은 기부처로 — PG 기부 결제), 앱이 내는 경품형 보상(달성자에게 쿠폰 — 이달의 리프터 쿠폰 흐름과 같은 모양).

### 제약

- 오프라인 우선 앱이다. 출석 판정은 서버 시각으로 하고, 기기에서 찍은 사진은 올라갈 때까지 「올리는 중」으로 둔다(마감 직전에 오프라인으로 찍은 것도 찍은 시각으로 인정).
- 기존 피드·DM·알림·신고(moderation)·미디어 업로드·근처 헬스장(src/backend/internal/gyms/handler.go)을 다시 쓴다.
- 앱(Capacitor) 카메라와 웹 카메라를 둘 다 지원해야 한다. 갤러리를 막는 것은 앱에서 더 확실하다.
- GPU는 동업자와 공유한다. AI 판별은 묻고 쓰거나 CPU 모델로 한다.

### 기대 효과

- 그룹 멤버의 30일 유지율이 혼자 쓰는 사용자보다 높아진다(측정: 그룹 참가자와 비참가자의 D30 비교).
- 초대 링크로 신규 가입이 는다(그룹마다 평균 초대 수).
- 챌린지 완주율과 「만회」 비율로 벌칙 설계가 맞는지 확인한다.

### 결정 (2026-11-13 · 사용자 메시지 3165 「권장대로 진행」)

- 벌칙: **보충 운동(만회) + 그룹이 정하는 벌칙 기록 + 주 1회 면제권**. 출석표의 빨간 칸은 기본으로 들어간다.
- MVP 인증: **앱 카메라만·운동 중에만·오늘의 지시·중복 검사·멤버 이의**. AI 기구 판별과 위치는 2단계로 미룬다.
- 공개 범위: **초대 전용 2~10명**. 공개 모집은 하지 않는다.
- 돈: 보류. 법률 검토 전까지 앱이 돈을 받거나 맡거나 나눠 주지 않는다(ADR-065).
