# SRS-070 — 화면 정리 P2 — 운동 완료 요약·기록 상세·분석의 반복 제거(D5·D6) + lb 종목 1RM 단위

- **derives_from** → URS-023

### 요구 서술

운동 완료 요약은 PR 목록을 따로 두지 않고 종목별 기록 줄(세트 수·볼륨·1RM) 오른쪽에 금색 「PR n」으로 합친다. 1RM 은 회색 보조 글자로, 추정 주석은 화면 맨 아래 한 번만 둔다. 부가 행동(루틴으로 저장·다시 시작·공유)은 한 줄 보조 버튼으로 모으고 「완료」만 주 버튼으로 둔다.

기록 상세는 「한쪽 입력(볼륨 ×2)」을 종목 머리에 한 번만, 기록하지 않은 RPE 열은 숨기고, 추정 주석은 한 번만 표시한다. lb 로 기록한 종목의 1RM 은 lb 로 보인다(요약·기록 상세). 분석은 「추정 1RM」과 「최근 PR」의 중복을 하나로 합치고 「추정치」 태그를 섹션 주석 한 줄로 바꾼다.

### 수용 기준

- 4종목·PR 8개 운동의 요약에서 PR 관련 줄이 4줄(종목당 1줄)이고 PR 총수 표시(summary-prs)는 그대로다.
- 기록 상세에서 RPE 를 하나도 적지 않은 종목은 RPE 열이 없고, 「Epley」 주석은 화면에 1번만 나온다.
- 덤벨 플라이를 lb 로 기록하면 요약·기록 상세의 1RM 이 lb 단위로 표시된다(단위 테스트·e2e).
- 기존 testid(summary-pr-list·summary-prs·summary-breakdown·btn-summary-*·detail-volume) 유지 — summary-pr-list 는 PR 이 합쳐진 종목 줄 목록을 가리킨다.
