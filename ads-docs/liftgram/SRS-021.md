# SRS-021 — 헬스장 위치 매칭 마켓플레이스 (지오·조건매칭·수수료 우선순위·신규노출 보장)

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-021.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-011, URS-012

### 요구 서술

시스템은 사용자가 입력한 조건(반경·24시간·시설·가격대 등)과 등록 헬스장을 위치 기반으로 매칭하고, 반경 내 헬스장에 실수요 리드를 전달한다. 후보 랭킹은 **수수료(광고비) 납부 비율에 따른 우선순위**를 반영하되, **신규 등록 헬스장에는 일정 기간 항상 일정 %의 수요(노출)를 보장**해 유료 순위만으로 마켓이 왜곡되지 않게 한다. 이는 순수 기록앱이 못 가진 로컬 양면 네트워크 축이며 조기 B2B 현금흐름의 기반이다.

### 수용 기준

- 사용자 조건 게시 → 반경 내 헬스장에 리드 전달 → 헬스장 응답까지 왕복이 동작한다.
- 수수료 비율에 따른 우선순위 + 신규 헬스장 노출 보장(랜덤 가중) 규칙이 랭킹에 반영된다.
- 위치 정보는 사용자 동의 기반으로 처리되고 스팸/허위 리드가 필터링된다.
- 매칭 결과·리드→방문 전환 지표가 사용자·헬스장 양측에 기록된다.

### 연결

도출 URS: URS-012(헬스장 운영자 리드·공정 노출), URS-011(입문자 로컬 접근). 관련: SRS-022(광고·리드), ADR-021(매칭·수수료 정책), SAD-014(마켓플레이스 아키텍처).
