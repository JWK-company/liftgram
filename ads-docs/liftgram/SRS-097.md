# SRS-097 — 홈 화면 위젯 — 작은(운동 중이면 지금 세트·휴식 / 아니면 운동 시작) · 중간(+ 이번 주 운동 횟수 · 다음 루틴) · iOS WidgetKit · 안드로이드 위젯

### 요구 서술

폰 홈 화면에 리프트그램 위젯 두 크기를 둔다. 작은 위젯은 운동 중이면 지금 종목·세트·휴식 남은 시간을, 운동 중이 아니면 「운동 시작」 버튼을 보여 준다. 중간 위젯은 여기에 이번 주 운동 횟수(주간 목표 대비)와 다음 루틴 이름을 더한다.

위젯은 앱이 넘겨준 작은 요약(앱 그룹·공유 저장소)만 읽는다. 기록 DB 를 직접 읽지 않는다. 앱은 운동 시작·세트 완료·휴식 변경·운동 종료·주간 집계가 바뀔 때 요약을 쓰고 위젯 갱신을 요청한다.

### 수용 기준

- 작은·중간 위젯이 안드로이드 실기기와 iOS 시뮬레이터에 추가된다.
- 운동 중이면 위젯 내용이 잠금화면 카드와 같은 세트·휴식을 보여 준다(휴식은 끝나는 시각 기준 카운트다운).
- 「운동 시작」을 누르면 앱이 열리고 다음 루틴(없으면 빠른 운동)이 시작된다.
- 로그아웃하면 위젯이 개인 정보 없이 「로그인」 상태로 바뀐다.
