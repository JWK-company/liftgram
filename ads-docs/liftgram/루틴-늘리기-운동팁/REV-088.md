### 핵심 지적

- 요점의 근거가 데이터에 남지 않아 지어낸 팁을 잡을 수 없다 → 줄마다 `from`(desc·chapter·basis).
- 웰니스 게이트(`src/core/src/domain/wellness.ts`)는 '치료' 정도만 막아 통증·디스크·교정 효과 표현을 못 막는다 → 팁 전용 금지어 + 상세에 늘 안전 고지.
- 테스트 명령이 틀렸다(`bun test` → `cd src && bun run test:core`), 종목 상세 근육은 proto enum 이라 `toMuscles()` 변환이 필요, 점검 스크립트는 hidden 행 404 도 실패로 낸다.
- 「시작 전」 한 줄 문장이 앞뒤가 안 맞고 늦게 끼어들어 버튼을 민다 → 부위 읽기를 `ready` 에 포함. 시트 위 시트·기기 뒤로 동작이 정해지지 않았다.
