# ADR-045 — 크리에이터 루틴은 출처 인용형 정적 데이터로 — 이름은 인용만 · 링크로 원본 연결 · 공식 경로(oEmbed·Data API)+사람 검수 · 자막 수집 안 함

> 타입 ADR · 그룹 liftgram · ADStudio가 `ADR-045.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **informs** → SAD-026, SRS-091, SRS-092

### 맥락

사용자가 AI 콘셉트 루틴 대신 한국 유명 운동인의 실제 영상 루틴을 넣고 원본 링크로 연결하길 원했다. 루틴 내용(종목·세트·횟수)은 사실 정보지만, 대본·썸네일은 저작물이고, 유명인 이름의 상업적 사용은 부정경쟁방지법(2022~)상 문제가 될 수 있으며, YouTube 약관은 영상·자막 내려받기를 금지한다(BIZ-001 §6).

### 결정

- 데이터 = core 정적 파일(배포로 갱신) — 서버·스키마 변경 없음.
- 표기 = 「출처: 채널 · 「영상 제목」」 인용. 사람 이름을 상품명·배지로 쓰는 것은 허락받은 채널만(이번 범위 밖).
- 연결 = 원본 링크(새 창). 임베드·썸네일은 이번 범위 밖(필요 시 공식 임베드만).
- 수집 = oEmbed(제목·채널) + Data API 설명란(키 있을 때) + 사람 확인. 자막·음성 수집·받아쓰기 안 함. 영상이 말하지 않은 세트·횟수는 from:'default' 로 표시.

### 근거 / 대안

- 자막 자동 수집 + AI 정리: 빠르지만 약관 위반이고 오인식이 섞인다 — 기각.
- 서버 DB + 관리 화면: 확장엔 좋지만 시범 규모(10여 개)엔 과하다 — 버전 수가 늘면 재검토.
- 「○○의 루틴」 이름 앞세우기: 유입 효과는 크지만 퍼블리시티 위험 — 제휴(허락) 뒤로 미룸.

### 결과

- 장점: 법적 위험 낮음 · 원본 채널로 시청 유입 · 서버 부담 0.
- 트레이드오프: 콘텐츠 추가가 배포에 묶임 · 사람 검수 시간 · 영상 삭제 시 점검 필요.
- 되돌림: RoutinesClient 의 [원본] 콘셉트 그리드·ConceptDialog 호출 주석을 풀고 새 섹션을 주석 처리(옛 AI 콘셉트 4개 데이터는 보존). 저장 값은 oEmbed 제목·채널만 정적 데이터에 두고 Data API 로 읽은 설명란 원문은 보관하지 않는다(API 정책 저장 기간 — qa H-3 · 정책 원문 확인 필요).
