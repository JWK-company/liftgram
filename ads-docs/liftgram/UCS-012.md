# UCS-012 — 여성 입문자가 안심 온보딩 → 첫 AI 루틴 → 버디 매칭으로 습관을 만든다

> 타입 UCS · 그룹 liftgram · ADStudio가 `UCS-012.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **elaborates** → URS-011

### 주 흐름

1. 가입 후 입문 온보딩에서 성별·목표(입문 근력)·경력·가용 시간·위치·장비를 입력한다.
2. 시스템이 입문 친화 AI 루틴(짧은 시간·자세 영상 안내)을 생성하고 사용자가 조정·채택한다.
3. 첫 세션을 수행·기록하고, 여성 우선 필터로 같은 목표의 버디/멘토를 추천받는다.
4. 그룹/챌린지에 가입해 책임감 루프(결석 케어)로 습관을 이어간다.

### 대안 / 예외 흐름

- 여성 우선 매칭 후보가 부족하면 그룹 우선 노출로 대체하고, 불편 상대는 차단·신고할 수 있다.
- 가용 시간이 매우 짧으면 '30~40분 틈새 루틴'으로 축약 생성한다.
- AI 루틴은 웰니스 가드레일을 통과해야 하며(진단·치료 표방 금지), 실패 시 기본 템플릿 루틴으로 폴백한다.

### 사전 / 사후 조건

사전: 계정 생성. 사후: 채택된 루틴·첫 기록·버디/그룹 연결 중 최소 하나가 확보되어 재방문 동기가 생긴다.
