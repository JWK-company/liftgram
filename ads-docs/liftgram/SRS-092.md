# SRS-092 — 크리에이터 루틴 큐레이션 규칙 — 공식 경로만(oEmbed·Data API) · 자막·음성 수집 금지 · 사람 검수 · 영상 실존 점검

### 요구 서술

크리에이터 루틴은 YouTube 약관과 저작권·퍼블리시티를 지키는 방식으로만 만든다. 영상 제목·채널은 공식 oEmbed 로, 설명란은 공식 Data API(키가 있을 때)로 읽는다. 영상·음성·자막을 내려받거나 받아쓰지 않는다. 루틴 내용(종목·세트·횟수)은 운영자가 영상을 보고 확인한 사실만 적고, 확인하지 못한 세트·횟수는 우리 기본값임을 표시한다.

형사 사건 등 논란이 보도된 인물의 영상은 싣지 않는다. 영상이 삭제·비공개되면 해당 버전을 숨긴다 — 점검 스크립트가 oEmbed 응답으로 찾아낸다.

### 수용 기준

- 점검 스크립트: 모든 버전 영상 id 를 oEmbed 로 조회해 제목·채널이 데이터와 다르거나 404/401 이면 실패를 보고한다.
- 버전 데이터에 verifiedAt(검수 날짜)·prescription 출처(영상 명시 / 우리 기본값) 표시가 있다.
- 코드·스크립트 어디에도 영상·자막 다운로드 경로가 없다(리뷰 체크).
