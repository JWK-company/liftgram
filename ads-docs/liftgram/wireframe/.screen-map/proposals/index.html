S-145 · 운동 보관

보관은 없애고, 내가 만든 종목만 「삭제」로

말씀: 보관이 왜 필요한지, 보관한 종목을 볼 곳도 없다. 꼭 필요하지 않으면 흐름과 화면을 지운다.

지금

  • 종목 상세 아래 「보관」 → 확인창 → 그 종목이 목록·고르기에서 사라집니다(기본 종목도, 내가 만든 종목도).
  • 지난 기록은 그대로 남습니다. 지우면 기록의 종목 이름이 사라져서 「지우기」 대신 「감추기」로 만든 기능입니다.
  • 되살리는 곳이 없습니다. 한 번 보관하면 다시 찾을 방법이 없어, 말씀하신 문제가 맞습니다.
  • 기본 종목 600여 개는 검색으로 찾기 때문에, 하나를 감춰도 얻는 것이 거의 없습니다.
1기본 종목은 보관 버튼 없앰 · 내가 만든 종목은 「삭제」권장

내 종목의 「삭제」는 속으로는 지금처럼 감추기라서 지난 기록 이름이 남습니다. 확인창 문구는 「지난 기록은 남아요」로 둡니다. 이미 보관된 기본 종목은 다시 보이게 되돌립니다(기기마다 다음 동기 때).

2보관 유지 + 「보관한 종목」 목록 추가

종목 목록 맨 아래 「보관한 종목 N개」 → 목록에서 「되살리기」. 기능은 온전해지지만 화면이 하나 늘어납니다.

3보관·삭제 모두 없앰

내가 만든 종목도 지울 수 없게 됩니다. 잘못 만든 종목이 고르기 목록에 계속 남습니다.

정해 주실 것

  1. 1·2·3 중 어느 쪽인지
  2. (1이면) 이미 보관된 기본 종목을 다시 보이게 되돌려도 되는지
S-146 · 이름 바꾸기

⋯ 시트 대신 이름 옆 연필 → 직접 입력 · 「원래 이름으로」

말씀: ⋯ 메뉴에 「이름 바꾸기」 하나뿐인데 시트를 띄울 필요가 없다. 운동 상세에서 연필로 원하는 이름을 쓰고, 기본 이름으로 되돌리는 버튼도 둔다.

지금

  • ⋯ → 「이름 바꾸기」 → 시트 「이 종목을 무엇이라 부를까요?」 → 정해진 별칭 중에서만 고릅니다(벤치프레스 · 플랫 벤치 …). 직접 쓰기는 없습니다.
  • 별칭이 없는 종목은 ⋯ 자체가 안 보입니다.
  • 고른 이름은 나에게만 보입니다(내 기록·루틴·운동 화면). 종목은 하나라서 기록은 섞이지 않습니다.
  • 바꾼 이름 아래에는 원래 이름이 작게 남습니다.
1연필 → 그 자리에서 입력칸 · 아래 별칭 칩 · 「원래 이름으로」권장

이름 옆 ✎를 누르면 이름이 입력칸으로 바뀝니다. 아무 이름이나 쓸 수 있고(30자까지), 그 밑에 기존 별칭이 칩으로 나와 누르면 채워집니다. 바꾼 상태면 「원래 이름(바벨 벤치프레스)으로」 버튼이 보입니다. 별칭이 없는 종목에도 연필이 생깁니다.

2연필 → 직접 입력만 · 별칭 칩 없음

가장 단순합니다. 다만 「바벨 벤치」처럼 흔히 쓰는 이름을 사용자가 매번 직접 쳐야 합니다.

참고: 지금 고른 이름은 내 화면에만 쓰입니다. 직접 쓴 이름도 같은 원칙으로 둡니다. 다른 사람에게 보이는 피드 글·공유 카드에는 원래 이름을 쓰고, 종목 검색은 원래 이름·별칭으로 찾습니다. 구현 때 피드·공유 카드가 어느 이름을 쓰는지 확인해 이 원칙에 맞춥니다.

정해 주실 것

  1. 1·2 중 어느 쪽인지
S-18 · S-21 · S-24

피드 머리에 「사람」 버튼 · 메시지에는 「새 메시지」만

말씀: 사람 찾기를 피드 머리의 사람 버튼으로 옮긴다. 메시지 화면의 사람 아이콘은 없애고, 메시지에는 실제 대화한 목록만. 사람 버튼은 팔로우 목록과 그룹 만들기 자리. 그룹 선택은 왜 있는지 모르겠다.

지금

  • 피드 머리: 🔍 발견(글·해시태그) · 💬 메시지 · 🔔 알림.
  • 메시지 목록은 이미 대화한 방만 보여 줍니다. 오른쪽 위 사람 아이콘은 사람 찾기가 아니라 「단체 대화방 만들기」(S-24)입니다. 팔로우한 사람 중 여럿을 골라 한 방을 만듭니다.
  • 사람 찾기(S-18)는 대화가 하나도 없을 때 나오는 「사람 찾기」 버튼으로만 들어갈 수 있어서, 찾기가 어렵습니다.
  • 「그룹」이 사용자 묶음(분류)처럼 읽히는 것이 헷갈림의 원인으로 보입니다. 분류 기능은 없습니다.
1피드 머리 🔍 · 👤 · 💬 · 🔔 / 사람 화면 = 찾기 + 팔로잉 / 메시지에는 「✎ 새 메시지」권장

👤 사람: 위에 이름 검색칸(지금의 사람 찾기), 아래에 팔로잉·팔로워 목록. 줄마다 「메시지」 버튼이 있어 바로 1:1 대화를 엽니다.
💬 메시지: 대화한 방 목록 그대로 두고, 사람 아이콘 대신 「✎ 새 메시지」. 사람을 한 명 고르면 1:1, 여럿 고르면 단체 대화방이 됩니다(인스타그램·카카오톡과 같은 방식). 따로 있던 「그룹」 화면(S-24)은 이 안으로 합쳐 없어집니다.

2말씀하신 그대로 — 단체 대화방 만들기도 👤 사람 화면으로

사람 화면에서 여러 명을 골라 「단체 대화」를 만듭니다. 메시지 화면에는 대화를 새로 시작하는 버튼이 없어집니다. 대화를 시작하려면 늘 사람 화면을 거쳐야 합니다.

두 안 모두 「그룹」이라는 말은 「단체 대화」로 바꿉니다. 피드 머리 아이콘이 4개가 됩니다(아이콘당 44px, 합쳐 176px). 360px 폭에서 제목과 한 줄에 들어가는지 구현 때 시험으로 확인합니다.

정해 주실 것

  1. 1·2 중 어느 쪽인지
  2. 사람 화면에 팔로워(나를 팔로우한 사람)도 넣을지, 팔로잉만 둘지
S-04 · S-06 · 체중

체중은 분석 맨 위로 · 운동 시작 때 한 줄로 기록

말씀: 분석 맨 아래 체중의 기록·목표 바꾸기·목표 지우기 버튼이 제각각이다. 체중은 위로 옮긴다. 운동 시작 때 S-06 맨 위에서 선택적으로 입력해 분석에 자동 반영한다. 인바디 QR 활용도 구상한다.

지금

  • 분석 화면 맨 아래 「체중」 카드: 그래프 · 기간 · 기록 · 목표 바꾸기 · 목표 지우기가 흩어져 있습니다.
  • 「운동 전 체중 체크인」이 이미 있습니다. 운동을 시작하면 체중 시트가 올라오지만, 기본이 꺼짐이고 켜는 스위치가 프로필 설정 깊숙이 있어 거의 안 보입니다. 체크인 값은 분석 그래프에 그대로 들어갑니다.
  • 프로필에도 체중 줄(기록 · 고치기)이 있습니다.
A분석: 체중 카드를 맨 위 요약 바로 아래로 · 버튼 정리권장

카드 머리 = 「체중 72.5kg · 어제」 + 오른쪽 빨간 테두리 「기록」 하나. 목표는 그래프의 점선으로 보이고, 목표 바꾸기·지우기는 카드 ⋯ 안으로 넣습니다(앱의 다른 카드와 같은 모양).

B운동 화면(S-06) 맨 위에 「⚖️ 오늘 체중」 한 줄 — 팝업 아님 · 안 써도 그만권장

운동을 시작하면 맨 위에 「⚖️ 오늘 체중 기록 · 지난 72.5kg」 줄이 보입니다. 누르면 지금의 체중 시트(± 버튼)가 열리고, 저장하면 「⚖️ 72.6kg ✓」로 바뀝니다. 기록하지 않고 운동하면 그냥 지나갑니다. 지금의 「시작하자마자 시트가 뜨는 체크인」과 프로필 스위치는 이 줄로 바꿉니다. 하루에 한 번 기록하면 그날 다른 운동에서는 줄이 접힌 채(값만) 보입니다.

C인바디 — 단계적으로

1단계(지금 가능): 체중 시트에 「인바디 값도 적기」를 펼쳐 골격근량 · 체지방률 두 칸을 더 받고, 분석에 함께 그립니다.
2단계(조사 필요): 결과지 QR은 인바디 웹(LookinBody)의 개인 결과 주소로 연결되는 것으로 알고 있습니다. 숫자를 바로 읽으려면 인바디와의 제휴(API)가 필요할 가능성이 큽니다. 대안은 결과지 사진을 찍어 숫자를 읽는 방식(OCR)입니다. 실제 QR을 확인한 뒤 따로 스펙으로 제안하겠습니다.

정해 주실 것

  1. A · B 그대로 진행해도 되는지
  2. B로 옛 「체크인 시트」와 프로필 스위치를 없애도 되는지
  3. C는 1단계만 이번에 할지, 조사부터 할지(실물 결과지 QR 사진이 있으면 큰 도움이 됩니다)
