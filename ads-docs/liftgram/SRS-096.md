# SRS-096 — 잠금화면 운동 카드·조작 — iOS Live Activity(다이내믹 아일랜드)·안드로이드 진행 중 알림 · 세트 완료/휴식 +30초/휴식 끝내기 · 잠금 중 조작 대기열 · 휴식 끝 알림

### 요구 서술

운동 세션이 시작되면 잠금화면에 운동 카드를 띄우고, 세션이 끝나거나 버려지면 내린다. iOS 는 Live Activity(잠금화면 + 다이내믹 아일랜드), 안드로이드는 운동 중 고정되는 진행 중 알림(Android 16 의 진행 중 알림 형식 지원)으로 한다.

카드는 종목 이름, 세트 진행(현재/전체), 이번 세트 무게×횟수(사용자 단위 kg/lb), 휴식 카운트다운, 다음 종목을 보여 준다. 휴식 카운트다운은 끝나는 시각만 넘기고 시스템이 줄여 준다(매초 갱신하지 않는다).

조작은 셋이다. 세트 중에는 「세트 완료」 — 저장된 무게·횟수(지난 기록 프리필 포함) 그대로 완료하고 휴식을 시작한다. 조작에는 값을 싣지 않는다. 휴식 중에는 「+30초」와 「휴식 끝내기」. 값이 비어 있는 세트는 「세트 완료」 대신 「앱 열기」를 보여 준다.

세션 상태의 정본은 앱의 로컬 기록(도메인 함수)이다. 잠금 중 앱 화면 코드가 멈춰 있을 수 있으므로, 네이티브는 받은 상태 사본으로 카드를 바로 바꾸고 조작을 id 가 붙은 대기열에 쌓는다. 앱 화면이 살아나면 대기열을 순서대로 도메인 함수로 적용하고 지운다. 같은 조작은 두 번 적용되지 않는다.

휴식이 시작·변경될 때 네이티브 로컬 알림을 끝나는 시각에 예약하고(이전 예약은 취소), 사용자의 알림음 설정을 따른다.

### 수용 기준

- 안드로이드 실기기와 iOS 시뮬레이터에서 운동 시작 시 카드가 뜨고 완료·버리기 시 사라진다.
- 잠금 중 「세트 완료」 3번 → 앱을 열면 세트 3개가 완료돼 있고 볼륨·PR 계산이 앱에서 직접 누른 것과 같다.
- 「+30초」·「휴식 끝내기」가 카드 카운트다운과 앱 휴식 바에 같은 남은 시간으로 반영된다.
- 앱을 강제 종료한 뒤 다시 열어도 대기열 조작이 한 번씩만 반영된다.
- 휴식 종료 알림이 화면이 꺼진 상태에서 ±2초 안에 울린다.
- 앱에서는 휴식 끝 소리를 네이티브가 맡고(iOS 26+ AlarmKit · 안드로이드 알람 재생), 앱이 앞에 있을 때만 웹 소리를 낸다. 웹(브라우저)은 그대로다.
