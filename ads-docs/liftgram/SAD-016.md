# SAD-016 — 오프라인 만남 아키텍처 (버디/파트너 매칭·유료 번개·약속 캘린더·만남 안전)

> 타입 SAD · 그룹 liftgram · ADStudio가 `SAD-016.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **refs** → SRS-024, SRS-027

### 개요 (Summary)

경력·시간대·위치·목표 기반 버디/파트너 매칭, 유료 번개, 약속 캘린더, 오프라인 만남 안전을 잇는 meetup 모듈이다. 매칭은 프로필·운동온도(SAD-017)·안전 필터(SRS-027)를 입력으로 하고, 약속은 캘린더에 등록·리마인드되며, 유료 번개 결제는 SAD-013을 재사용한다. 데이트 매칭은 별도 탐색 UI 없이 SNS 부가 경로로만 노출한다.

### 컴포넌트 / 책임

- **BuddyMatcher: **조건(시간대·위치·목표·성별 우선) 기반 후보 산출, 운동온도·검증 배지 가중.
- **MeetupScheduler: **약속 제안·수락·장소/시간 확정, 캘린더 등록·리마인드(푸시 SAD-011 연계).
- **FlashEventService: **인플루언서 유료 번개 공지→신청→결제(SAD-013)→정원 확정·수수료, 취소/환불 정책.
- **NoShowFeedback: **이행/노쇼 결과를 운동온도·평판(SAD-017)에 반영, 페널티 규칙.
- **SafetyGuard (SRS-027): **여성 우선/전용 필터, 검증 배지, 차단·신고(ADR-017), 첫 만남 공개장소 권고·위치 최소 공유·미성년 제한(ADR-023).

### 연결
