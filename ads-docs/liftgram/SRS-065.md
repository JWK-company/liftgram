# SRS-065 — 기록 상세 세트 조합 표시 · 「이 운동 그대로 다시 시작」(기록 상세·요약) · 피드 남의 운동 「바로 시작」

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-065.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-021

### 요구 서술

기록 상세의 각 종목 머리에 그날의 기록 칸 조합(예: 「해머스트렝스 · 플레이트」, 「로프」, 「와이드 그립」)을 보이고, 세트 줄에 원암·한쪽 입력(「한쪽 40kg ×2」) 같은 세트 속성을 보인다. 기록 목록의 요약 카드(루틴 이름·PR 수·시간·볼륨)는 지금처럼 둔다.

기록 상세·요약에 「이 운동 그대로 다시 시작」을 둔다. 새 운동은 그 운동의 종목·순서·종목별 세트 수·슈퍼셋·기록 칸 조합을 따르고, 무게·횟수는 지금의 세션 시작 규칙(이전 기록)으로 채운다. 진행 중인 운동이 있으면 기존 「이어 하기 / 버리고 시작」 규칙을 따른다. 피드의 남의 운동 카드·상세에는 「내 루틴으로 가져오기」 옆에 「바로 시작」을 두고, 종목 매칭은 가져오기와 같은 규칙(id → 이름·별칭 정확 일치 → 커스텀 생성)을 쓴다.

### 수용 기준

- 해머스트렝스+플레이트로 한 체스트 프레스 기록 상세에 그 조합이 보이고, 「다시 시작」 운동의 그 블록이 같은 칸으로 열린다.
- 4종목·슈퍼셋 1묶음 운동을 다시 시작하면 같은 순서·세트 수·묶음으로 시작된다.
- 피드 운동 「바로 시작」이 루틴을 만들지 않고 새 운동을 시작한다.
