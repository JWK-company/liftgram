# UCS-019 — 트레이너가 프로 구독으로 회원 루틴·주간 스케줄을 관리하고 리포트로 점검한다

> 타입 UCS · 그룹 liftgram · ADStudio가 `UCS-019.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 사전 조건

- 온보딩에서 "회원을 구하고 싶어요"에 응답해 트레이너 role이 태깅되어 있고, 프로필에 등급·매너온도·검증 배지가 노출된다(SRS-025·027).
- 프로 모델 구독이 활성 상태다(SRS-014).

### 주 흐름

1. PT문의 DM(SRS-017)과 크레딧 멘토링 계약(SRS-023)으로 회원을 확보한다. 계약 성립 시 회원이 동의한 범위(루틴·주간 스케줄·운동 기록)의 접근 권한이 부여된다.
2. 담당 회원 목록에서 회원을 선택해 루틴에 처방 어휘(세트 타입·RIR·반복범위·중량대)로 처방을 작성한다.
3. 주간 스케줄(요일→루틴·휴식)과 블록 주기(N주+디로딩)를 편집한다 — 회원 홈에 즉시 반영.
4. 회원 리포트(부위별 볼륨·운동별 퍼포먼스·완료율)를 보고 다음 주 처방을 조정한다 — 판단은 트레이너, 앱은 사실 집계만 표시.
5. 정산은 기존 크레딧·수익배분 체계(SRS-016·023)를 따른다.

### 대안 / 예외 흐름

- 계약 해지·동의 철회 시 접근 권한 즉시 회수 — 이후 리포트·루틴 편집 불가, 감사 로그 기록.
- 프로 구독 만료 시 처방 작성·리포트가 잠기고 열람 전 상태로 강등(기존 처방은 회원에게 유지).

### 사후 조건

- 회원 세션에 처방이 렌더되고(UCS-018), 처방 이력이 변경 추적된다.
