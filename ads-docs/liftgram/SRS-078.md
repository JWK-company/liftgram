# SRS-078 — 체중 추세 차트 — 기간 전환 · 목표 체중 선·남은 차이 · 주간 변화

- **derives_from** → URS-024

### 요구 서술

통계에 「체중」 블록을 두고 SRS-077 이력을 날짜 축 곡선으로 그린다. 기간은 1개월·3개월·1년·전체에서 고른다. 사용자가 목표 체중을 정하면 목표선을 함께 그리고, 최신값과의 차이(예: '1.7kg 남음')를 보여 준다.

주간 변화는 최근 기록으로 계산한 주당 변화량(kg·%)으로 보여 주며, 계산 방법(이동평균 구간 등)은 스펙에서 정한다. 기록이 하나뿐이면 곡선 대신 값과 '한 번 더 적으면 추세가 보여요' 안내를 보여 준다. 감량·증량을 권하거나 건강 상태를 판단하는 문구는 쓰지 않는다(SRS-015).

### 수용 기준

- 기록 두 개 이상에서 곡선이 날짜 순서·비율에 맞게 그려지고, 기간 전환 시 축이 다시 맞춰진다.
- 목표를 정하면 목표선과 남은 차이가 보이고, 목표를 지우면 둘 다 사라진다.
- 주간 변화 계산이 단위 테스트(기록 간격이 불규칙한 경우 포함)로 검증된다.
- 블록 문구가 웰니스 카피 게이트를 통과한다.
