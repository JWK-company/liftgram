# SRS-087 — 서버 백업 검증·월 복원 시험·결과 기록 — 백업은 DB와 다른 디스크(h2500-3 /home)에, 매일 결과·매월 복원 시험을 DB 표에 남김

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-087.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-027

### 요구 서술

매일 백업 스크립트는 덤프를 DB와 다른 물리 디스크(h2500-3 /home)에 남기고, 덤프가 읽히는지 확인한 결과(성공 여부·크기·테이블 데이터 수·백업 디스크 남은 공간)를 운영 DB의 백업 기록 표에 한 줄 남긴다. 실패해도 그 실패를 남긴다.

매월 1일 복원 시험은 가장 최근 덤프를 같은 DB 서버의 임시 데이터베이스에 되살려, 핵심 표(users·sync_records)의 행 수를 운영 DB와 대조하고 결과를 남긴 뒤 임시 DB를 지운다.

### 수용 기준

- 백업이 성공하면 kind=daily ok=true 한 줄이, 덤프가 비거나 읽히지 않으면 ok=false 한 줄이 생긴다.
- 복원 시험은 임시 DB를 남기지 않고, 행 수 차이가 0이거나 백업 뒤 늘어난 만큼(운영 ≥ 복원)이면 ok=true다.
- 백업 디스크 여유가 20GB 아래면 결과에 경고가 실린다.
