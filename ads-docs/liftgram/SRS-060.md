# SRS-060 — 운동을 루틴으로 저장 — 빠른 운동 완료 시 묻기 · 루틴 운동 「새 루틴으로 저장」 · 요약·기록 상세 「이 운동으로 루틴 만들기」

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-060.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-019

### 요구 서술

완료 세트가 1개 이상인 운동 하나를 루틴으로 저장하는 단일 기능을 둔다. 저장되는 루틴은 완료 세트가 있는 종목만, 오늘의 순서·슈퍼셋 묶음, 종목별 완료한 워킹 세트 수, 횟수 범위(루틴 운동이면 원래 루틴의 목표 범위, 아니면 그날 한 워킹 세트 횟수의 최소~최대), 휴식(원래 값 또는 기본값)을 담고 무게와 기록 칸 변형은 담지 않는다(다음 시작 때 지난 기록·지난 조합으로 채워진다).

진입은 세 곳: ① 빠른 운동 완료 시 「루틴으로 저장할까요?」 ② 루틴 운동 완료 시트의 「새 루틴으로 저장」 ③ 요약 화면·기록 상세의 「이 운동으로 루틴 만들기」. 기본 이름은 루틴 운동이면 「원래 이름 (수정)」, 아니면 「M/D 주요 부위」(완료 세트가 많은 주 근육 상위 2개)이고 저장 전에 고칠 수 있다.

### 수용 기준

- 빠른 운동 완료 시 질문이 뜨고, 저장하면 루틴 목록에 생기며 그 루틴으로 시작하면 같은 종목·순서·세트 수·슈퍼셋이 뜬다.
- 완료 세트가 없는 종목은 저장되지 않고, 무게는 저장되지 않는다(시작 시 이전 기록으로 채움).
- 「저장 안 함」·닫기면 루틴이 생기지 않는다. 요약·기록 상세에서도 같은 결과로 저장된다.
- 같은 이름이 있으면 「(2)」를 붙인다.
