# SRS-023 — 크레딧 시스템 (충전·소비·P2P 피드백·멘토링 계약·파트너 정산·환전)

### 요구 서술

시스템은 사용자가 크레딧을 충전하고, 일회성 피드백 요청·멘토링 계약(기간형 온라인 PT)·유료 번개 참가 등에 소비하며, 파트너(수익화 인증 완료) 유저가 크레딧을 현금으로 정산받는 내부 경제를 제공한다. 모든 크레딧 이동은 이중기입 원장으로 기록되고, 피드백/계약은 에스크로로 보호되며, 자전거래·어뷰징을 탐지한다. 크레딧 현금화는 전자금융·세무 규제 준수 범위에서만 개방한다. 정산·세무·글로벌 지급 인프라는 트레이너 수익배분(SRS-016)과 공유한다.

### 수용 기준

- 크레딧 충전(웹 MoR)→소비→상대 크레딧 이체가 이중기입 원장에 남는다.
- 멘토-멘티 계약 성립·기간 관리·정산 근거(실제 사용 기반)가 투명하게 표시된다.
- 파트너 인증(신원·계좌·세금양식) 완료자만 정산 가능, 플랫폼 수수료(15~30% 범위) 차감·세무 처리.
- 분쟁·미이행 시 에스크로 환불/중재, 자전거래 탐지·차단이 동작한다.

### 연결

도출 URS: URS-013(P2P 크레딧 경제), URS-009(트레이너 공정 수익). 관련: SRS-016(정산·세무 공유), SRS-014(수익화), ADR-022(크레딧 규제 대응), SAD-015(크레딧·월렛·정산), SAD-013(결제).
