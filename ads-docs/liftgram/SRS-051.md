# SRS-051 — 앱 셸·공통 UI 규약 (화면 프리미티브·상태 3종·토스트·다이얼로그·탭 내비·디자인 토큰)

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-051.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 요구 서술

운동 중 한 손으로 빠르게 기록하려면(URS-001) 화면마다 조작이 달라서는 안 되고, 한국어 문구·다크 테마 등 app에서 익힌 경험이 웹에서도 그대로여야 한다(URS-007). 이를 위해 **화면이 각자 만들지 않고 셸과 공통 컴포넌트를 쓰는 규약**을 둔다.

- 셸: 하단 탭 바(운동·피드·기록·캘린더·분석·프로필)·전역 운동 바·토스트 슬롯·모달 포털·에러 경계를 셸이 소유한다. 폭은 폰 폭(560px)으로 잡는다.
- 공통 컴포넌트: 버튼·아이콘 버튼·입력·아이콘(app과 같은 글리프)·아바타·스켈레톤·목록 상태·화면 머리·다이얼로그/액션 시트(RN Alert 대체)·화면 프리미티브.
- 상태 3종: 로딩·빈 상태·오류는 표준 컴포넌트와 라우트별 loading/error 경계로 보여 준다.
- 디자인 토큰: app의 theme/tokens.ts가 원본이고 make sync-core가 CSS 변수를 생성한다(드리프트 검사). 색 하드코딩 금지.

### 수용 기준

- 새 화면 제너레이터(make gen-page)가 셸 규약(RSC 초기값·loading·error 경계)을 지킨 뼈대를 만든다.
- 토큰을 바꾸면 sync-core 뒤 CSS 변수가 바뀌고, 생성물과 원본이 어긋나면 검사가 실패한다.
- 확인 대화상자·액션 시트는 모두 Dialog 컴포넌트를 거친다(브라우저 기본 confirm 미사용).
