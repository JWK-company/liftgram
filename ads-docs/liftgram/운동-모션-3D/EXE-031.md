# EXE-031 — SPEC-034 Phase 1 — 범용 생성기와 표본 검증 구현

> 타입 Execution · 그룹 liftgram/운동-모션-3D · ADStudio가 `EXE-031.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-034

### 요약

범용 생성기와 제작 도구를 만들고, 리뷰 지적을 반영한 뒤 전 클립을 저해상도로 눈 검수했다. 연결은 633행 중 311행, 클립 294개다. 제작 도중 렌더 버그가 확인되어 12개 진행 시점에 멈추고 고쳐 다시 시작했다.

### 테스트 결과

- python3 src/scripts/motion/qc.py --selftest: 16개 지표 통과
- 사전 점검 전 클립: 합격 219, 경고 60, 불량 15. 불량 15는 눈으로 확인(스텝업 발·상자 접촉 6cm 등)
- render_queue 전 클립 시험 렌더: 실패 0
- 실제 영상 합성 지표(IoU·구멍·떨림)와 빨강 경계는 제작 후 Phase 2에서 확인한다(이번 단계 미확인)

### 수용 기준 확인

SRS-055: 표본 40개 대신 전 클립 294개의 5프레임 시트를 눈으로 확인했다. 자동 지표는 첫 실행에서 실제 불량(몸 파묻힘 47건, 바 위치 7건 등)을 잡았고 수정 후 줄었다.

### 코드 리뷰
