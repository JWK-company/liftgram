# REV-054 — SPEC-034 스펙 리뷰

> 타입 Review · 그룹 liftgram/운동-모션-3D · ADStudio가 `REV-054.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **reviews** → SPEC-034

### 패널 구성

- 3D 애니메이션 파이프라인 기술 감독
- 운동 지도·근육 해부 전문가
- 웹·PWA 프런트엔드 성능 엔지니어
- 오픈소스 라이선스·배포 운영 감사관

### 핵심 지적

- 자동 변환은 검증된 적이 없고, 270개 안팎의 영상이 평면 가정·2포즈 왕복으로 표현할 수 없다.
- 자세 원본에 부상 위험 자세가 있고(RDL 무게 경로) 기존 지표로는 잡히지 않는다.
- 영상 키가 다른 동작을 합쳐 원암 풀업 같은 오안내가 생긴다.
- 배포 위치·SW 수정 대상이 틀렸고, MP4 Range 요청이 기존 캐시와 충돌한다.
- 라이선스 서술이 부정확하고 저장소가 공개 상태다.
