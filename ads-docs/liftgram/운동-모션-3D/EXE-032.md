# EXE-032 — SPEC-034 Phase 2 — 전 종목 제작과 검수 구현

> 타입 Execution · 그룹 liftgram/운동-모션-3D · ADStudio가 `EXE-032.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-034

### 요약

h2500-3 GPU로 704px 영상 294개를 렌더·Wan·합성했다. 전 영상을 5프레임 시트로 눈 검수해 불량을 고쳐 다시 만들고, 5개는 제외했다. 합격 영상 289개가 종목 306행에 연결된다. 633행 중 나머지 327행은 사유와 함께 픽토그램을 유지한다.

### 테스트 결과

- 제작: 289개 오류 0, 약 20MB, H.264·BT.709, 길이 2.4초.
- src/scripts/motion/qc.py 최종 판정: 합격 219 · 경고 59 · 불량 11. 불량 11개는 눈으로 오탐으로 판정해 src/scripts/motion/qc_waivers.json 에 지표별로 올렸다(스텝업·스텝다운 6개 pen_max, 누운 레그·니 레이즈 2개 elbow_min, 사이드 벤드 2개·스핑크스 1개 contact_slip_cm).
- 불량 심기: 벤치프레스 Wan 8프레임을 배경으로 지우자 불량으로 잡혔다.
- 프레임 튐(이 기록을 처음 쓴 뒤 발견): 5프레임 시트에 안 보이던 튐이 25프레임 연속 시트에서 나왔다. 몸통 높이가 최대 14cm, 몸 회전이 최대 16° 한 번에 뛰었다. 전 클립을 잰 결과 값이 달라지는 21개를 다시 제작했고, 마스크 기준 최대 튐 비율이 7.64에서 2.8로 줄었다. 튐이 컸던 8개 클립은 25프레임 시트로 확인했다.
- 한계: 나머지 클립은 프레임 간 수치와 5프레임 시트로만 확인했다.
