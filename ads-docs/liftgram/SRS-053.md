# SRS-053 — 오프라인 기록 보존 — 동기 실패 표면화·계정 전환 가드·백업 파일·설정 동기

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-053.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 배경

2026-10-26 컷오버 때 드러났다. 옛 앱의 동기가 8월부터 매번 실패했는데(서버 레코드 65건에 섞인 _status가 pull을 죽였다) 화면은 아무 말도 하지 않았고, 운동 32건을 포함한 두 달치 기록이 기기에만 있었다. 주소를 옮기자 꺼낼 길이 없어 임시 복구 페이지로 IndexedDB를 덤프해 되살렸다.

### 요구

동기 건강(마지막 성공·연속 실패·안 올라간 사용자 기록 수)을 들고, 멈췄으면 경고 띠로 알린다. 로그인하지 않은 채 기록이 쌓이면 백업을 권한다.

계정 전환 시 미동기 기록이 있으면 지우지 않는다 — 원래 계정으로 돌아가거나, 백업 파일로 내보낸 뒤 지운다.

백업 파일 내보내기·가져오기. 가져오기는 지우지 않고, 더 최근에 고친 것만 덮으며, 기본 카탈로그는 건너뛴다.

계정과 함께 옮길 앱 설정은 프로필(app_prefs)에 싣는다.

서버·클라이언트 양쪽에서 WatermelonDB 내부 필드(_status·_changed)를 걸러낸다.
