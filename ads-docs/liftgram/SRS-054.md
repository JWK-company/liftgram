# SRS-054 — 화면 재설계 — 앱바 2형·5탭 라인 아이콘·목록 줄·구간 선택기·위험 동작 ⋯ (화면 구성 규칙 · 6단계 배포)

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-054.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 배경

v0.23에서 로고·주황·라이트/다크·글꼴(디자인 토큰)은 앱 전체에 들어갔지만 화면 배치는 옛 RN 앱을 옮긴 그대로였다. 앱바가 화면마다 다르고, 탭이 6개(기록·캘린더가 같은 데이터)이며, 모든 요소가 카드라 위계가 없고, 운동 취소·기록 휴지통 같은 위험 버튼이 크게 노출되고, 운동 중에도 탭바가 휴식 띠와 겹쳤다. 운영자가 북타래처럼 화면별로 디자이너가 손본 배치를 요청했고, 시안(claude.ai/artifact/3CVyQDuS3Ky1s1qBdrXudT)을 2026-10-26 전부 권장안(A)으로 승인했다.

### 공통 규칙 (북타래 차용 · 색은 liftgram 주황)

앱바 2형 — 탭 첫 화면: 로고(운동 홈) 또는 큰 제목 + 오른쪽 아이콘 최대 2개. 하위 화면: ← · 가운데 제목 · 더보기(⋯).

탭바 — 5개 이하, 라인 아이콘, 현재 탭만 브랜드색 + 위쪽 강조선. 개발 피드백 탭은 내부 사람에게만.

목록 — 카드 대신 줄(왼쪽 내용 · 오른쪽 값/›)과 구역 제목. 카드는 요약 한 장에만.

선택 — 기간·보기 전환은 구간 선택기(회색 틀 안 흰 칸) 또는 밑줄 탭. 칩은 필터에만.

위험 동작 — 삭제·취소는 ⋯ 메뉴나 시트 안으로, 확인을 거친다. 화면에 늘 노출하지 않는다.

치수 — 좌우 여백 16–20 · 누르는 칸 44 이상 · 카드 반경 12 · 시트 반경 16 · 활자는 토큰 단계 안에서만.

### 결정 (D1~D6 — 모두 A)

D1 탭 5개: 운동 · 기록 · 피드 · 분석 · 프로필. 기록과 캘린더는 한 탭의 목록/달력 전환. /calendar 주소는 기록 달력으로 이어진다.

D2 운동 중 집중 모드: 운동 화면에서는 탭바를 숨기고, ⌄로 내리면 모든 탭 위에 진행 중 막대(휴식·현재 종목).

D3 운동 홈 요약형: 이번 주 목표 → 시작 버튼 → 루틴(줄마다 시작) → 최근 운동.

D4 라인 아이콘 + 현재 탭 위 강조선.

D5 피드 글쓰기는 + 버튼 → 전체 화면 작성기(운동 완료의 「피드에 공유」도 같은 작성기).

D6 단계마다 배포하고 버전을 올린다(SemVer minor).

### 단계

P0 공용 조각 (v0.24.0) — 앱바 2형 · 탭바 5칸 라인 아이콘 · 목록 줄 · 구역 제목 · 구간 선택기 · 밑줄 탭 · 바닥 시트 · 숫자 한 줄 · ⋯ 메뉴.

P1 운동 흐름 (v0.25.0) — 운동 홈 · 운동 중(집중 모드) · 운동 추가 시트 · 완료 · 진행 중 막대.

P2 기록·분석 (v0.26.0) — 기록 목록/달력 · 분석 · 루틴 상세 · 종목 목록/상세 · 기록 상세.

P3 계정·설정 (v0.27.0) — 프로필 · 로그인 · 가입·비밀번호·확인 · 로그인·보안 · 백업 파일.

P4 소셜 (v0.28.0) — 피드 · 게시물 · 발견 · DM · 알림 · 남의 프로필.

P5 나머지 + 넓은 화면 (v0.29.0) — 코칭·장비·헬스장·프로그램·관리, 태블릿/데스크톱 폭.

### 불변

기록 데이터·동기화·오프라인 저장·휴식 알림 소리 예약(Web Audio)·세션 저장·로그인 방식은 바꾸지 않는다. 화면 요소의 data-testid를 유지해 기존 e2e가 그대로 돈다(데이터 안전·오프라인 e2e는 단계마다 필수 통과). 단계마다 라이트·다크 모바일 캡처로 확인한다.
