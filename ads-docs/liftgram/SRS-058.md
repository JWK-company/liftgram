# SRS-058 — 머신 적재 방식(핀로드/플레이트)·케이블 부착물(로프·일자바·V바·EZ바·벌컨 등) 기록 칸 + 지난 선택 기억 + 플레이트 한쪽 입력

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-058.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **derives_from** → URS-016, URS-018

### 요구

같은 브랜드·같은 머신 종목이라도 핀로드(스택)와 플레이트로드는 무게 의미가 달라 이전 기록·PR이 섞이면 안 된다(#57). 케이블 종목은 부착물(로프·일자바·V바·EZ바·싱글 핸들·벌컨/MAG 그립 등)에 따라 수행 무게가 달라 기록을 나누고, 지난번 부착물을 기억해 기본 선택한다(#54).

플레이트 머신은 한쪽 무게로 입력하는 것이 편하므로 「한쪽 무게로 입력」을 고를 수 있고, 볼륨·PR 비교는 양쪽 합으로 계산한다(#53). 손 방향·폭 그립(오버·언더·뉴트럴·와이드·클로즈)은 지금처럼 세트 속성이며 기록 칸을 나누지 않는다.

### 범위

- 기록 칸(버킷) 축: 머신 = 브랜드 × 적재 방식, 케이블 = 부착물. 그 외 축 추가 없음. 변형 키 규칙·정규화 함수 확장 + 기존 키 하위호환(적재 방식 미지정 = 기존 칸).
- 운동 중 UI: 머신 종목 옵션에 적재 방식, 케이블 종목 옵션에 부착물. 지난 선택 기본값.
- 플레이트 한쪽 입력: 세트 또는 종목 단위 표시 플래그 + 볼륨·1RM 계산 반영. 표시 무게와 계산 무게 구분.
- ADR-026(버킷 축=기구 하나) 개정, ADR-030(초안) 재결정.

### 수용 기준

- 같은 체스트 프레스 머신(해머스트렝스)에서 핀로드 80kg 기록과 플레이트 40kg×2 기록의 이전 기록·PR이 서로 섞이지 않는다.
- 로프 푸시다운 30kg과 일자바 푸시다운 40kg이 각 부착물 칸에 따로 남고, 다음 세션에 지난 부착물이 기본 선택된다.
- 플레이트 한쪽 40kg 입력 세트의 볼륨이 80kg 기준으로 합산된다.
- 기존 기록(적재 방식·부착물 미지정)은 그대로 기존 칸에서 보인다(이관 없이 하위호환).

### 연결

도출: URS-018(무게 달라지는 조건 분리), URS-016(변형 분리 기록). 피드백 #57·#54·#53. 결정 개정: ADR-026·ADR-030.
