# SRS-043 — 처방 어휘 데이터 모델 + 세션 처방 렌더 (세트 타입·RIR·중량 이어달리기·세트 완료 UX)

> 타입 SRS · 그룹 liftgram · ADStudio가 `SRS-043.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 요구 서술

루틴 데이터 모델에 **처방 어휘** — 세트 타입(웜업/탑/백오프)·목표 RIR(0~6)·반복범위(min~max)·중량대 힌트(저/중간/고중량 또는 수치) — 를 선택적으로 저장한다. 처방의 작성 주체는 사람(트레이너 또는 프리셋 루틴)이며 알고리즘이 자동으로 처방을 변경하지 않는다(BS-004 핵심 결정). 세션 화면은 처방이 있으면 세트 행에 타입 배지·RIR 라벨·목표 반복 placeholder를 렌더하고, 없으면 기존 자유 기록 UI를 그대로 유지한다(옵트인 레이어).

세션 기록 편의 두 가지를 함께 제공한다. **① 중량 이어달리기**: 직전 세트의 실측 중량·횟수를 입력하면 같은 운동의 다음 세트 권장 중량을 순수함수로 계산해 placeholder로 제시한다(웜업 래더 비율·백오프 비율 — 소수점 시 가장 가까운 실중량 안내). 제안은 항상 근거(reasonKey)와 함께 표시되고 사용자가 자유롭게 무시할 수 있다(웰니스 가드레일 — SRS-015). **② 세트 완료 마이크로 UX**: 중량·횟수가 모두 입력된 세트만 완료 체크할 수 있고, 완료 행은 잠금(재탭으로 해제)되며 세트 타입별 권장 휴식 시간으로 기존 restAlarm 타이머가 자동 시작된다. 미완료 세트가 있는 종료는 확인 모달을 거친다.

### 수용 기준

- 루틴 세트에 setType·targetRir·repMin/repMax·loadHint를 저장·수정할 수 있고, 마이그레이션 후 기존 루틴은 처방 없음(null)으로 무손상 동작한다.
- 세션에서 처방 세트는 타입 배지+RIR 라벨+반복 placeholder로 표시되고, 처방 없는 세트는 기존 UI와 픽셀 수준 동일.
- 20kg 입력·체크 시 다음 웜업 세트 placeholder가 규칙대로 갱신되고 reasonKey 문구가 노출된다(단위 kg/lbs 각각 검증).
- 완료 체크 → 행 잠금·타이머 시작(타입별 시간), 재탭 → 해제·편집 가능. 미완료 종료 시 확인 모달.
- 권장 중량 계산은 순수함수 + 단위 테스트(경계: 첫 세트·0/음수·단위 전환) 포함. cd app && npm run typecheck·test 통과.
