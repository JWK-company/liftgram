# SAD-026 — 크리에이터 루틴 — core 정적 데이터(주제별 버전·출처) + 콘셉트 시트 확장 + 세트·횟수 가져오기 + oEmbed 점검 스크립트

> 타입 SAD · 그룹 liftgram · ADStudio가 `SAD-026.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **refs** → SRS-091, SRS-092

### 개요

크리에이터 루틴은 서버·스키마 변경 없이 core 정적 데이터로 시작한다. 콘셉트 루틴(conceptRoutines.ts)과 같은 결로 creatorRoutines.ts 에 주제(conceptId)별 버전 목록을 두고, 루틴 탭의 콘셉트 시트가 그 주제의 버전을 함께 보여 준다. 저장은 기존 importRoutine 을 세트·반복 범위·메모까지 받도록 넓혀 쓴다.

### 컴포넌트 / 책임

- core/domain/creatorRoutines.ts — CreatorRoutine{id·conceptId·source{videoId·title·channel·channelUrl·verifiedAt}·summaryKo·days[{nameKo·items[{exerciseId·sets·repsMin·repsMax·restSec?·from:'video'|'default'}]}]} · creatorRoutinesFor(conceptId).
- core 테스트 — 종목 id 카탈로그 실존 · videoId 형식 · 출처 필드 필수 · 주제당 채널 ≥2 · 문구 가드(guideCopy).
- routineRepository.importRoutine — 선택 인자 targetRepsMax·restSeconds·routineNotes 추가(기존 호출 결과 불변).
- RoutinesClient 콘셉트 섹션 — 주제 카드(버전 0개 주제 숨김) → 시트 하나 안에서 단계 전환(버전 목록 → 버전: 출처 줄·제휴 아님 고지·종목 세트×횟수·「원본 영상 보기」·「내 루틴에 저장」). 옛 AI 콘셉트 4개는 호출부 주석(데이터 보존).
- scripts/check-creator-routines.mjs — oEmbed 로 영상 실존·제목·채널 대조(배포 전 수동/CI 선택). 영상·자막을 내려받는 코드는 두지 않는다.

### 연결
