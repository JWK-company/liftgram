- **휴식이 끝나면 카드가 위로 튀어 오터치가 날 수 있다.** 세로 가운데 맞춤 때문이다.
- **± 가 누르는 즉시 실행되어 슈퍼셋을 끌면 값이 바뀐다.**

## 에뮬레이터에서 추가로 찾은 것

리뷰 지적이 아니라 반영 후 API 35 에뮬레이터에서 확인하다 찾은 것으로, 위 집계에 넣지 않았다.

- **± 를 누른 채 밖으로 끌면 값이 바뀜.** 스크롤할 내용이 없으면 `ScrollView` 가 취소를 보내지 않는다. 버튼 밖으로 나가면 직접 취소하도록 고쳤다.
- **마지막 단계에서 ± 가 한 줄만큼 내려감.** 다음 줄을 `GONE` 대신 `INVISIBLE` 로 바꿨다.
- **라이트에서 완료 버튼 아래 옅은 띠.** 진행 막대 바탕을 투명하게 바꿨다.
