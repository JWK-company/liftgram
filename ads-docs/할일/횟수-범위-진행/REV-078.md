# REV-078 — SPEC-043 코드 리뷰

> 타입 Review · 그룹 할일/횟수-범위-진행 · ADStudio가 `REV-078.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **reviews** → SPEC-043

## 패널 구성

- 근력 운동 코치 겸 도메인 리뷰어(점진적 과부하·더블 프로그레션) — 규칙 타당성·버그·문구·e2e 를 한 번에 봤다(Task 등급 · 스펙 리뷰를 겸함 — 스펙이 승인된 제안 A 를 그대로 옮긴 것이라 코드와 함께 봤다).

## 핵심 지적

- 「채우기」가 사람이 고친 값을 덮는다(새로 그리면 카드가 다시 뜸).
- 한쪽 입력 배수를 맞추지 않아 지난번 합계를 한쪽 칸에 넣는다.
- 실패 세트를 빼서 오히려 무게를 올린다 — 더블 프로그레션 원칙과 어긋남.
- 다른 루틴의 같은 종목 기록으로 제안한다(3~5회 루틴 기록이 8~12 루틴 제안에 쓰임).
- 범위 안 「한 회 더」가 높았던 세트를 깎는다.

## 분류

| 번호 | 지적 | 분류 | 반영 |
| --- | --- | --- | --- |
| D-1 | 사람이 고친 값 덮음 | 채택 | `fillOpenWorkSets` 가 userEdited 세트를 건너뛰고, 카드는 채울 세트가 없으면 숨는다(화면 상태 대신 데이터로) |
| D-2 | 한쪽 입력 배수 | 채택 | 지난번 무게×배수 ÷ 이번 배수, 증분도 배수로 나눈다 |
| D-3 | 실패 세트 | 채택 | 주 세트에 실패가 있으면 hold |
| D-4 | 다른 루틴 기록 | 채택 | `getPreviousLineWorkSets` — 같은 루틴 줄(routine_exercise_id)·같은 조합의 직전 기록 |
| D-5 | 높았던 세트 깎음 | 채택 | `repsBySet` — 세트마다 지난번 +1(위쪽 값까지) |
| D-6 | 증분 하나 | 채택(일부) | `progressionIncrementKg` — 바벨 2.5 · 덤벨·케틀벨 2 · 머신·케이블 5 · lb 5/10. 가벼운 종목 비율 상한은 보류 |
| D-7 | 세트별 「다음엔 무게 ↑」가 블록 판정과 어긋남 | 채택 | 세트 글자를 「위쪽 값 달성」으로 |
| D-8 | 드롭·백오프에도 목표 | 채택 | 웜업·피더·드롭·백오프 제외(화면·저장소 같은 기준) |
| D-9 | 세트를 한 뒤에도 제안이 남음 | 채택 | 작업 세트를 하나라도 끝내면 접는다 |
| D-10 | e2e 가 기본 범위에만 의존 | 채택 | 편집기에서 6~8 로 바꾸고 운동 네 번(결과 · hold · addRep 세트별 · increase) |

| D-12 | 운동 중 루틴 범위 변경 미반영 | 보류 | 그 세션 안에서만 생기는 일 |
