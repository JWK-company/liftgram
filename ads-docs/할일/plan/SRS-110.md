# SRS-110 — 루틴 한눈에 — 종목 한 줄과 미리보기 시트

> 타입 SRS · 그룹 할일/plan · ADStudio가 `SRS-110.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 배경

사용자 요청(2026-11-08 채팅 1240 · 2번): 루틴 목록 줄은 이름과 「종목 n개」만 보여, 어떤 루틴인지 알려면 편집 화면에 들어가야 한다. 웹 보고서의 제안 2-A(종목 한 줄) + 2-C(미리보기 시트)를 사용자가 「추천대로 진행」(1252)으로 승인했다.

### 요구

- **R1 종목 한 줄**: 루틴 목록 줄(폴더 밖·폴더 안)에서 「종목 n개」 자리에 종목 이름을 루틴 순서대로 「 · 」로 이어 한 줄로 보인다. 앞 세 개까지 적고 나머지는 「외 N」(줄이 좁아 이름이 잘려도 「외 N」은 보인다). 이름은 다른 화면과 같은 표시 이름. 종목이 없으면 「종목 없음」.
- **R2 미리보기 시트**: 줄의 이름·종목 부분을 누르면 시트가 열린다 — 루틴 이름, 종목마다 이름과 「3세트 · 8~12회」(처방이 있으면 처방 세트 수, 유산소는 「유산소」), 슈퍼셋 묶음 표시. 아래에 「시작」(그 루틴으로 운동 시작 · 진행 중 운동이 있으면 기존 확인 흐름)과 「편집」(루틴 편집 화면).
- **R3 기존 동작 유지**: 줄 오른쪽 「시작」 버튼과 ⋯ 메뉴는 그대로. 시트가 열려도 목록 순서·폴더 펼침은 바뀌지 않는다.

### 범위 밖

- 루틴 카드 디자인 전면 개편 · 근육 그림(오늘 카드에만).
