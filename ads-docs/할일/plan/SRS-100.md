# SRS-100 — 잠금화면 위 전용 운동 화면(안드로이드) — 화면을 켜면 갤럭시 잠금화면 대신 운동 화면 · 세트 완료·무게·횟수 조정·휴식 조작 · 휴식 끝에 화면 켜기

> 타입 SRS · 그룹 할일/plan · ADStudio가 `SRS-100.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 요구

안드로이드 앱 사용자가 운동 중에 휴대폰을 잠갔다가 다시 켜면, 갤럭시(기기) 잠금화면 대신 **리프트그램 운동 화면이 화면 전체로** 보여야 한다. 사용자는 잠금을 풀지 않고 다음 조작을 할 수 있어야 한다:

- 지금 종목·세트 번호·무게×횟수를 본다.
- 무게(±)·횟수(±)를 바꾼 뒤 「세트 완료」를 누른다.
- 휴식 카운트다운을 보고 +30초·건너뛰기를 누른다.
- 다음 세트·종목을 미리 본다.

배경: SRS-096의 잠금 카드(알림)는 갤럭시 잠금화면에서 작게만 보인다. 사용자는 「잠금으로 돌아갔을 때 화면 전체를 우리 앱으로 조작하고 싶다」고 요청했다(2026-11-03, 갤럭시 S26).

### 수용 기준

| # | 기준 |
| --- | --- |
| 1 | 운동 중(카드 스냅샷 있음) 화면을 끄고 켜면 운동 화면이 잠금화면 위에 전체로 보인다 |
| 2 | 세트 완료는 잠금 해제 없이 된다. 바꾼 무게·횟수도 함께 기록되고, 앱을 열면 한 번만 반영된다(SRS-096 대기열) |
| 3 | 휴식 +30초·건너뛰기가 카드와 같은 규칙으로 동작한다 |
| 4 | 휴식이 끝나면 화면이 켜지고 운동 화면과 소리(설정 따름)가 나온다 |
| 5 | 「잠금 해제」를 누르면 기기 잠금(지문·PIN)을 거쳐 앱의 운동 화면으로 간다. 그 밖의 화면은 잠금 해제 없이 열리지 않는다 |
| 6 | 운동이 끝나면 운동 화면이 닫히고 원래 잠금화면으로 돌아간다 |
| 7 | 프로필 「잠금화면 운동 화면」으로 끌 수 있다(기본 켜짐). 기기가 전체 화면 알림을 막았으면 「허용 필요 — 켜기」로 설정 화면을 연다 |
| 8 | 잠금이 풀린 상태(일반 사용 중)에는 이 화면이 뜨지 않는다 |

### 범위 밖

- 아이폰 — 애플은 잠금화면 전체를 앱에 주지 않는다(Live Activity만, SRS-096).
- 갤럭시 나우바 전용 연동.
- 잠금 화면에서 운동 종료·종목 넘기기 — 실수 방지를 위해 잠금 해제 뒤에만 한다.
