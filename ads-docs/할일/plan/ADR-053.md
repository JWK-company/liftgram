# ADR-053 — 추천 탭 광고 간격을 팔로잉보다 좁힌다

> 타입 ADR · 그룹 할일/plan · ADStudio가 `ADR-053.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **informs** → SRS-098

### 맥락

ADR-050은 피드 광고를 글 6개마다로 정했다. 사용자는 추천 탭을 광고 위주로 두라고 했다(2026-11-05). 실광고는 아직 없고 관리자 미리 보기로만 보인다.

### 결정

추천 탭은 팔로잉과 같은 6번째 글 뒤에 첫 칸을 두고, 그다음부터 글 3개마다 둔다. 팔로잉 탭은 6개 그대로다. 운동 중 광고 0 규칙은 그대로 둔다. 구현은 `src/core/src/domain/adPolicy.ts`.

### 대안

- 처음부터 3개마다: 첫 화면 인상이 나빠 택하지 않았다.
- 팔로잉과 같은 6개: 사용자 요청과 다르다.

### 결과

- ADR-050의 피드 간격 규칙은 추천 탭에 적용하지 않는다.
- 하루 상한·첫 7일·서포터 규칙은 ADR-050대로 실광고를 붙일 때 저장소와 함께 만든다. 그때 3개 간격이 지나친지 다시 본다.
- 추천 관심도는 광고 목적으로 쓰지 않는다.
