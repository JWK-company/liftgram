# ADR-050 — 서포터 가격과 광고 자리 규칙 — 월 2,900원 · 운동 중 광고 0 · 자리 먼저, 실광고는 스토어 출시 뒤

> 타입 ADR · 그룹 할일/plan · ADStudio가 `ADR-050.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **informs** → SRS-098
- **refs_legacy** → PLM:SRS-014

## 맥락

수익 모델 보고서(2026-11-03)를 사용자가 할 일 #T3에서 「권장대로 따른다」고 정했다. 보고서가 오너 결정으로 남긴 항목도 권장안으로 확정한다. 앱 광고 방향은 BS-006·ADR-046·SRS-098 에 이미 있고, 이 결정은 그 위에 가격과 세부 규칙을 정한다.

보고서는 앱이 웹뿐이라는 전제로 쓰였다. 지금은 안드로이드 앱이 있으므로, 앱 광고만 쓰고 웹은 무광고로 둔다는 SRS-098 이 보고서의 웹 광고 순서보다 우선한다.

## 결정

- **유료 등급 이름:** 서포터. 기능은 잠그지 않는다.
- **가격(잠정):** 월 2,900원 · 연 24,000원 · 평생 59,000원. 결제 구현 때 수수료와 부가세를 반영해 다시 정한다(SRS-098).
- **서포터 혜택:** 광고 없음 · 프로필 배지 · 공유 카드와 앱 색 테마 · 새 기능 먼저 써 보기.
- **광고 금지:** 운동 세션 전체(세트 표·휴식 타이머·종목 추가와 교체 피커·전역 운동 바) · 잠금 운동 화면 · 운동 알림 카드 · 홈 위젯 · PR 축하 오버레이(`src/frontend/app/components/PrCelebration.tsx`) · 공유 카드 · 온보딩 · 로그인 · 결제 · 설정 · 약관 · 개인정보 · DM · 코칭 · 신고 화면 · 내용이 없는 화면(빈 목록·로딩·오류). 세트가 0인 완료 요약도 비운다.
- **광고 자리:** 완료 요약 결과 아래 1개(하루 첫 운동만) · 피드 게시물 6개마다 1개 · 기록·통계·종목 상세 스크롤 끝 1개 · 운동 홈 맨 아래 1개.
- **빈도:** 가입 후 첫 7일 광고 없음 · 하루 8회 상한. 가입 기록을 알 수 없는 비로그인 사용자는 일단 비운다.
- **표시:** 「광고」를 항상 표시하고 게시물 카드와 구별되게 그린다. 버튼 바로 옆에 두지 않는다.
- **순서:** 지금은 자리와 가드만 만든다. 스토어 출시와 아래 점검을 통과한 뒤 AdMob 을 붙인다.
- **결제 구현:** 이 결정에 넣지 않는다. 출시 체크리스트의 결제 항목에서 다룬다.

## 실광고 착수 점검

- 광고 방식 시범: AdMob 배너는 웹뷰 위 네이티브 층이라 스크롤 안 자리에 넣지 못할 수 있다. 자리 동기 · 하단 고정 · 웹뷰 안 광고 중에서 고른다.
- 개인정보처리방침: `src/frontend/app/privacy/page.tsx` 의 「광고 목적의 프로필 분석이나 제3자 판매는 하지 않습니다」를 고친다.
- 스토어 신고와 동의: Play 광고 포함·데이터 보안 신고, 광고 ID 권한, 동의 화면, iOS ATT.
- Play 정책: `REQUEST_INSTALL_PACKAGES` 와 앱 자체 업데이트를 스토어 빌드에서 어떻게 할지 정한다.
- 서포터 판정: 계약의 User 에 값이 없다. 서버 값을 만든다.
- 광고 업종: 보충제 등 차단 목록을 정한다. 관련 규제는 확인이 필요하다.

## 근거 / 대안

- **보고서 근거:** 국내 경쟁 앱이 「광고 + 광고 없는 PRO」를 쓰고, 광고 불만은 운동 중 광고에서 나온다.
- **Hevy식 루틴 개수 상한:** 「모든 기능 무료」와 어긋나 기각.
- **운동 끝 전면 광고:** 완료의 기분을 깎아 기각.
- **휴식 타이머 아래 배너:** 오터치 무효 클릭 위험으로 기각.
- **잠금 운동 화면 광고:** Google Play 정책 위반 소지로 기각(SPEC-021).

## 결과

- **위험 — 가격 전제:** 보고서 가격은 웹 결제 수수료 3.5% 기준이다. Play 자동 갱신 구독 수수료는 15%로, 월 2,900원의 수령액은 약 2,465원이다. 소비자가에 부가세가 포함되면 약 2,240원으로 줄어든다(추정). 웹은 광고가 없어 「광고 없음」 혜택은 앱에서만 값이 있다.
- **위험 — 평생 이용권:** 평생 59,000원은 서버 비용을 계속 부담한다. 판매 전에 판매 수 상한과 서비스 종료 시 환불 문구를 정하고 법률 확인을 받는다.
- **수치 한계:** 경쟁 앱 가격은 2026-11 조사값이고, 수익 계산은 추정이다.
- **바뀌는 문서:** SRS-098(자리 목록). PRD 비목표의 광고 자리 문장도 함께 고친다.
