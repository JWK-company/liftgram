# BS-008 — 출시 전 체크리스트

> 타입 BS · 그룹 할일/plan · ADStudio가 `BS-008.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

## 요약

할 일 #T9의 출시 전 체크리스트입니다. 구현은 하지 않았고, #T10의 글대로 여기서 멈추고 대기합니다.

상태는 네 가지로 적습니다. **됨**은 코드에서 확인한 것, **안 됨**은 없다고 확인한 것, **미확인**은 실행이나 운영 서버 확인이 필요한 것, **결정**은 사용자가 정할 것입니다.

요청하신 질문의 답은 다음과 같습니다.

- **결제가 북타래와 같은가:** 같게 할 수 없습니다. 북타래는 구독으로 기능을 여는 모델이고, 리프트그램은 기능을 잠그지 않는 서포터 모델입니다(ADR-050). 북타래도 실제 결제 연동 코드는 찾지 못했습니다(표와 등급 판정만 확인). 가져다 쓸 구현이 없습니다.
- **광고가 북타래와 같은가:** 다릅니다. 북타래는 읽기 몰입을 해쳐 광고를 기각했고(북타래 ADR-008), 리프트그램은 앱에 광고를 넣기로 했습니다(ADR-050).

## 6. 해자

**현재 판단:** 기능 자체로는 해자가 약합니다. 세트 표, 타이머, 분석은 경쟁 앱도 갖추고 있습니다. PRD가 말한 리텐션 해자(메이트·챌린지)는 아직 없습니다(BS-007).

이 앱에서 쌓일 수 있는 후보입니다. 시장 근거로 검증한 것은 아니고, 코드에 있는 자산에서 뽑은 가설입니다.

| 후보 | 왜 쌓이는가 | 지금 상태 |
| --- | --- | --- |
| 사람 코칭 관계 | 코치와 회원이 함께 옮겨야 해서 이탈 비용이 큽니다 | 처방은 작동, 알림·동의·열람 화면이 없음 |
| 운동 친구와 피드 | 사람이 있어야 가치가 생깁니다 | 피드는 있고 사람이 없음 |
| 쌓인 기록 | 오래 쓸수록 옮기기 번거롭습니다. 다만 가져오기·내보내기가 있어 잠그는 힘은 약합니다 | 작동 |
| 기구·브랜드별 기록과 한국어 종목 | 국내 헬스장 기구 데이터는 따라오기 어렵습니다 | 기록 작동, 분석 연결 없음 |

**권장:** 첫 출시의 해자는 코칭 관계로 잡고, 동의·알림과 코치 분석 화면을 먼저 끝냅니다. 정하실 일입니다.

### 쉽게 베끼지 못하게 하는 최소한의 방지책

화면과 기능은 완전히 막을 수 없습니다. 웹 소스는 브라우저에서 보이고 앱은 디컴파일됩니다. 그래서 법적 권리를 먼저 잡고, 데이터 대량 수집만 막기를 권합니다. 위 후보처럼 사람과 관계가 쌓이는 쪽이 실제 방어입니다.

| 방지책 | 상태 | 할 일 |
| --- | --- | --- |
| 상표 등록 | 미확인 | 「liftgram」 이름과 로고의 국내 상표를 조회하고 출원합니다. 비슷한 이름의 충돌도 봅니다. 변리사 확인이 필요합니다 |
| 약관의 금지 조항 | 안 됨 | `src/frontend/app/terms/page.tsx`에서 관련 표현을 찾지 못했습니다. 복제·자동 수집·역설계 금지를 넣습니다 |
| 데이터 대량 수집 방지 | 미확인 | 피드와 공개 API의 요청 제한을 점검합니다 |
| 앱 코드 난독화 | 안 됨 | `src/mobile/android/app/build.gradle:69`가 `minifyEnabled false`입니다. 켜고 시험합니다. 시간을 벌 뿐 막지는 못합니다 |
| 저작권 증거 | 미확인 | 비공개 저장소를 유지하고, 직접 만든 종목 데이터와 픽토그램의 제작 기록을 남깁니다 |
