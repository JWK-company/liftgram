# SRS-102 — 운영자 페이지와 사용자 의견 수집

> 타입 SRS · 그룹 할일/plan · ADStudio가 `SRS-102.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

### 요구

출시 뒤 운영자는 앱이 어떻게 쓰이는지 숫자로 봐야 한다. 지금은 가입자 수조차 DB를 직접 봐야 알 수 있고, 운영 기능은 앱 하단 탭에 섞여 있다.

### 기능

- 운영 탭을 없애고 운영 기능을 `/admin` 으로 모은다
- 가입, 현재 접속, 일·주·월 활성, 재방문, 기능별 사용, 루틴 사용 방식, 콘텐츠와 신고 현황을 보여 준다
- 사용자 수 지표는 로그인, 비로그인(무작위 기기 ID), 합계를 나눠 보여 준다
- 이용 기록은 우리 DB에만 쌓는다
- 운영 피드백은 운영진만 쓰고, 사용자 피드백은 앱 사용자가 쓴다. 둘은 섞이지 않는다
- 피드백은 나중에 운영자 승인 뒤 자동 수정으로 이어질 수 있는 구조로 저장한다

### 제외

- 결제율: 결제 기능이 생길 때 붙인다(할 일 문서에 등록)
- 승인 뒤 자동 수정 자체

### 수용 기준

운영 탭이 없고, 운영자만 `/admin` 에서 로그인·비로그인·합계로 나뉜 통계를 본다. 일반 사용자는 눈에 띄는 입구로 의견을 보내고, 운영 피드백은 운영진만 쓴다.
