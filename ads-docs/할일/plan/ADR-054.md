# ADR-054 — 이용 통계는 우리 DB에, 비로그인은 무작위 기기 ID로, 피드백은 PLM 대신 우리 DB로

> 타입 ADR · 그룹 할일/plan · ADStudio가 `ADR-054.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **informs** → SRS-102

### 맥락

앱은 이용 기록을 전혀 남기지 않고, 로그인 없이도 쓸 수 있다. 운영 피드백은 2026-11-03에 쓰지 않기로 한 PLM 아이디어보드로 보내고 있다. 사용자는 나중에 ADStudio 보고 기능처럼 피드백을 승인하면 자동으로 코드를 고치는 흐름을 계획하고 있다.

### 결정

- 이용 기록은 우리 PostgreSQL 에 쌓고 외부 분석 도구를 쓰지 않는다
- 비로그인 기기는 계정과 연결하지 않는 무작위 ID로 센다. 로그인 중에는 기기 ID를 보내지 않는다
- 사용자 수 지표는 로그인과 비로그인을 따로 내고, 합계는 둘의 단순 합으로 낸다
- 운영 피드백과 사용자 피드백을 `feedback_items` 한 표에 `kind` 로 나눠 저장하고, 승인 상태와 처리 기록 칸을 둔다. PLM 전송은 끊는다
- 결제율은 이번에 만들지 않는다

### 대안

- PostHog 등 외부 도구: 화면 흐름 분석은 강하지만 외부 제공을 방침에 추가해야 하고 비용이 든다
- 로그인 사용자만 집계: 단순하지만 비로그인 사용자가 보이지 않는다
- 기기 ID와 계정 연결: 전환율은 알 수 있지만 익명성이 사라진다
- 피드백을 PLM 에 유지: 이미 떠난 시스템에 의존하고, 자동 수정으로 이을 상태를 우리가 갖지 못한다

### 결과

- 같은 기기가 하루 안에 비로그인과 로그인을 모두 쓰면 합계에 두 번 잡힌다
- 비로그인에서 가입으로 넘어간 전환율은 측정하지 못한다
- 비로그인 숫자는 위조 요청으로 부풀 수 있어, 추세로만 읽어야 한다
- 개인정보처리방침을 고치고 7일 공지 뒤 수집을 시작한다
