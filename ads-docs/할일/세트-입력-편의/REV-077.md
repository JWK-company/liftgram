## 핵심 지적

- 시트가 닫히며 확인창이 같은 순간 열리면, 시트 칸을 걷는 popstate 가 막 열린 확인창을 닫는다(운동 버리기·루틴 삭제 등 4곳). 개발 StrictMode 도 같은 길.
- 창의 선택지가 화면 이동을 하면 창 칸 걷기(history.back)의 popstate 를 Next 가 RESTORE 로 받아 진행 중 이동을 버린다.
- 가져오기 화면 보초가 창 칸이 빠진 popstate 에도 반응해 「나갈까요?」를 띄우고 보초를 쌓는다.
- 빈 칸 복사가 다른 세트의 값을 지운다(무게만 적고 누르면 횟수 null · 운동 중 횟수 0).
- 버튼의 세트 수를 저장 전 그림으로 센다.
