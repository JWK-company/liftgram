### 패널 구성

- 보안 감사관: 입구, 쿠키, 프록시 경계
- 시험 설계자: 시험이 실제로 결함을 잡는지
- 프런트엔드·세션 신뢰성 담당: 탭 경합, 오류 분기, 접근성
- 배포·운영 담당: compose, 배포 스크립트, 이미지

### 핵심 지적

- 치명 결함은 없다. 보안 감사에서 Access 를 우회하는 경로를 찾지 못했다.
- 높음: 로그인 뒤 돌아갈 주소가 `/%09/evil.example` 로 외부 사이트에 갈 수 있었다. 브라우저 실측으로 재현했다.
- 높음: 다른 탭의 로그아웃, 세션 종료, 계정 교체가 열린 탭에 전달되지 않아 화면과 실제 요청 계정이 달라질 수 있었다.
- 중간: 서비스 이름 없는 `docker compose up` 이 운영 웹을 앱 설정으로 다시 만들어 공개 주소를 끊고 모든 인터페이스에 포트를 열었다. 임시 프로젝트에서 실측했다.
- 중간: Access 의 403 을 권한 회수로 오판, JSON 이 아닌 로그인 응답에서 버튼 멈춤, 503 이 로그아웃으로 처리됨, 열린 탭의 역할이 낡음.
- 시험: 위조 헤더를 받은 쪽에서 확인하지 않았고, 탭 경합 시험이 줄서기를 증명하지 못했으며, 12시간 만료 시험은 쿠키 조작으로 통과해 실제 경로를 지나지 않았다.
