### 패널 구성

| 역할 | 관점 |
| --- | --- |
| 모바일 UI 디자인 시스템 검토자 | 상자·밑줄·꺾쇠 규칙의 충돌, 빠진 단추, 깨질 배치, 토큰 대비 |
| 접근성·e2e 시험 검토자 | 새 가드의 실현성·거짓 양성/음성, 기존 e2e 충돌, 접근성 이름·터치 영역·대비 |

Feature 등급이라 세 명이 기본이지만, 이 스펙은 화면 모양 한 관심사라 두 관점으로 나눴다.

### 핵심 지적

- 상자가 된 quiet 는 secondary 와 같은 모양이 된다 — 위계는 크기로만 갈린다.
- 빨강이 화면에 여러 번 생긴다(피드 글마다 「팔로우」, 홈 띠의 「받기」 채움).
- 업데이트 줄 안의 채운 단추가 평평한 기록지 가드(`src/frontend/e2e/flat-design.spec.ts`)에 「상자」로 걸린다.
- 가드가 다크를 `emulateMedia` 로만 켜면 `dark:` 변형이 안 켜진다. hover 바탕·비활성 단추·스위치 줄·달력 칸을 잘못 센다.
- ghost 를 테두리 상자로 바꾸면 사용자 의견으로 정한 루틴 카드 「▶ 시작」(판 없는 빨강 글자)이 바뀐다.
- 범위에서 빠진 단추가 있다: 체중 카드 「기록」, 연습 블록 「다시 해 보기」, 휴식 띠 「+15초」·「건너뛰기」. 「숨기기」는 이미 없어졌다.
