### 요약

세트 방식 6개의 틀과 판정·운동 중 남은 줄 계산을 core 에 만들고, 처방 줄에 피더 타입·「최대」·방식 이름을 더했다. 무게는 기존 「1RM %」·「탑셋 %」 기준을 쓴다. 서버 코칭 정리 규칙도 같은 값을 알고, 코치 저장에서 회원 값을 지킨다.
