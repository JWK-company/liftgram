# EXE-052 — SPEC-041 Phase 4 — 운동 후 반영과 기록 구현

> 타입 Execution · 그룹 할일/세트-방식 · ADStudio가 `EXE-052.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-041

### 요약

운동을 마칠 때 운동 중 바꾼 세트 방식이 「<종목> 세트 방식 A → B」 항목으로 뜨고, 체크하면 루틴 줄의 처방을 새 틀 전체로 쓰며 끄면 오늘만이다. 처방 루틴도 반영할 수 있게 잠금을 풀었고 처방 줄은 세트 수 항목을 만들지 않는다. 기록 상세에 세트 방식 태그를 단다.
