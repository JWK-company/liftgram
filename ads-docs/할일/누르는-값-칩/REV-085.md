## 패널 구성

- **React 정확성 리뷰어** — 비활성 처리, 마친 세트, 유산소, 음수 여백, 이름 문구 (9개 지적)
- **모바일 시각 디자인·UX 리뷰어** — 360×640 라이트·다크 화면, 마친 세트 화면을 직접 찍어 본 판단 (8개 지적)
- **접근성·시험 리뷰어** — 낭독기 이름, 44px, e2e가 실제로 회귀를 잡는지 (8개 지적)

## 핵심 지적

- e2e의 바탕 측정은 칩 바탕이 없으면 바깥 버튼을 재게 되어 있었다. 바깥 버튼은 원래 투명이라 「바탕 없음」 단언이 구조가 깨져도 통과한다.
- 마친 세트의 「이전」은 못 누르는데 이름이 「…채우기」로 남았다. 유산소는 마친 세트에도 바탕이 남고 눌렸다.
- PR 칩이 비활성일 때 예전 안내(「채울 세트가 없어요 — 세트를 추가하세요」)가 사라졌다.
- 「이전」 칩이 둥근 회색 네모라 바로 옆 입력칸과 높이로만 구별됐다.
- 빨강 가드에 세트 방식 이름 예외와 시험이 없었다.
