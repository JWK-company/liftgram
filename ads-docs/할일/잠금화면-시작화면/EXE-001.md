## SPEC-017 Phase 1 — 시작 화면(로고 차오르는 로딩) 구현

### 요약

스토어 앱의 콜드 스타트를 「아이콘 → 같은 자리의 빈 윤곽 로고 → 웹 덮개에서 로고가 차오름 → 첫 화면」으로 이었다. 네이티브 스플래시(안드로이드 12+ SplashScreen API·iOS LaunchScreen)와 웹 부팅 덮개가 같은 기하·같은 크기(56)·같은 OS 바탕색을 쓰고, 덮개가 문서에 들어오는 순간 인라인 스크립트가 스플래시를 내린다. 실패해도 플러그인 상한 6초와 CSS 8초 안전망이 화면을 풀어 준다.
