| 역할 | 관점 |

| 안드로이드 플랫폼 엔지니어 | 커스텀 뷰 제스처, 시스템 뒤로 가기, 1초 틱·재빌드, API 24~35 |

### 핵심 지적

- 붙잡는 동안 drain 이 새 휴식을 흘리고, 되돌린 휴식이 웹 휴식에 LWW 로 진다(계약 1).
- 되돌릴 때 옛 단계를 맨 앞에 넣으면 그 사이 온 스냅샷과 어긋나 세트가 겹친다(계약 2).
- 붙잡는 중 앱이 앞에 오면 같은 세트가 두 번 기록되거나 앱에서 고친 값이 덮인다(계약 3).
- 손잡이를 왼쪽 끝에서 잡으면 시스템 뒤로 가기가 화면을 닫는다(안드로이드 1).
- 화면을 떠나면 Handler 의 5초 깨우기가 지워진다(안드로이드 2).
- `ValueAnimator.areAnimatorsEnabled()` 는 API 26 부터라 24·25 에서 죽는다(안드로이드 3).
- 가로 문턱 12dp·슈퍼셋 예외 누락은 승인안과 다르다(사용성 1·2).
- ② 첫 밀기의 진동이 완료로 착각된다. TalkBack 의 띠 상태 전환이 말없이 일어난다(사용성 5·7).
