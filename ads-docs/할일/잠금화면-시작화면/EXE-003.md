# EXE-003 — SPEC-017 Phase 3 — 웹 다리 · 적용기 · e2e 구현

> 타입 Execution · 그룹 할일/잠금화면-시작화면 · ADStudio가 `EXE-003.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-017

## 요약

앱 껍데기(Capacitor) 안에서 웹이 잠금화면 카드 플러그인(`LiftgramLock`)과 주고받는 다리를 만들었다. 잠금 중 누른 완료 조작을 앱 복귀 때 seq 순서로 기록에 반영하는 적용기(drain)를 core에 두고, 같은 write 계약(판정·비교·완료 한 write → 채우기 → 워터마크 → 내려쓰기 확인 뒤 ack)을 단위·e2e로 고정했다. 휴식은 의도 시각 LWW로 웹·네이티브가 합치고, 카드에 보인 값과 저장값이 다르면 두 값을 보여 「본 값으로 바꾸기」를 준다. 웹 브라우저(앱 아님)에서는 플러그인 호출이 0이다.
