# REV-040 — SPEC-030 코드 리뷰

> 타입 Review · 그룹 할일/피드-추천-탭 · ADStudio가 `REV-040.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **reviews** → SPEC-030

### 패널 구성

- 서버·SQL·개인정보 검토자: 쿼리 누출, 자동 숨김 악용, 동시성, 비용
- 화면·상태 검토자: 탭 상태, hydration, 공개 범위 흐름, 시험 공백
- 이 스펙은 Feature 등급이라 규칙상 3명이지만 두 분야로 나눠 2명이 넓게 봤다. 부족분은 이 문서에 적어 둔다.

### 핵심 지적

- 추천 쿼리에서 비공개·차단 글이 새는 문제는 없었다.
- 배포를 막을 문제는 모두 자동 숨김에 있었다: 차단당한 사람의 표, 새 계정 3개의 악용, 숨긴 댓글의 영구 방치.
- 화면에서는 시트를 닫았다 열면 공개 범위가 전체 공개로 돌아가는 문제가 가장 위험했다.
