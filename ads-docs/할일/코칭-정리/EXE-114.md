## 요약

코칭 목록 줄의 ⋯ 를 떼고 오른쪽에 🗑 하나만 둔다(코칭 중 「연결 끊기」 · 보낸 요청 「요청 취소」 · 받은 요청 「요청 거절」 · 확인창 문구도 같은 뜻 + 「운동 기록은 지워지지 않아요」). 코치 쪽 기록 요약·루틴은 담당 회원 줄을 눌러 들어가는 회원 화면 탭으로 옮겼고, 회원 쪽은 코치 이름을 누르면 시트(공유 범위 바꾸기 · 연결 이력)가 열린다(2a). 연결 이력은 회원 화면 루틴 탭 맨 아래 접기 칸으로(3a).
