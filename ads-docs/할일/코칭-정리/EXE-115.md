# EXE-115 — SPEC-059 Phase 3 — 8칸 코드·코치 찾기 정리 구현

> 타입 Execution · 그룹 할일/코칭-정리 · ADStudio가 `EXE-115.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-059

## 요약

「코드로 연결」을 인증 코드처럼 8칸으로 바꿨다 — 소문자는 대문자로, 칸은 저절로 넘어가고, 붙여넣기(하이픈·공유 문구·링크)도 받는다. 코칭 화면의 「코치 찾기」 검색을 없애고 안내 두 줄(코드 · 사람 찾기 → 프로필 요청)을 두었다. 프로필의 「코치로 요청」은 상대가 「코칭 요청 받기」를 켰을 때만 보이고, 서버도 끈 사람에게 오는 회원 요청을 거절한다(4a).
