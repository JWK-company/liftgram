# EXE-044 — SPEC-040 Phase 2 — 유형별 대표 컨펌 구현

> 타입 Execution · 그룹 할일/모션-전종목-재제작 · ADStudio가 `EXE-044.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-040

### 요약

동작 유형별 대표 16개를 공통 엔진으로 만들고, 사용자 컨펌(힙 쓰러스트 팔꿈치만 지적)과 독립 동작 리뷰를 반영해 16개를 모두 다시 만들었다. 검수 페이지(같은 주소)에 수정판을 올렸다. 운영에는 아직 넣지 않았다.

### 수용 기준 확인

- SRS-055: 대표 동작이 관절 범위·고정점·관통·무게중심 검사를 통과한다 — 19개 합격.
- ADR-061: 동작 근거는 유튜브 관찰 기록(서버 `references.json`, 원형 46개)이고 영상은 내려받지 않았다.
- 컨펌: 사용자 답 1018(힙 쓰러스트 외 통과, 확장 진행). 수정판은 같은 페이지에서 다시 보도록 알렸다.
- 떨림 기준: 프레임당 관절각 12°·위치 6cm·비틀림 25°, 완화 상한은 `CAPS`. 묶음 순서는 SPEC 표대로 앉기·런지부터.
- GPU 시간: 영상당 약 1분(4장 병렬 기준 실효) → 남은 약 595개는 10~11시간(재작업 제외).
