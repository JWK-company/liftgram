### 요약

가로로 밀기·위로 밀기·당기기·팔·어깨·코어·머신·역도/전신 묶음의 계산식을 만들어 CPU 뼈대 검사를 통과시키고, GPU 4장으로 4회차(393 → 148 → 33 → 10개)를 돌려 전 종목 영상을 만들었다. 영상 614개 중 567개가 새 영상(합격)이고 47개는 기존 영상을 유지한다. 컨펌은 전 종목 검수 페이지에서 한꺼번에 받는다(사용자 1087).
