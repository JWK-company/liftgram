# EXE-045 — SPEC-040 Phase 3 — 앉기·런지 묶음 구현

> 타입 Execution · 그룹 할일/모션-전종목-재제작 · ADStudio가 `EXE-045.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-040

### 요약

앉기·런지 묶음 76개(영상 기준)의 계산식을 만들어 75개를 GPU로 제작하고 검수 페이지(같은 주소)에 올렸다. 사용자가 1050에서 「지금까지 한 종목에는 피드백 할 건 딱히 없어」로 확인했다. 운영 반영은 다음 묶음과 함께 한 번에 한다.

| 검수 페이지 반영 | 75개 게시(시시 제외) |

### 수용 기준 확인

- SRS-055: 앉기·런지 75개가 자동 검사를 통과했다. 시시 스쿼트 1개는 사유(지워진 비율 1.03%)를 기록하고 기존 영상을 유지한다.
- ADR-061: 동작 근거는 서버 references.json의 유튜브 관찰 기록이다. 영상은 내려받지 않았다.
- 사용자 승인: 1050(피드백 없음).

### 코드 리뷰

REV-070: 채택 7 · 보류 5 · 기각 0. 채택 7건은 반영해 재제작까지 마쳤다.

### 범위 밖 변경
