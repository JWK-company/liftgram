### 리뷰 밖에서 찾은 문제

운영 서버에서 이미지를 실제로 띄워 찾았다. 둘 다 코드 리뷰와 로컬 시험으로는 드러나지 않았다.

- Dockerfile 의 onnxruntime 1.20.1 이 모델의 ConvInteger 를 실행하지 못해 시작 즉시 종료: 평가 때와 같은 1.31.1 로 고정
- numpy 의 OpenBLAS 가 코어 수(64)만큼 스레드를 띄워 `pids_limit` 를 소진, 상태 확인 명령이 실행되지 않음: `OPENBLAS_NUM_THREADS=1` 로 해결

### 후속 조치

- 보류 2건은 검토 대기가 쌓이면 다시 본다
- 첫 배포 뒤 운영에서 검사 컨테이너 healthy 와 격리를 확인한다
- 맥에서는 프로세스 첫 요청이 약 6초 걸려 3초 상한에 걸렸다. 운영 서버 첫 요청은 0.2초여서 코드는 바꾸지 않았다(일시 실패 경로로 재검사된다)
