### 수용 기준

- 걸린 사진의 글은 작성자에게만 보이고 파일은 404: 브라우저 시험으로 확인
- 제3자에게 보이지 않음: 추천 탭에서 확인
- 검토자는 모든 장을 미리 보고 승인하면 열림: 확인
- 일시 실패는 올리기를 막지 않고 재검사: 단위 시험으로 확인
- 시행일 전에는 검사와 카카오 호출을 하지 않음: 단위 시험으로 확인
