## 핵심 지적

- **새 시트 시험이 늘 실패**: 「루틴 가져오기」 진입 링크는 ADR-064 로 막혀 있어(`src/frontend/app/components/routines/RoutinesClient.tsx:605`) `btn-routine-import` 를 누를 수 없었다 — 실제로 Phase 4 시험에서 라이트·다크 둘 다 시간 초과. 주소 `/routines/import` 도 `notFound()`(`src/frontend/app/routines/import/page.tsx`).
- **허용 목록 0 인데 재지 않는 곳**: 프로필 칩·분할 토글은 시트 안에만 그려지고, 달력 자랑 버튼·고른 날 칸은 기록이 늦게 읽히면 조용히 빠졌다.
- **사진 위 버튼 판정이 엇나감**: `onImage` 가 조부모의 직계 img 만 봐서 아바타 옆 버튼을 건너뛰고, 형제 img 위에 뜬 버튼은 놓쳤다.
- **코칭 회원 화면 기간 토글**: 고른 칸 판과 트랙의 대비가 1.12(라이트)·1.48(다크)이고 트랙은 아직 8px — segCellClass 를 안 썼다.
- **남은 빨강**: 추천 헬스장 ★·「추천」, 장비 링크 아이콘, 장비 태그 「추가」, 댓글 「답글 보기」, 세트 방식 이름, DM 보낸 사람 이름.
- **남은 6px**: 기록 칸 고르기의 「한쪽만」 칸, 운동 블록 메모 입력·다른 조합 칸·휴식 스테퍼.
- **보조 버튼이 칩처럼 보임**: 종목 찾기 「스무고개」 버튼이 옅은 판(R1b 와 같은 꼴)이었다.
- 손으로 쓴 칩(폴더·온보딩·코치 프로필)에 포커스 링이 없음 · 체중 카드 「기록」이 앞 값과 이어 읽힘.
