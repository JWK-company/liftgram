# EXE-010 — SPEC-019 Phase 1~3 — 잠금화면 위 전용 운동 화면 구현

> 타입 Execution · 그룹 할일/잠금-운동화면 · ADStudio가 `EXE-010.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-019

## 요약

SPEC-019 세 단계를 한 번에 구현했다.

- 안드로이드: 운동 중 화면을 다시 켜면 갤럭시 잠금화면 위에 리프트그램 운동 화면이 전체로 뜬다(`LockWorkoutActivity`). 잠금을 풀지 않고 할 수 있는 일은 세트 완료(길게 누르기), 무게·횟수 ±, 휴식 +30초·건너뛰기다. 휴식이 끝나면 화면을 켜서 띄우고 소리를 낸다.
- 웹: 바꾼 값을 정확히 한 번, 바꾼 칸만 출처 user로 기록한다. 프로필에서 켜고 끌 수 있고, 허용이 필요하면 안내한다.
- 버전: 앱 1.3.0(4) · 웹 0.60.0.

## 코드 리뷰

REV-015(전문가 3명): 채택 31 · 보류 4 · 기각 0. 스펙 리뷰 REV-014: 채택 47 · 보류 2.

주요 반영:

- 화면 꺼짐에는 FSI를 쓰지 않는다(화면이 다시 켜지는 문제). 화면 켜짐 + 잠김일 때 쏜다.
- 길게 누르기는 시계 기반이다.
- TalkBack에서도 쓸 수 있다.
- 「본 값으로 바꾸기」가 정한 칸을 되돌리지 않는다.
- 카드 버튼은 초안을 싣지 않는다.
- refill 판정을 채우기 규칙과 같게 맞췄다.
- 완료 버튼은 아래 고정 줄에 둔다. 여백·큰 글꼴에도 맞춘다.
