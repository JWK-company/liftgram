# EXE-011 — SPEC-020 구현

> 타입 Execution · 그룹 할일/잠금-서비스 · ADStudio가 `EXE-011.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-020

## 요약

SPEC-020(ADR-049)을 구현했다. 고친 문제는 잠금화면 운동 화면이 갤럭시 실기기에서 뜨지 않던 것이다.

- **운동 중 포그라운드 서비스**: 운동 중에만 도는 서비스(specialUse · 알림은 운동 카드)를 넣었다. 앱 프로세스가 얼지 않으니 화면 꺼짐·켜짐 방송이 제때 온다.
- **직접 시작**: 「다른 앱 위에 표시」를 허용하면 화면 꺼짐·휴식 끝에 운동 화면을 직접 띄운다. 1.5초 뒤 실제로 열렸는지 확인하고, 막혔으면 전체 화면 알림(FSI)으로 넘긴다.
- **휴식 시각**: 서비스가 도는 동안에는 서비스가 지킨다.
- **진단**: 실기기에서 원인을 볼 수 있게 프로필에 진단 줄(다른 앱 위 · 배터리)과 「잠금 운동 화면 진단 기록」을 넣었다.

커밋 `bb41292`. 배포는 웹 0.61.0, 앱 1.4.0(versionCode 5)이다.

## 수용 기준 확인

- **SRS-100**(화면을 끄고 켜면 운동 화면): 서비스가 방송 수신을 보장하고, 오버레이 허용이면 직접 시작하고, 아니면 켤 때 FSI를 쏜다.

  - 코드와 JUnit으로 확인했다.
  - **실기기 확인이 남았다** — 결과 회신의 확인 목록을 따른다. 안 되면 진단 기록이 원인을 보여 준다.
- **SRS-100**(휴식 끝 화면 켜기):

  - 꺼진 화면에 FSI가 허용되면 FSI를 쏜다. 아니면 직접 시작(wake)하고, 열림과 화면 켜짐을 확인한 뒤 필요하면 FSI로 넘긴다.
  - 서비스가 돌면 15분 이하의 휴식은 제시간에 끝난다(정확 알람 없이). 실기기 확인이 남았다.
- **SRS-096**(카드): 운동 중에는 카드가 FGS 알림이다.

  - 운동이 끝나면 REMOVE한다. 설정을 끄면 DETACH해 카드를 남긴다.
  - Android 14+에서는 사용자가 지울 수 있다. 지우면 다음 상태 변화 때 다시 나온다.
- **프로필 진단**: e2e로 확인했다.

  - 빠진 허용만 줄로 보이고, 누르면 그 설정 kind가 열린다.
  - 허용하고 돌아오면 줄이 사라진다.
  - 옛 앱이거나 알림·설정이 꺼져 있으면 줄이 없다.
