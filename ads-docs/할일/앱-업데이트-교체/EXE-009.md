## SPEC-018 Phase 4 — 판정 · 웹 화면 · e2e 구현

### 요약

새 앱 사용자는 홈 띠의 「업데이트」로 시트를 연다. 시트는 크기 안내 → (설치 허용) → 받기 → 「업데이트」 → 시스템 확인 화면 순서로 간다. 안드로이드 크롬 PWA 사용자는 「전용 앱으로 바꾸기」 시트를 연다: 기록 확인 → APK 받기 → 앱 열기(intent · 앱이 로그인 넘기기를 시작) → 웹 아이콘 지워도 됨. 옛 디버그 키 앱은 기록 확인 뒤 시스템 브라우저로 공개 `/app`을 연다.

판정은 순수 함수(`decideOffer`·`recordCheckVerdict`)로 모았다. 화면은 단계를 저장해 설치하고 돌아와도 이어진다. 단계를 넘을 때와 복원할 때마다 기록을 다시 확인한다.

리뷰(REV-013) 49건을 반영했다. 주요 반영: 기록 확인 우회 막기 · 운동 시작 시 설치 거둠 · 받은 파일을 최신판 해시에 묶기 · 「설치 취소」 탈출 · 옛 서비스 워커 우회 받기 링크.

#### 사용자가 할 일 1 — 출시 키 백업(맥 터미널 · 약 5분)

백업할 것은 `~/.liftgram-release/` 안의 두 파일이다: `upload.jks`(키) · `secret.properties`(키 비밀번호). 잃으면 앱 사용자 전원이 앱을 지우고 다시 설치해야 하고, 되살릴 길이 없다.

1. 암호화 묶음 만들기 — 새 암호를 두 번 묻는다. 이 암호는 따로 적어 둔다(비밀번호 관리자나 종이). 묶음과 같은 곳에 두지 않는다.

`cd ~ && tar -czf - .liftgram-release/upload.jks .liftgram-release/secret.properties | openssl enc -aes-256-cbc -pbkdf2 -iter 200000 -salt -out ~/Desktop/liftgram-key-backup.enc`

1. 복원 시험 — 방금 암호로 풀어 지문을 읽는다. 마지막 줄이 `SHA256: 7D:12:4A:8D:…:FA:E7:80:B8`이면 성공이다.

`rm -rf /tmp/lgk && mkdir /tmp/lgk && openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -in ~/Desktop/liftgram-key-backup.enc | tar -xzf - -C /tmp/lgk && keytool -list -v -keystore /tmp/lgk/.liftgram-release/upload.jks -alias liftgram -storepass:file <(sed -n 's/^storePassword=//p' /tmp/lgk/.liftgram-release/secret.properties) | grep 'SHA256:'; rm -rf /tmp/lgk`

1. `~/Desktop/liftgram-key-backup.enc`를 서로 다른 두 곳에 복사한다. 예: USB 메모리 하나 + 클라우드 드라이브 하나. 이 맥의 iCloud 동기 폴더는 하나로 치지 않는다. 그다음 바탕화면의 원본은 지운다.
2. 표식 남기기(또는 Claude에게 「백업 완료」라고 알리면 대신 쓴다):

`echo 7d124a8d64e38b3f2ed6e4308188d336d18f87f23f0a42a3fa7e1e23fae780b8 > ~/.liftgram-release/BACKED_UP`

#### 사용자가 할 일 2 — 배포 뒤 실기기 확인(안드로이드 휴대폰)

- 옛 디버그 앱(1.1.0)이 있는 폰: 홈 띠 「앱을 한 번만 다시 설치」 → 기록 확인 → 브라우저의 `/app`에서 새 앱을 받아 설치한다. 기록과 로그인이 그대로인지 본다.
- 크롬 PWA로 쓰는 폰: 홈 띠 「전용 앱으로 바꾸기」 → 기록 확인 → APK 받기 → 「앱 열기」 → 같은 계정으로 로그인됐는지 → 「웹 아이콘 지워도 돼요」까지 간다.
- 새 앱 안 업데이트(3 → 4)는 다음 앱 버전을 낼 때 확인한다. 지금은 서버의 최신판이 설치본과 같아 「최신」 배지만 보인다.
- 세부 체크리스트는 EXE-007 「남은 일」의 1~11번이다. 이번 단계에서 셋을 더했다: 받는 중 앱 전환 뒤 이어 받기 · 대체 설치 취소 뒤 복귀 · 운동 시작 시 확인 화면 거둠.
