# REV-024 — SPEC-022 스펙 리뷰 — 광고 자리와 운동 중 가드

> 타입 Review · 그룹 할일/광고-자리 · ADStudio가 `REV-024.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **reviews** → SPEC-022

## 패널 구성

| 역할 | 관점 |
| --- | --- |
| 정책·요구 리뷰어 | Play·AdMob 정책, SRS-098 정합, 가격 위험, 실광고 구조 |
| 구현 실현성 리뷰어 | 운동 상태, 배치, e2e 실효성, 더 단순한 대안 |

두 관점을 독립 리뷰어 한 명이 함께 봤다. 코드와 문서만 읽었고 실행은 하지 않았다. 법률 해석은 리뷰어의 추정이다.

## 핵심 지적

- **AdMob 배너는 웹뷰 위 네이티브 층이다.** 스크롤 안 자리에 그대로 넣지 못할 수 있다.
- **읽기 실패 시 가드가 뚫린다.** `activeLoaded` 는 실패해도 켜진다.
- **「e2e 가 지킨다」가 공허했다.** 슬롯이 원래 없는 상태에서 0개를 재면 언제나 통과한다.
- **가격은 전제가 다르다.** 웹 결제 수수료 기준이라 앱에서는 수령액이 줄어든다.
