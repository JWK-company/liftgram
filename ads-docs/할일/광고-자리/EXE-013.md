# EXE-013 — SPEC-022 구현

> 타입 Execution · 그룹 할일/광고-자리 · ADStudio가 `EXE-013.json`에서 자동으로 만든 읽기용 파일(고치려면 .json 또는 ADStudio에서)

- **executes** → SPEC-022

## 요약

실광고 없이 광고 자리를 확보했다. 공용 슬롯 `AdSlot` 을 화면 6곳에 넣고, 운동 중이거나 운동 상태를 모르면 비우게 했다. 일반 사용자에게는 아무것도 보이지 않고, 관리자는 운영 탭에서 미리 보기로 자리를 확인한다. 서포터 가격과 광고 규칙은 ADR-050 에 잠정으로 정했다.

미리 보기 사진으로 완료 요약과 홈 자리가 내용을 가리지 않는 것을 확인했다. 사진은 데스크톱 폭이다.

**확인하지 못한 것:** 폰 폭 사진 · 안드로이드 앱 안 화면 · 가드를 빼 보는 변이 시험 · 저장소 읽기 실패의 화면 시험(단위 시험만 있음).

## 코드 리뷰

REV-025: 채택 5 · 보류 5 · 기각 0. 스펙 리뷰는 REV-024(채택 18 · 보류 4 · 기각 1).

## 범위 밖 변경

없음. 웹 버전은 올리지 않았다. 아직 배포하지 않은 0.63.0 에 함께 실린다.

## 남은 일

- 사용자에게 보이는 변화는 관리자 미리 보기뿐이며, 배포 전에는 보이지 않는다.
- 실광고 전 선행: 광고 방식 시범, ADR-050 의 착수 점검, REV-025 의 보류 A·B·6.
- 서포터 가격은 결제 방식을 정할 때 다시 정한다.
