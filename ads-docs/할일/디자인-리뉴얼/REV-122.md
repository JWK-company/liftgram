## 핵심 지적

- 흰 바탕에서 입력칸·체크칸 경계가 `--color-line`(1.4:1)뿐 — 누르는 것의 경계는 3:1 이상이어야 한다(시각 H · UX M).
- 종목 사이 선과 세트 줄 사이 선이 같은 1px 이라 종목 경계를 놓친다(시각 M · UX M).
- 완료/미완료가 둘 다 ✓ 모양이고 색으로만 갈린다(UX H).
- 루틴 「▶ 시작」·홈 빨강 테두리 버튼은 11-09 사용자 피드백으로 올린 것 — 내리면 되돌림(UX H · M).
- `!` 로 테두리만 바꾸던 Card(피커 선택·디로드·오늘 할 운동·슈퍼셋·근처 헬스장)와 왼쪽 띠(RoutineOrigin inset) 가 평평 기본값에서 뜻을 잃는다(프론트 H).
- 바탕색을 직접 적은 곳(`src/frontend/app/layout.tsx` themeColor · `src/frontend/app/globals.css` 부팅 덮개 · `src/frontend/public/manifest.json`)이 범위에 없다(프론트 M).
- 공용 부품만 바뀐 채 배포하면 「반은 옛 디자인」 화면이 나간다(프론트 M · UX M).
- 가드가 Card 를 찾을 표식이 없고, 직접 짠 상자는 못 잡는다 · 왼쪽 강조선 허용과 「왼쪽 테두리 0」 조건이 부딪힌다(QA H).
- 실제로 깨질 시험: `src/frontend/e2e/home-primary.spec.ts:205`·`:227` · `src/frontend/e2e/value-chips.spec.ts:109`·`:146`·`:294`·`:346` · `src/frontend/e2e/coaching-v2.spec.ts:1075`·`:1257`(QA). 완료 줄 ok-soft 기대값은 0건.
