## 패널 구성

- **데이터 계산 리뷰어** — 세트 요약 숫자가 운동 화면에 실제로 깔리는 세트와 같은지(처방·웜업·드롭·슈퍼셋)
- **화면·접근성 리뷰어** — 목록 줄·시트의 누르는 영역, 깜빡임, 갱신, 시트 접근성

## 핵심 지적

- 세트 수를 `targetSets` 하나로 세면 처방(prescription) 루틴에서 운동 화면과 숫자가 어긋난다 — 웜업·피더·드롭은 작업 세트에서 빼고, 처방 줄이 빈 횟수는 블록 횟수를 이어받아야 한다
- 횟수 표기가 다른 화면(「8-12」)과 달랐다(「8~12회」) — 같은 함수 `repRangeLabel`을 써야 한다
- 이름을 다 읽기 전에 「종목 없음」이 잠깐 보인다(로드 전 [] ≠ 0개)
- 세트 수·순서를 고쳐도 목록 줄이 그대로일 수 있다 — 반응형 쿼리가 행 증감만 본다
- 유산소 판정을 이름으로 하면 틀린다 — 종목 종류(kind)로
- 슈퍼셋은 「연달아 있는 같은 묶음」만 A1·A2 — 떨어진 같은 그룹 값은 묶음이 아니다
