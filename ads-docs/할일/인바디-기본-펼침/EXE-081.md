## EXE-081 인바디 기본 펼침 · 운동 중 체중 카드 · 체중 패널 통일 — 구현

## 요약

사용자 요청 세 가지를 한 번에 구현했다.

- **인바디 칸 늘 보임**: 체중 입력(WeighInSheet)의 골격근량·체지방률 칸은 토글(`weighin-inbody-toggle`) 없이 처음부터 보인다. 「인바디 수치」 소제목과 「선택 · 비워 두면 적지 않아요」 안내는 남겼다.
  - 예전 「펼치지 않음 = 손대지 않음」은 「빈칸 = 적지 않음」으로 지킨다. 칸별로 처리한다:
    - 비었고 원래도 값이 없던 칸, 출발값 그대로인 칸 → 키를 빼서 쓰지 않는다.
    - 사람이 지운 칸 → null(지움).
  - 고치기는 원래 값이 칸에 채워져 열린다.
- **운동 중엔 시트 없이 카드 안에**: 「오늘 체중」 카드의 「기록/고치기 ⌄」(aria-expanded)를 누르면 바닥 시트 대신 카드 안에 펼친다.
  - 저장하면 접히고 값·✓가 반영되며, 포커스는 「기록/고치기」로 돌아온다.
  - 다시 누르거나 Esc를 누르거나 카드를 접으면 닫힌다.
  - 카드 안 저장 버튼은 테두리 모양이다(빨강 채움은 「완료」 하나).
- **체중 패널 하나**: 새 `BodyweightPanel`의 구성은 ① 바로 입력(bodyweight-entry) → ② 목표 체중(bodyweight-goal) → ③ 지난 기록 → ④ 체중 미설정으로 두기다.
  - **목표**: 지금 목표를 보여 준다. 「정하기/바꾸기」 → 그 자리 입력 → 「저장」(2번), 「지우기」는 1번이다.
  - **지난 기록**: 「고치기」는 그 줄 자리에 테두리 상자로 펼쳐진다(보이는 제목 · 취소 · Esc는 그것만 닫음). 「지우기」는 확인 창을 거친다.
  - **같은 패널을 쓰는 곳**: 프로필 「체중」 시트, 통계 체중 카드 「기록 ›」(같은 시트), 운동 카드(compact — 입력이 맨 위, ②~④는 「목표 · 지난 기록 ⌄」 아래).
- **통계 체중 카드 머리**: 빨간 테두리 「기록」 + ⋯(목표 바꾸기·지우기)를 다른 카드 머리처럼 회색 「기록 ›」 하나로 바꿨다(채움·테두리 없음 · 44px). ⋯와 따로 뜨던 목표 시트는 없앴다. 목표 값의 저장소·규칙(bodyweightPref)은 그대로다.
