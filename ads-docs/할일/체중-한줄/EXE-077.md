### 요약

프로필의 두 줄 「체중」(부가 설명 + 값 + 「기록」 버튼)과 「체중 기록 전체 n개 ›」를 **「체중 ‹최근 값› ›」 한 줄**로 합쳤다. 줄 전체(52px)가 누르는 자리이고, 누르면 「체중」 시트 하나가 열린다: 맨 위 바로 입력(기존 기록 시트의 ±·직접 입력·인바디 펼침·±30% 확인·저장을 그대로 씀) → 「지난 기록」 목록(고치기·지우기 그대로) → 「체중 미설정으로 두기」(설명은 확인 창에만) → 「확인」. 저장하면 시트는 열린 채 새 줄이 목록 맨 위에, 뒤의 줄 값도 바로 바뀐다. 줄의 「어시스트(체중−보조)·맨몸±가중 볼륨 계산 기준 · 가장 최근 기록」과 미설정 버튼 아래 「기록은 남아요. …」는 지웠다. 공용 `WeighInSheet` 에 `inline` 모양(포탈·스크림·제목·둘째 버튼 없이 입력과 저장만 · 저장해도 닫히지 않음)을 더했다. 포탈 쪽(운동 화면 「오늘 체중」·통계 카드 「기록」·목표 체중·고치기)은 내용 덩어리를 변수로 옮긴 것뿐이라 그대로다. 스펙 없는 패치이며 worktree 에서만 고쳤다(커밋·배포·버전 올림 없음).

### 새 시험이 보는 것

1. 프로필에 「기록」 버튼·「체중 기록 전체」 줄·「볼륨 계산 기준」 설명이 없고, 「체중」 줄 하나가 버튼(이름 「체중 미설정」 · ≥44px · › 하나 · 값이 줄 안)이다.
2. › → 시트 이름 「체중」 · 기록이 없으면 「지난 기록이 없어요 — 값을 맞춰 주세요」·「아직 기록이 없어요」 · 미설정 버튼 없음 · 둘째 버튼 없음.
3. 직접 입력 71 저장 → 시트 열린 채 목록 `71.0kg` · 줄 값 `71.0kg` · 2초 안 되누름은 줄이 늘지 않음 · 포커스는 저장 버튼 · +0.5 저장 → `71.5kg, 71.0kg`.
4. 미설정 버튼 아래 설명 없음 · 확인 창에 설명 · 취소 → 그대로 · 확인 → 「미설정」(기록 남음) → 바로 입력 저장 → 다시 내 체중.
5. 360px 문서·시트 가로 넘침 0 · 다크에서 시트 바탕 어둡고 글자 밝음 · 닫고 새로고침해도 최근 값.
