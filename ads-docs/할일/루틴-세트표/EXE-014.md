## SPEC-023 구현

### 요약

루틴 편집기에 운동 화면과 같은 세트 표를 넣고, 세트 타입을 일반·웜업·드롭·탑·백오프로 통일했습니다. 운동 하나에 강도 목표 하나(「여유 N회」)를 두고, 오늘 근육 버튼을 헤더로 옮겼으며, 가이드 버튼과 실패·플레이트 계산 메뉴를 뺐습니다. 새 루틴을 완료 없이 벗어나면 내용이 있을 때 묻고, 비어 있으면 묻지 않고 버립니다. 네 단계를 한 번에 구현했고 이 문서가 네 단계 모두의 기록입니다.

### 수용 기준 확인

- 표에서 설정한 타입·무게·횟수·강도 목표가 운동 화면에 그대로 나타납니다: e2e로 확인.
- 지난 기록이 시작 값보다 먼저이고, 고정 줄은 표의 무게로 시작합니다: e2e로 확인.
- 타입 메뉴에 실패·플레이트 계산이 없고 가이드 버튼이 없습니다: e2e로 확인.
- 360px에서 표와 헤더가 넘치지 않습니다: e2e와 사진으로 확인.
- 새 루틴 벗어나기의 경로별 동작: e2e로 확인. 잠금 딥링크 경로는 보류(REV-028).
